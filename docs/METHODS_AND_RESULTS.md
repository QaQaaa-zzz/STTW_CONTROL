# 方法与结果总表

更新：2026-09-14。本文是本项目唯一的方法台账；每次完成实验后原位补充，不另建版本副本。范围仅STTW_CONTROL，不包含DVGC/JIT。

## 如何读结果

- RMSE为误差均方根；速度使用车体真实前向速度，网络使用轮速估计。圆形路径是径向误差，弯道是右法向投影误差，不能跨任务直接排名。
- 恢复完成与不摔倒不同。未离开恢复带的扰动不计作成功恢复；超时未恢复不是物理摔倒。失败/删失时间不填零，不以成功子集均值代表全组。
- 三个评估初态种子不等于三个独立训练种子。未注明独立留出者均为开发/回归证据。历史记录中的“运行中”只代表当时快照；下表未核实完整数值的项目明确标注。
- 以下按方法归并运行，工程预检不另算性能方法；配置、预算、观测、检查点、逐项证据以对应run冻结声明和[VALIDATION](VALIDATION.md)为准。阶段性最佳、固定末次、事后诊断不能混称“最佳”。

## 尚未形成实验结论的方向

- 自动上层α网络、严格生存优先分配、固定α独立重训对照：提出过设计/建议，但本次五臂没有训练这些方法；当前α是外部给定条件。
- 能量作为奖励/α调度依据：目前只做动机讨论与机械功记录，没有电能模型与节能验证。
- Flow Matching、Diffusion、MPC/MPPI：讨论过替代路线，未在本项目完成性能对照，不列作已尝试的训练方法。
- 转向单通道、decoupled/coupled、authority-aware等可配置原型：源码/工程检查存在，未查到完整公平性能对照者不编造胜负；已完成且可排名的映射对照以上述response_comparison为准。
- 实车、8字学习泛化、多速度多半径的独立留出性能：尚无可替代上述开发证据的完整结论。
