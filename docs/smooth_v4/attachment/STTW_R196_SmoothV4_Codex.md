## 5. 新奖励：定义与精确系数

全部tracking都比较实际运动与原始黑线。记e_v=v−v_c，e_delta=delta−delta_c，e_psi=psi_raw_unwrapped−psi_actual_unwrapped；u=max(−e_v,0)，o=max(e_v,0)。

H(z)=z²(|z|≤1)，否则2|z|−1。χ与g的原始指令定义保持：χ=clip((|delta_c/q(v_c)|−.18)/.12,0,1)；g资格和.4s等待/.4s上升沿用当前V3，不能由网络或实际误差开关它。

### 5.1 普通、冲突和恢复的任务成本

普通：Nv=8H(e_v/.10)，Nd=8H(e_delta/.05)。

α0冲突：
```
V0 = .4 H(u/.30) + .4 H(o/.10) + 2 H(max(u-.60,0)/.20)
D0 = 8 H(e_delta/.05)
```
转向主项不从8加大到80。给必要的0.3～0.6m/s欠速更合理价格，而不是鼓励瞬时猛追转角。

α1冲突：
```
V1 = 8 H(e_v/.10)
D1 = .8 H(e_delta/.05) + 2 H(max(|e_delta|-.15,0)/.05)
```
保留α1对少转的原有基础压力，不能把次要目标彻底取消。

合成：
```
C_speed = (1-g)*((1-chi)*Nv + chi*V_alpha) + g*8H(e_v/.10)
C_steer = (1-g)*((1-chi)*Nd + chi*D_alpha) + g*H(e_delta/.10)
C_heading = 6*g*H(max(|e_psi|-.01,0)/.10)
```
较旧航向权重4、死区.03、尺度.15，新的小误差成本更明确，针对直行与回正后剩余.05～.10rad偏差。不重新锚定参考，sin/cos不代替累计误差。

航向即将到位时的偏航阻尼成本：
```
r_c = v_c*cos(caster)*tan(delta_c)/wheelbase
C_yaw_damping = .5*g*exp(-(e_psi/.15)^2)*H((r_actual-r_c)/.20)
```
大航向欠账时该项很小，允许转过去；接近目标时防止持续偏航造成过冲。它只是reward，不是向执行器注入解析航向反馈。

### 5.4 在正确位置、正确时间尺度上评价平滑

删除旧 `0.1*sum(((final_command−previous_final_command)/[3,60])²)` 的优化作用，仅保留其日志作旧新对照。这个5ms未除时间的电机命令差不是上层转角参考平滑成本。

令D_j为一个完整20ms策略区间末端实际offset；D_{j-1}为前一区间末端：
```
V_D_j = (D_j-D_{j-1})/.02
A_D_j = (V_D_j-V_D_{j-1})/.02
C_upper_rate = .10*((V_D_v/1.0)^2 + (V_D_delta/.40)^2)
C_upper_acceleration = .05*((A_D_v/10.0)^2 + (A_D_delta/10.0)^2)
```
这里steer rate为rad/s、第二差分为rad/s²；speed分别m/s²和m/s³。参考“刹车→保持”只付短暂成本，高频反复反向反复付成本。不能对raw的目标变化计这两项。

### 5.5 无总成本100裁剪，但有独立极端保护


## 6. 抑制保护前请求的抖动：轻量Actor时间正则

reward中的rate/acc针对实际交给底层的修正。为避免“网络请求很抖但被slew掩盖”，额外在PPO Actor loss中加入一个小项，Critic不拟合它。

D_theta(o)指当前Actor均值经原tanh/非对称缩放得到的保护前修正，不加raw，不经过slew，不采样。

```
L_temporal = lambda_T * sum_j M_j * ||
 (D_theta(o_{j+1})-D_theta(o_j)) / [.10,.02] ||² / N_valid_pairs
lambda_T = .01 * min(accepted_policy_updates/10, 1)
```
配对来自同一环境、同一回合相邻20ms观测，不能用shuffle minibatch的邻行；两个输出均用当前参数并允许梯度。真实done前的最后合法transition可保存，但reset后的新观测不能接上；数据切片末端没有合法next_obs时mask。

M_j要求两端原始指令变化率均不大于.1m/s²、.02rad/s，且两端|phi|<.24、|phi_dot|<.6，避开急剧姿态反应。N_valid_pairs是同回合真实配对总数，不是变动的M=1计数。没有合格pair时该项为0。

这种正则属于CAPS式时间平滑思路，但这里正则化的是物理参考修正并加了任务mask，不声称原论文参数直接适用。不要加空间噪声损失、不要扩展新网络，也不要在采样后加未纳入概率的有色噪声。

最终先给对比图，然后用具体数据回答：黑线是什么；α0指令是否更平滑；少抖是否以更大欠转/更慢响应为代价；α1是否保住速度；回正后能否同时保持；旧底层通过场景是否被保住。只有本run的实际测量可填入结果，不把本说明中的预期值写成结果。
