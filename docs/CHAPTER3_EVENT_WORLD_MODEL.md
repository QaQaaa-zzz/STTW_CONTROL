## 合并后的模型与统计合同

吸收新增建议中的并行读出、有效事件标签和道路相对特征；不采用预设提升幅度、必胜基线或把240条整程分母认定为错误的说法。实际接线的动作是路线、请求速度、α及技能选择；κ属于候选路线特征，不另写成已实现的独立控制通道。

令V_h表示交接发生且此前未违反任务道路约束，z_h为物理交接状态及按声明初始化规则得到的下游闭环状态。总体任务概率应为

\[
P(Y=1\mid s,a)=P(V_h\mid s,a)\int R_\phi(z_h,g,I)\,p_\theta(z_h\mid V_h,s,a)\,dz_h.
\]

若Rφ只训练2秒接续，左侧必须改为该2秒事件，不能冒称整程到达概率；整程头与短窗头分开评价。到达目标已包含触岸时，不再额外乘入口条件下的边际触岸概率。概率校准在分组开发集检验，不因采用乘积自动成立。

上游预测交接分布，入口/腾空/触岸可作同次前向的辅助输出，不强迫五次串行自回归。短历史与完整历史/PCA做显式消融；13维root不能自动替代转向、关节和控制器状态。物理交接状态与初始化后的控制器状态分别处理。地面段使用原路线相对误差，飞行段保留物理空间表示；预测四元数须保持合法表示。

动力学准入先作为共享启发式基线，阈值由声明开发条件核验；不把稳态侧倾公式当瞬态安全认证。所有规划方法共用同一准入，另做有无筛查消融。速度/α对应哪种来车优势由实测决定，不预先规定右倾必选α1。

## 任务与决策时限

## 两个预测模型与技能边界

目标方法按地面和跳跃两类能力组织。当前工程原型实际为共享编码器加接近、跳跃、续行三个预测头，输入PCA压缩的控制历史；尚未实现独立两模型、完整短时轨迹预测或任意下一接触模式分类。容量与组织方式依据独立预测误差决定，不预先增加大型模型或底层PPO。

|模型|输入|输出与边界|
|---|---|---|
|地面模型|实际车辆状态、控制历史、局部地形/边界、候选路径、速度和α|固定短时段轨迹、状态变化和耗时；用于接近、绕行及交回H75后的续行|
|跳跃模型|触发时的预测状态、跳跃策略身份、起落地形及机构状态|离地、清障、首次触地和恢复事件的时间/状态及中间轨迹，终点为满足交接条件且H75实际开始续行|

模型输入包含位置/航向、纵横速度、侧倾/俯仰与角速度、转向/摆关节实际状态；保存ESO、滤波、延迟和控制历史。缺失历史时如实说明状态不完备。模型输入地形来自已知地图，不使用未来真实轨迹。

首次触地不是预测终点。跳跃模型输出的交回状态继续输入地面模型，预测到共同终点；任一阶段失败保留实际终点，不补造后续状态。恢复终点、车轮支撑、整车净空及道路边界分别记录。接触模式保留双轮/单前轮/单后轮/无支撑；无支撑不能自动标成主动跳跃。

真实来车接口现可通过 `ground_handoff.reference_path` 读取固定世界路径（s、xy、heading、curvature），接近与落地续行共用该参考，不在落地时重定位。历史直道/左右偏移双弯各两档速度，共6条8秒名义DEV；平面30cm沟平移至6.3～6.6m，跳跃触发线5m，策略距离参考及事件区域同移3m。运行合同与配置在数据盘 `chapter3_bend_approach`，六条现已完成：4条回交并续行至8秒，左右1.8m/s两条在回交前姿态超限；尚非共同目标任务验收。[全部结果](evidence/chapter3_bend_approach/RESULTS.md)。

首要指标为到共同终点并保持有效行驶的完整任务完成率。另报完成用时/距离、选择跳跃后的失败率、有成功跳跃候选却绕行的比例、硬约束违反、过晚决策、超时、推理成本，以及状态/事件时间误差和错误可行判断。分母明确，失败不从任务统计删除；按独立任务作配对统计与置信区间，重复帧不当独立样本。

拟证明两项方法价值：接近指令能否改善实际起跳及整程结果；持续前进下，把准备距离与绕行机会截止时间结合是否改善决策。RecoveryBridge替换须重测模型条件，检验技能增强是否真实扩大接近方式或减少绕行。均为待验证假设，不预写优于基线、首次创新或既有能力完成。

论文顺序：任务定义→接近方式对起跳的影响→运动预测模型→提前选路与接近规划→仿真验证→讨论。附件的文献比较尚未在本轮逐篇核验，不作为已证实的新颖性结论。
