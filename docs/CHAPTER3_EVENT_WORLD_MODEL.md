# 第三章：接触事件与越障后恢复的预测规划

当前主线按用户2026-11-09要求调整。附件是研究设计参考，文中预算和预期贡献不当作已完成结果。实验结果仍只写第三章结果台账；预算、队列、采集协议保存在run目录。旧地图任务图可复用，LLM和场景菜单不作为当前研究主线。

## 要回答的问题

同一来车、同一障碍和远岸承载带，后续恢复道路不同，是否应改变接近动作或轮行/跳跃选择？先验证预测准确性，再验证真实整程净增；不预设事件模型一定优于普通前向模型。单纯成功率预测、腾空、首次触地和完整任务到达分别报告。

## 数据与模型合同

模型输入为可观测车辆状态（路径/航向误差、纵横速度、侧倾/俯仰及角速度、转向、摆关节）、局部高程图、当前接触模式、候选控制及技能身份、后续道路。保存实际控制历史、ESO/滤波/延迟等影响未来的状态；缺失时明确非Markov限制，不宣称只用姿态速度已完整描述状态。高程图只取当前已知地图，不使用未来实际轨迹。

输出为下一事件类型、到事件时间、事件后状态分布和多标签约束结果。共享状态/地形编码，地面、越障和恢复三分支；从小型MLP/GRU开始。连续段可用物理基线加残差，碰撞瞬间独立预测跃迁。状态、类别、时间、结果损失分别记录；未到达事件不能填零，观测窗末仍未恢复按右删失，实际物理失败独立标记。概率评分与校准在留出组上评价。

接触模式：双轮、仅前轮、仅后轮、无轮支撑；首次远岸接触和恢复是事件，不能把每次无接触都解释为主动跳跃。先保存原始力，再按冻结阈值生成标签；净接触力＋空间区域只是远岸接触代理，真实碰撞对象身份尚需补采。恢复谓词需由无障碍正常行驶的速度/误差/姿态包络标定、冻结并保持窗口；未提供该谓词的历史数据不能自动标成恢复成功。

记录双时间尺度：物理步接触/位姿/执行量；50Hz策略输入、动作与控制历史。`record_physics_contacts=true`为既有评测器新增可选记录，输出`physics_contact.npz`，不改变默认入口。该记录器尚待一次真实仿真接线与开关配对检查；不能把代码存在写成已采集。现有body_contact历史记录实际混合5/20ms，不够充当2.5ms碰撞真值。

## 规划与对照

有限候选包括轮行/跳跃、速度/α接近档和合法绕行。预测接近→清障→远岸承载→恢复→共同目标，采样多次未来并按固定约束、完成概率、时间与能耗排序。能耗需实际力矩与角速度积分；没有该数据先报告缺失，不拿动作范数冒充能量。新状态到来后允许有预算重规划，不另训整轨迹PPO。

比较：几何规则、旧C6入口能力、同输入直接整程分类器、定步长状态模型、事件模型止于清障、完整恢复事件模型。所有方法共享地形/后路信息、候选、训练数据、终点与预算。按完整来车母轨、布局与车辆参数分组，先划分后切片；同根后缀不得随机混进TEST。

嵌套宽窄后路用于检验恢复空间影响，但不能保证后路信息带来额外成功。另用相同承载带后的左右弯等不嵌套后路检验动作选择价值。先固定动作核对着地前前缀，再允许规划器选动作。报告事后可利用上限、逐根新增/丢失成功、置信区间、Brier、事件误差、推理与物理交互成本。

## 推进顺序

1. E0：等待当前ditch150候选；冻结实际checkpoint后，与原技能配对测试普通同高地面、碎石同高地面和既定0.60m沟。先接触记录与落地回交可执行，再扩至24–40条。原目标沟失败原样保留，较窄沟仅另列能力诊断。新地面不能套用平台z=.23落地判据。继续沿用已授权训练，不新增底层PPO或训练预算。
2. E1/E2：确认事件标签可信后采探索完整轨迹，拟议300–500条并非已启动预算；按覆盖/误差决定是否扩展。训练直接能力、定步长和事件三类模型。无足够事件数据不先堆模型容量。
3. E3/E4：同地图同目标实际验证，再比较RecoveryBridge技能替换。旧平台能力模型不跨新技能/地形直接复用。50–80独立初态及更大扩展均先冻结合同再执行，不自动启动。
