# 第三章：面向技能交接可恢复性的预测与规划

## 当前研究问题与证据判断

研究问题改为：上游技能的终端状态分布与下游控制器可接续的状态域是否重叠；能否通过入场速度、α和路线改变重叠程度；没有足够重叠时，是否需要修复下游控制器。前两章分别提供地面速度—转向偏好接口和受扰技能修复方法，本章研究它们之间的接口，不重复训练一个新跳跃技能作为主要贡献。

旧“事件预测→候选选择→执行”最小工程闭环已完成，但不等于新研究问题已经验证。用户提出的第一、二章统计是研究背景，本次未复核其原始记录，不直接移植为本章实验事实。当前不以超越基线为继续条件，也不把仅能执行当作接口机制已成立。

已完成第一步：复算原技能720与1440条，以及原技能/RB400各240条的阶段标签，详见[阶段与初始化审计](evidence/chapter3_handoff_audit/RESULTS.md)。720条中265未到入口、153回交后失败；1440条真正发布1199，其中383未到入口、379回交后失败。去除回交前已越廊样本，回交后仍分别127和326失败。说明**上游到达和下游接续都是瓶颈**，不能认定全链仅卡在交回。当前记录不足以把捕获与已捕获后续行分开。

## 两个待实现的接口模型

令物理状态为x，控制器状态为c（ESO、滤波、历史帧与mask、延迟/执行器状态），下游任务几何为g（局部高程、走廊宽度/曲率/弯向、目标与剩余时域），初始化规则为I。

1. **上游到交接**：学习 pθ(x_h,τ_h,到达交接且此前未违规 | x_t,c_t,局部地图,入场路线,v,α,跳跃策略版本)。未交接轨迹必须有失败/缺失事件标签，不能只拟合成功着陆。物理交接状态与按I生成的下游控制状态分开表示。
2. **交接到续行**：学习 Rφ(x_h,c_h,g,v_down,α_down,I,控制器版本)，预测在冻结观察窗内不越廊、无物理/运行域失败并继续推进的概率，以及经验扰动裕度。先验证捕获标签，再决定是否预测恢复距离；不再把“交回发生”作为需要学习的主要概率。

总体评分整合上游有效交接概率与下游接续概率，避免重复乘道路合格因子；显式输入剩余时间。只有任务设置时间代价时才使用预测时长。裕度定义为声明扰动方向和归一化尺度下、实际测得的接续可行范围或保守下界；无采样处为未知，不能用未校准概率冒充状态空间距离，更不称全局安全保证。

每次获得新的实际状态时更新候选预测；需固定重规划触发点、执行中的控制指令保持方式与真实查询延迟。该闭环是下一版目标，**当前实现仍为一次途中选择加发布复核**。

## 下一步：先检验可接续性和初始化，不训练新跳跃网络

- 先用无障碍地面行驶标定可接续包络，再冻结误差容差、观察窗、保持/推进要求、道路及物理约束。这里的“稳定”是动态有界续行，不要求停住或持续双轮静态支撑。
- 首轮拟议预算：24个已记录交接来源，按路线/落地状态分层选取，不只挑成功例；在相同实际交接处对照冷启动与测量一致初始化，再补有限方向扰动。后缀1–2秒；前缀重跑开销单列。预算和具体扰动范围需写入运行合同后执行，本次尚未启动。
- 原接口冷启动：ESO/扰动与滤波归零，H75历史清空仅一帧。对照应区分“测量初始化”和“真实历史预热”：填充重复当前帧不能称预热；不能把腾空阶段的地面模型无条件积分当有效估计。
- 短分叉必须包括足够物理/控制隐藏状态。现有记录不是完整仿真快照，优先同起点重跑前缀并在交接时分叉，不静默移植root状态。先检查未加修正分支与正常连续执行是否一致到足以支持标签。
- 标签至少分为：直接接得住；直接失败但在固定短修正动作集/预算内有成功；在已测修正中仍失败；未知/记录不完整。第二类只证明在已测动作集合中可救，不能把“未救成”称不可恢复。修正预算、作用时长和权限固定，不放宽物理或道路判据。

## 任务与决策时限

已知高程地图及道路边界；公共接近段连接跳跃路线和向前绕行路线，两路在障碍后汇合。车辆持续前进，不能靠停住等待、倒退或过线后换路补救。速度范围由实际闭环测试确定，不预设任意低速可稳定。

区分地图分岔、最晚可进入绕行的位置、决策线。第一版固定决策线：在声明来车状态与速度范围内，用H75测试最晚绕行位置，再向前留出实测计算、指令响应及转向准备余量。地图路口存在不代表当前状态仍能驶入。

- 决策线前：比较完整跳跃和绕行方案。达到开发集冻结可靠性门槛的方案中比较通行时间；跳跃不满足而绕行可执行时绕行。
- 两类均未达可靠性门槛：在仍可达且满足硬约束的前进候选中，选择预测完成率最高者，明确记录低置信度；门槛不足不能改写为可行。若没有合法候选，记录不可执行及实际结果，不放松物理或道路约束。
- 越过决策线：路线固定，后续只更新该路线内的速度、α、接近曲线和已验证区间内的触发位置；扰动不能授权跨回另一道路。
- 计算期间继续执行上一指令，预测起点和评价计入实际延迟。超时沿用此前已检查且仍可执行的方案；失效则记录无有效备选。10Hz仅是开发目标，由实测耗时与道路余量决定。

## 两个预测模型与技能边界

目标方法按地面和跳跃两类能力组织。当前工程原型实际为共享编码器加接近、跳跃、续行三个预测头，输入PCA压缩的控制历史；尚未实现独立两模型、完整短时轨迹预测或任意下一接触模式分类。容量与组织方式依据独立预测误差决定，不预先增加大型模型或底层PPO。

|模型|输入|输出与边界|
|---|---|---|
|地面模型|实际车辆状态、控制历史、局部地形/边界、候选路径、速度和α|固定短时段轨迹、状态变化和耗时；用于接近、绕行及交回H75后的续行|
|跳跃模型|触发时的预测状态、跳跃策略身份、起落地形及机构状态|离地、清障、首次触地和恢复事件的时间/状态及中间轨迹，终点为满足交接条件且H75实际开始续行|

模型输入包含位置/航向、纵横速度、侧倾/俯仰与角速度、转向/摆关节实际状态；保存ESO、滤波、延迟和控制历史。缺失历史时如实说明状态不完备。模型输入地形来自已知地图，不使用未来真实轨迹。

首次触地不是预测终点。跳跃模型输出的交回状态继续输入地面模型，预测到共同终点；任一阶段失败保留实际终点，不补造后续状态。恢复终点、车轮支撑、整车净空及道路边界分别记录。接触模式保留双轮/单前轮/单后轮/无支撑；无支撑不能自动标成主动跳跃。

真实来车接口现可通过 `ground_handoff.reference_path` 读取固定世界路径（s、xy、heading、curvature），接近与落地续行共用该参考，不在落地时重定位。历史直道/左右偏移双弯各两档速度，共6条8秒名义DEV；平面30cm沟平移至6.3～6.6m，跳跃触发线5m，策略距离参考及事件区域同移3m。运行合同与配置在数据盘 `chapter3_bend_approach`，六条现已完成：4条回交并续行至8秒，左右1.8m/s两条在回交前姿态超限；尚非共同目标任务验收。[全部结果](evidence/chapter3_bend_approach/RESULTS.md)。

当前回交实际使用H75 + ECBC/ESO、zero_lower=true，不误称启用了Local300残差。地面反馈为已有clean-state接口，跳跃前噪声/延迟尚未扩展到回交段；随机物理参数保留。新模型须绑定实际执行接口和策略身份，不能直接套用旧平台能力数据。

## 候选生成与预测评价

规划器有限枚举可跟踪接近曲线、已测稳定速度档、α（初步0/.5/1）、已测触发区间及跳跃/绕行路线。路径不能越出原道路，调整参考不改变共同目标和原任务边界。每个变量须先通过执行接口并取得真实记录，不能因配置中存在就称已实现。

按接近→跳跃/恢复→H75续行，或绕行→续行，连续预测到同一终点。能力评价器使用预测过程与实际完整任务标签训练/校准；报告状态、事件时间、净空/边界风险及完整完成概率。通行时间为初版代价，行驶距离另报；没有力矩×角速度数据时不声称预测了真实能耗。

跳跃策略当前依赖直线参考坐标。改变跨越位置和方向前，应统一变换位置、速度、航向、障碍距离与历史观测，并核验平移/旋转等价回放；这一能力尚不能视为已验证。

## 对照、指标与贡献边界

主对照：固定绕行、几何规则、充分调优的状态规则、同数据/候选的直接整程成败预测、世界模型规划；旧C6与无恢复预测可作为附加诊断。共享地图、技能、候选权限、决策线、计算时序和硬约束，简单规则不被故意削弱。

首要指标为到共同终点并保持有效行驶的完整任务完成率。另报完成用时/距离、选择跳跃后的失败率、有成功跳跃候选却绕行的比例、硬约束违反、过晚决策、超时、推理成本，以及状态/事件时间误差和错误可行判断。分母明确，失败不从任务统计删除；按独立任务作配对统计与置信区间，重复帧不当独立样本。

拟证明两项方法价值：接近指令能否改善实际起跳及整程结果；持续前进下，把准备距离与绕行机会截止时间结合是否改善决策。RecoveryBridge替换须重测模型条件，检验技能增强是否真实扩大接近方式或减少绕行。均为待验证假设，不预写优于基线、首次创新或既有能力完成。

论文顺序：任务定义→接近方式对起跳的影响→运动预测模型→提前选路与接近规划→仿真验证→讨论。附件的文献比较尚未在本轮逐篇核验，不作为已证实的新颖性结论。
