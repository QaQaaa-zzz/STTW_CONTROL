核查日期：2026-10-22。范围：用户粘贴的完整评审；实际物理外力、路径采样、训练、PPO、评测、逐例结果及两分支奖励版本。未开展新训练或物理仿真，没有把评审建议全部直接改成算法。审阅采用scientific-critical-thinking技能组织“事实/假设/建议”的区分；方法工具来源见文末。

## 一、总体判断与研究主问题

这份评审抓住了重要问题：解析模型的目标与任务标签不同；跨速度代理失效；有限扰动暴露、单训练种子、任务保持不足；目前不足以支持“容扰度指导训练更强”。这些应当接受。

需要纠正的是：本次双网络容扰度训练没有使用V3；不存在已发现的4倍reward-dt错误；采样单测和实际路径族占比已经存在；PPO的奖励截断不等于直接动作梯度消失；二分法和有限oracle不能自动证明真实边界/不可恢复上界。critic失配、暴露不足、引导太弱等是合理解释，尚未被消融识别为原因。

建议主问题收敛为：**在冻结底层的中层控制任务中，方向性恢复余量是否能帮助选择更有效的恢复训练数据，并在相同总交互量下改善实际任务恢复？** 解析模型是待验证的信息来源；经验抗扰改善是目标，不能用余量分数改善代替。单网络α是控制器候选与另一个研究问题，不强行宣称两条线都已完成。

## 三、幅值约束公式：能推什么，不能推什么

若冻结系数模型满足 `zdot=λz+bu+γF(t)`，通过乘exp(−λt)并设终端z(T)=0，得到

```text
z(0)+KF = −b∫₀ᵀ exp(−λt)u(t)dt
|u(t)|≤U  ⇒  |z(0)+KF|≤|b|U(1−exp(−λT))/λ = R_inf
```

对该单一标量、自由可选有界输入、无其他约束的模型，这个区间条件是可达条件。它不要求拟合E_b。但实际中层只能改参考，真实转角速率还受ECBC/ESO/local300、转角幅度、执行器动力学、路径需求影响。配置±3rad/s是最终执行器速度命令限幅，并未证明实测δdot硬限幅正好3，因此不能直接称整车可恢复区域。

L2预算给半径 `R_2=|b|sqrt(E_b(1−exp(−2λT))/(2λ))`。等半径换算得到

```text
U_equal = sqrt(E_b λ/2 × (1+exp(−λT))/(1−exp(−λT)))
```

用已有24个快照的λ=6.38450585、E_b=.0308390853、T=1s，`U_equal≈0.31429rad/s`。但这不是L2最小能量最优输入的峰值；后者在边界初时刻为

```text
|u*(0)| = sqrt(2λE_b/(1−exp(−2λT))) ≈ 0.62752rad/s
```

两者都小于3，但只能说明所拟合任务代理对应较小的理想控制努力尺度，不能据此证明“闭环带宽就是0.314”或“其余物理能力可调用”。数值与24个状态的来源见[输入换算审计](evidence/tolerance_review_audit_20261022/equivalent_input_audit.json)。同时需说明力与控制可同时作用、T≥Δ、γ视作常数等假设。

## 四、建议采用的优先顺序

1. **先把恢复数据密度和任务保持问题做成可控实验。** 用TRAIN实际前缀完整分支、3–4s恢复片段，保留名义父策略BC/KL或适量无扰回合。短片段价值边界和完整任务剩余时间必须说清；前缀采集、失败和训练成本一并计。先验证有实际恢复暴露且正常任务不明显退化，再讨论容扰度引导增益。critic预热作为单独工程验证，不把未证主因写成事实。
2. **引导效用与控制器改进分层比较。** 从同一固定父模型、相同奖励/优化设置出发，比较uniform与guided，记录状态条件余量/选择概率/实际活动恢复样本；保留覆盖而非直接只练最低30%。最终至少多训练种子、独立场景组。若采用u325/V3，明确是新控制器协议，不与旧双端点直接混算。
3. **解析余量继续做可解释基线，而不是先验安全判定。** 增加输入幅值约束版与经验方向标签比较；先检验单调性再细化边界。 learned predictor或余量特征应在足够独立TRAIN标签后再做匹配消融，不因解析代理表现差立即增加第三个网络。

不一次性同时改V3铰链、成功阈值、初态随机化、critic、引导强度和预测网络，否则又无法知道哪个改变有效。没有证据要求我们先把容扰度精度做到极高；真正要验证的是训练用途。
