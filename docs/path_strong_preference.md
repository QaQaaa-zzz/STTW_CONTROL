## 2. 具体怎样做成一个网络

### 单个条件Actor，直接用PPO学习两种行为

部署时只有一个函数：

\[
(\Delta v,\Delta\delta)=\pi_\theta(o,\alpha)
\]

所有α使用同一套参数、一次前向计算。训练时配一个共享Critic；不为不同α建立独立Actor或优化器。

保留351维Actor输入、352维Critic输入，以及`128→128→64`隐藏层。α仍位于输入索引336，但在第二、第三隐藏层增加直接调制：

\[
q=2\alpha-1
\]

\[
h_1=\operatorname{ELU}(W_1o+b_1)
\]

\[
z_l=W_lh_{l-1}+b_l,\qquad
h_l=\operatorname{ELU}\!\left[(1+qg_l)\odot z_l+qc_l\right],
\quad l=2,3
\]

\[
\mu=W_4h_3+b_4.
\]

这里的\(g_l,c_l\)是共享的可训练向量。每个网络只新增384个参数。α能够直接改变中间特征的强弱和偏置，避免完全依赖首层把一个α数值传递到底。该结构采用特征调制思路；其在本任务中的效果仍需训练验证。[FiLM原论文](https://arxiv.org/abs/1709.07871)

Actor与Critic都采用上述条件结构。既有动作映射、滤波、slew、修正权限和冻结local300保持原合同。

这个调整有现成轨迹依据。按α=1奖励、训练使用的\(\gamma=0.997\)重新评分，得到以下**折扣成本，越低越好**：

| 左弯 | 22.74 / 30.15 | **35.21 / 30.15** |
| 右弯 | 19.41 / 18.63 | **29.65 / 18.63** |

原系数在左弯更偏好减速轨迹；系数2能让左右高速弯都认可已有的保速行为。这里是固定轨迹重评分，不是训练成功证明。
