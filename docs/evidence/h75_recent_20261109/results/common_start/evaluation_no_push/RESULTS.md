# 续训150轮：无外部推扰结果

[全部13工况五alpha图](plots/README.md) · [平地工况5](plots/case_05.png)

固定共同起点150轮模型，关闭起步横向力与周期速度冲击，保留地形、车辆随机化、噪声和延迟。65条件中56完整观察10秒；6个domain运行域终止、3个侧倾阈值终止。60个非平地条件均记录到接触并越过初始障碍带。

同一150轮模型有推扰25/65→无推扰56/65，新增完整31、丢失0。初态和车辆随机参数已核对相同。共同有效窗口路径RMSE均值0.5494→0.2336m，速度RMSE0.3640→0.3858m/s。各自实际窗口无推扰路径0.4448m、速度0.4018m/s、速度偏差-0.3811m/s；窗口不同不要混比。

|alpha|完整/13|路径RMSE(m)|速度RMSE(m/s)|
|---|---:|---:|---:|
|0|13|0.240|0.475|
|0.25|12|0.263|0.445|
|0.5|12|0.443|0.405|
|0.75|10|0.626|0.357|
|1|9|0.652|0.328|

上表按各自实际观察窗口计算。平地case5五alpha均完整；原有推扰时五alpha全部提前终止。低alpha路径更准，但仍减速，高alpha速度误差较小但跑偏/终止更多。完整观察不是全部任务约束合格，侧倾阈值不是确认摔倒。13工况×5alpha不是65独立地形。

本表没有原H75无推扰对照；用户随后授权的配对补测见[新对照目录](../evaluation_no_push_paired/)。没有据此认定续训优于原H75。
