## 终止原因

互斥组合：原模型仅domain36、仅侧倾阈值4、两者同时1；新模型仅domain35、仅侧倾阈值2、两者同时1、未知2。总计41→40。对应非互斥信号domain37→36，侧倾阈值5→3，不重复相加，不把41/40叫摔倒。domain是控制器路径跟踪运行域，不是地形边界或任务走廊。发生时刻按首个20ms失败步末端记录。

关键反例：工况5是平地，五alpha原模型1.78–1.82秒domain终止，新模型1.88–2.00秒domain终止；不能把这些归因于石子/拖距。原模型9条件、新模型5条件在进入障碍带前已终止（平地单独看），说明有前段跟踪问题待查。非平地共60条件：抬高轮接触56→60，越过障碍带55→60，但越过环带不等于整段任务完成。

## 偏离路径诊断更正：平地并非无扰动

复核initial_state.npz的pulse及apply_pulse源码：工况5在起步0–0.1s施加约32N横向力，且保留域随机化；此前“平地失败”遗漏这一关键条件，不能解释成无扰动平地也不会跟踪。

原模型alpha0：0.5s路径误差-0.500m、yaw -38.31°；1.0s误差-0.889m；1.78s终止时车头+35.36°、路径切线-23.17°，预瞄点车体前向坐标0.01145m低于0.05m门槛。新模型对应0.5s误差-0.452m、yaw -31.46°，1.88s预瞄前向0.03942m触发。是先偏离再回摆/错过弯道并触发预瞄运行域，不是路径消失。数值取保存20ms步端点，预瞄按实际参考/位姿/进度重建。

13工况中5个24/32N工况两模型所有alpha均提前终止；3个零起步脉冲工况共15条件，完整观察原14、新13。条件间路径/地形不同，该分组是相关性证据，不是推力单因素消融。零脉冲也保留域随机化。所有失败不能单归因越野，更不能据这些复合压力工况断言纯越野无跟踪能力。
