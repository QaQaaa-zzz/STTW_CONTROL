# STTW 投稿观点与证据映射

这是证据组织表，不是已提交稿件。当前原始研究问题：在非平坦地形上，固定底层之上的偏好条件速度/转向修正，能否产生可选择、可解释的路径—速度取舍并执行外部给定偏好变化？不研究第三章的跨技能选择。

## 主线应怎样表达

**方法核心**：alpha进入上层策略，联合调整速度和转向参考；冻结Local300与ECBC/ESO承担底层执行。保留既有滤波、非对称限速和动作边界。用同一原始路径与用户速度评价，而不是用策略修改后的参考重定义成功。

**实证核心**：同一模型通过alpha提供不同工作点；任务权重与道路空间约束决定选择。连续指标及实际轨迹比“全面提高成功率”更准确地描述这项方法。

**机制与动态支持**：同状态双通道干预、接触几何分析和既定弯内切换，说明工作点变化怎样通过两个参考通道产生行为。负拖距是本车接触解释，不作为首次发现或新稳定性定理。

## 方法章节必须说清楚的事实

- 五alpha档位与原H75/Local300身份；Zero是同底层而无H75，不是纯ECBC。
- 物理.0002s、底层.005s、上层.02s；上层修正参考而非直接缩放底层平衡动作。
- 请求速度、后轮估速和真实速度不同；低速请求从同一2.3m/s热启动开始，不称静止起步上坡。
- alpha选择的权重、误差单位、共同窗口、峰值约束和候选集合，不能把.5和.75写成互相冲突的普适最优。
- 固定路线地形矩阵与带重规划切换实验分开；切换结果包括重规划闭环。
- 五参数种子仅是物理/执行参数重复，已有DEV数据用于方法发展，不包装成未见测试。
