# 越野新弯道运行域退出诊断

[原120条实际/参考XY](../chapter3_offroad_task_map/xy.png)。复用原轨迹，未重跑物理，也未改变失败标准。

首版S弯参考峰值曲率1.589/m，90°圆角参考峰值1.544/m（半径0.65m）。冻结H75跟随器名义转角上限0.3rad、轴距0.27903m、caster=0，对应名义几何曲率tan(0.3)/0.27903≈1.109/m；此值是跟随器请求范围，不是车辆或学习修正后的严格能力认证。

运行域退出条件在torch_path_reference.py中是预瞄点车体前向坐标≤0.05m，或路径投影航向与实际航向差≥90°，或数值故障；数值故障在执行侧另记。不能直接放宽此条件把退出改称成功。

原始实际终点例：S弯1.5m/s、alpha0、root0，终点约(5.094,1.107)m，实际航向21.75°，全局最近道路航向−29.04°；90°弯1.5m/s、alpha.5、root0，终点约(4.414,1.947)m，实际航向90.13°，全局最近道路航向0°。这些是20ms记录末帧及全局最近参考的事后诊断，不能冒充内部5ms有历史约束投影的精确触发分解。

下一条件保留首版压力地图，另以同石子、脊坡、沟、目标、速度/alpha矩阵测试：S弯参数幅值0.65m、x2..8.5m；圆角半径1.1m、偏移2.6m。只改变道路几何，不改物理/道路约束；不保证成功。参数：learning/configs/chapter3_offroad_map_gentle.json。新120条验证属于探索DEV，不是原压力条件的替代成绩。
