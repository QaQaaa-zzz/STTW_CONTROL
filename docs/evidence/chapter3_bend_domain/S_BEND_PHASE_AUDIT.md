# 更缓S弯首次越廊阶段核查

[全部实际/参考XY](../chapter3_offroad_task_map_gentle/xy.png)。复用原30条S弯轨迹，未重跑。

25条首次道路违规发生在跳跃接管前，另外5条无道路违规记录；没有首次越廊发生在跳跃或续行的条件。时间取20ms策略记录中累积道路违规标志首次变真，真实物理越界发生在该记录窗口内，不冒充精确事件时刻。

6条交回STTW中5条已在接近阶段越廊；其中一条最终进入目标但按原整程判据不合格。无越廊的root0、2.3m/s、alpha0在交回约0.78秒后侧倾阈值超限。其余交接后失败间隔约0.08–3.98秒，具体逐条记录见s_bend_phase_audit.json。

因此RB候选对比必须区分接近、跳跃和续行；不能把既有地面违规归因于新跳跃策略，也不能清除既有违规使任务变成成功。
