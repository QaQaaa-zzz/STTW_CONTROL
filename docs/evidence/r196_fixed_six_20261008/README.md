## 实测结论

**已完成18/18条10秒轨迹，无物理失败；上层有取舍收益，但没有全面改善，航向恢复仍不可靠。**

三项保持同时检查末[9.5,10)秒速度≤.1m/s、转角≤.04rad、航向≤.05rad，任何一步超限即不通过，不是只检查RMSE均值。三方法均2/6通过，但通过场景不同；单种子开发面板不是泛化成功率。

具体收益与代价：

- 直行/变速：两上层指令窗口速度误差都高于底层。直行两上层航向不合格；变速α1合格、α0航向不合格。
- 正向缓转：α0速度与转角误差略改善，侧倾减小，但末航向更差；三方法均未同时保持。
- 反向缓转：α0改善速度/转角并完成三项保持；底层与α1仍有航向问题。
- 转向反转：两上层速度改善、峰值侧倾降低并完成末段三项保持，但指令窗口转角误差增加。
- 加速急转：速度RMSE B0/α0/α1=.0827/.1180/.0174m/s；转角=.0582/.0738/.1003rad；峰值侧倾=.4131/.2532/.2119rad。α1保速度与姿态，代价是更明显欠转和航向误差；α0的速度、转角均比底层差，但峰值侧倾降低。三方法方向都未恢复；末航向RMSE=.3158/.2897/.4372rad。
