# 第三章当前交付：技能交接预测与规划

[下载代码、模型和精简结果包](chapter3_current.zip) · [文件与模型校验清单](chapter3_current.json)

本交付以第三章为主。第一章 H75 提供地面速度—转向参考调节，第二章 RB 提供跳跃候补；第三章研究**接近方式产生的落地状态，能否被下游控制器接住并继续完成任务**。H75接触OAT仅作背景，未混入第三章统计。论文暂不改写。

## 方法与数据流

已知地图、实测车辆状态和候选路线／速度／α → 上游接口模型预测交回状态分布 → 下游模型结合道路相对状态预测续行能力 → 有限候选选择 → STTW接近、冻结跳跃策略执行 → 首次远岸接触后读取实测状态、允许修改后续路线 → STTW续行。

上游实装为55维紧凑状态／历史／地形／动作特征，TRAIN-only PCA和动作直连，小型集成输出39维交接状态的条件预测及不确定性参数。时间残差版取消“请求速度就是交回速度”的基线。下游使用交接状态和19维道路相对特征，输出接续概率；外推边距是特征，不是安全证明。代码中保留直接分类器和仅状态模型作对照。预测网络已监督拟合；本轮未新增底层技能训练，LLM未接入此闭环。

各批协议独立，不能横向相减解释收益。旧来车已参与开发，均按开发复测解释；旧自动报告中“new independent roots”不能覆盖实际数据角色。

## 模型和代码包含什么

|包内位置|内容|
|---|---|
|`code/learning/`|当前控制、预测、拟合、规划、评估、地形、录制与分析代码；保留不同入口，不把历史选择器当自主规划|
|`models/h75/`、`models/local300/`|本章所用H75权重／配置／路线、Local300权重；当前Playground续接使用ECBC/ESO，未启用Local300残差|
|`models/native_rb/`|Source及原评测登记Run1/2/3完整checkpoint、normalizer身份、正式训练／运行配置；三个主种子8113001/8114001/8115001，对应末轮学生种子8113010/8114010/8115010|
|`models/isaac_rb/`|Isaac Source、301／400／500候补；与原生三个种子是不同模型家族，禁止混称|
|`models/chapter3_*/`|原紧凑上游、时间残差上游、Frenet下游及对应直接／仅状态对照的实际权重、训练曲线和声明|
|`inputs/`、`assets/`、`third_party/`|当前任务／道路／运行配置，原生车体及mesh，使用到的JIT运行时源码；原仓库只读复制|

## 下一步与复核范围

优先修复Playground速度／转向接口及共同起点重复性，再用同样三个RB候补取得可信的远岸交接；不追加大规模训练。Isaac已有完整任务实例继续作为第三章工程闭环证据，接口预测与规划收益仍分别验证。

`MANIFEST.json`逐文件记录来源、包内位置和SHA256；ZIP回读验证每个文件，原生checkpoint核对既有注册表。包内保留原始配置用于审计，异机须按manifest映射绝对路径并准备匹配的Isaac或MuJoCo/JAX环境。**不包含外部SDK、全量训练数据，不宣称新机器GPU复现已经完成。** 源代码版本以manifest为准；代码和模型实际随包上传，不仅给本机路径。
