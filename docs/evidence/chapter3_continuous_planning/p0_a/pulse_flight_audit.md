# 上升触发的横推有多少真正作用在越台飞行中

三墙开发后验证面板中，共有 **1,000 个施加非零横推的不同物理前缀**。其中 **632 个**的 100 ms 横推与主越阶飞行完全错开，**6 个**部分重叠，**362 个**完全落在这次飞行中。632 个完全错开的案例，在横推期间都重新接触了地形，100 个物理子步中有 73 至 100 个检出了接触。飞行以前的推力也可能改变车辆真正起跳时的横向速度。

现稿第 2 页模型描述的原文是 “During ascent, an unmeasured lateral disturbance w ∈ {−5, 0, +5} N perturbs the vehicle.” 归档代码在出现上升速度、满足接近台阶及瞬时无接触条件时首次触发。在车辆仍有效的情况下，它会将世界坐标系 y 向的力持续 20 个 5 ms 控制步。触发后的接触变化不会取消这个力。上述数字审核的是这一事件的实际时序。[原稿](../../../chapter3_paper/MANUSCRIPT.pdf)

|---|---:|---:|---:|---:|---:|---:|---:|---:|
| −5 N | 500 | 0 | 0 | 316 | 3 | 181 | 319 | 265 |
| 0 N | 500 | 0 | 0 | 316 | 3 | 181 | 319 | 394 |
| +5 N | 500 | 0 | 0 | 316 | 3 | 181 | 319 | 272 |

0 N 行的重叠和接地计数指触发后 100 ms 的观察窗。500 个案例实际施力时间全部为 0。非零力的 1,000 个案例实际施力时间全部为 100 ms。限定为飞行后双轮承重且复锁的非零力案例，共 537 个，493 个完全错开、3 个部分重叠、41 个完整重叠。其余真实飞行与未复锁结果均保留。[分组计数，包括各墙布局和复锁子集](pulse_flight_counts.csv)

原始面板取自 veto_fallback 和 veto_fallback_followup 的三种墙布局、100 个起点、五种接近方式和三档推力。81,000 行旧出口与门的评分对应 4,500 个此类组合。每个组合有三条出口轨迹，三条在交回前的 qpos、qvel 摘要一致。主审计只读取其中走原始直行出口的一条。三个墙布局之间共有 1,500 条不同的前缀状态轨迹。相同状态轨迹的触发时刻、施力步数、飞行起止、承重、复锁及窗口内有接触的子步数均逐项相等。整段接触载荷原始数值的字节并非处处相同，连同载荷和接触标志严格按字节去重有 1,648 份记录，它们的计数另列。起点、接近方式和扰动也存在配对关系。[逐尝试明细及原始 XY、接触和施力记录路径](pulse_flight_attempts.csv.gz)

## 时间如何对齐

原论文的 flight 函数先寻找连续无接触子步，再用前后轮几何、台阶位置、离地净空与上升运动识别真正越过台阶的那一次飞行。落地与复锁单列。我们用同一个函数找出主飞行，再回到它使用的同一段 1 ms 子步求交集。每个 5 ms 记录行存的是**截至该行时刻、此前五个子步**的载荷。力在控制 tick n 下发，第一组受力子步记录在行 n+1。同一次飞行中，只保留原函数返回的首、末 5 ms 采样点会向内舍去边界。例如每个推力档按这两个采样点会得到 316 个完全错开、151 个部分重叠、33 个完全重叠。分组表同时保留了这套旧时间网格的计数。接地使用归档的轮/体法向载荷阈值 10⁻⁵ N 与非轮车体接触标记。[审计代码](../../../../learning/cli/chapter3_audit_pulse_flight.py)

## 一个可复查的起点

在单列的 TEST A 起点 1001，RB 采用原右偏接近和原直行出口。三档共同在 3.685 s 触发，100 ms 时间窗在 3.785 s 结束。论文函数报告主越阶飞行从 3.885 s 开始。+5 N 和 −5 N 案例分别有 90 和 89 个受力子步检出接触。图中的圆、三角和方形标记依次表示触发、主飞行开始和双轮承重。底部是两轮法向载荷之和。[实际 XY、施力与载荷](pulse_test_a_1001_xy_force.png) [逐例数值和原始轨迹](pulse_test_a_1001.csv)

MuJoCo 3.6.0 读取该案例的原冻结模型，整车质量为 5.091 kg。若整车严格无外接触，侧向空气力为零，重力仅指向竖直方向，关节力和锁定力均为内力，则整车质心满足 Mÿ = Fᵧ。5 N 力若有 100 ms 全部作用在这种状态中，则在这段时间末，相对相同初态的零力质心直线运动，侧向速度改变 0.09821 m/s，位置改变 4.911 mm。该公式不能给出地面接触期间的横移，也不直接预测基座原点、车轮或随后的过门结果。这里的数字来自对归档文件的 CPU 审计，没有新物理仿真，没有改动原稿。
