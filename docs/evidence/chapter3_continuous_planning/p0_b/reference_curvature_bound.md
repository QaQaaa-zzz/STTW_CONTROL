# 从落稳锚点能否及时切入预定通道

设一段地面参考线沿世界 x 严格向前，起点和终点的前进距离为 L，终点航向与 x 轴平行，且参考曲率的绝对值不超过 K。令 σ 为所需横移的方向符号，θ 为航向角，s 为弧长，u=σ sin θ。以起点横坐标为零。有

\[
\frac{du}{dx}=\sigma\frac{\cos\theta\,d\theta/ds}{dx/ds}=\sigma\kappa,\qquad
u(0)=u_0,\quad u(L)=0.
\]

因此曲线上任意位置都满足 \(u(x)\leq\min(u_0+Kx,K(L-x))\)。若 \(|u_0|>KL\)，单是终点航向条件就不可达。当 \(|u_0|\leq KL\) 且 \(h=(KL+u_0)/2<1\) 时，用单调函数 \(u/\sqrt{1-u^2}\) 积分得到横向位移上界

\[
D_{\max}=\int_0^L\frac{\min(u_0+Kx,K(L-x))}{\sqrt{1-\min(u_0+Kx,K(L-x))^2}}\,dx
=\frac{1+\sqrt{1-u_0^2}-2\sqrt{1-h^2}}{K}.
\]

若 h 达到 1，该测试不给有限上界。对于两端均朝正前方的情形，反解可得：要横移 \(d\leq 2/K\)，向前至少需要 \(L_{\min}=\sqrt{4d/K-d^2}\)。推导的对象是已声明的向前参考线，起止位置和航向都是约束。通道位置、到达时刻和航向条件一旦改变，需要代入新条件重新判断。

按冻结的单一通道规则，K=1 m⁻¹，两张图 288 项中有 226 项记录了落稳接手锚点。其中 9 项超过上界，均为右门，8 项因 h≥1 此式不给有限上界，209 项未被排除，62 项无接手。对右偏墙 1172、−5 N、近右门，参考锚点 x=11.6673 m，y=−0.220 m，初始航向为零。规定在 x=12.450 m 时与通道平行，目标 y=−0.622 m。需要横移 40.2 cm。现有的 78.27 cm 前进距离允许的最大横移为 15.95 cm。若保持相同目标与始末航向，最少需向前 1.203 m，即从目前锚点再提前约 42.0 cm 开始转。就算改用另一种样条，这一组条件仍然不相容。9 项的结论针对该初始通道规格；它们仍可能通过调整转弯起点、通道中心或到达时的朝向完成原始过门任务。
