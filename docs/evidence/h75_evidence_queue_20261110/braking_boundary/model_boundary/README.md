# 参数计算的B、固定状态模型测试与多组正面例子

先看[8个工况实际/原参考XY](XY_OVERVIEW.png)，再看以下相图。所有数值用原H75控制器的名义侧倾—转向模型参数计算，不从成功、失败结果拟合B。此轮选择用户提出的“根据小车参数计算”方案，并补做固定状态的低阶动力学模型测试；**不是重新运行完整Isaac/PhysX车辆碰撞测试**。原始真实轨迹仍来自Isaac。

## 参数推导

源码名义模型：phi_ddot=a1(v)*delta_dot+a2(v)*delta+a4*phi。参数质量5.4kg、质心高度0.2m、前向距离0.164m、轴距0.408m、拖距0.024m、主销倾角0.4363323rad，重力9.8m/s²；侧倾惯量按源码I=m*h²+0.043929*m/5.434。完整参数保存在protocol.json，复用analyze_roll_contacts.nominal_coeff，未重新辨识。

冻结域：v∈[0.5,3]m/s、|delta|≤0.8rad、理想实际|delta_dot|≤3rad/s、|phi|≤0.7rad，暂不含额外接触/外力残差。±3是isaac_path_rollout.py实际输出端命令限制（不是配置里较早的ECBC内部±4）。理想实际跟随是本名义模型的假设，原始碰撞轨迹会违反它，违规比例已逐条保存。

由三角不等式：

$$|\ddot\phi|\le |a_1(v)|3+|a_2(v)|0.8+a_4(0.7) \le B_{model}.$$

本速度域内a1、a2均为负，绝对值随速度增加；最大值在3m/s端点。因此这是端点解析上界，程序的速度网格只是记录计算，并非用有限网格声称证明未知函数极值。角度单位全部先用rad，最后转换deg。

|固定速度|a1|a2|a4|该速度下B上界（°/s²）|
|---|---:|---:|---:|---:|
|1.8|−2.72747|−28.15373|40.76191|3394.13|
|2.3|−3.48510|−47.09451|40.76191|4392.54|
|2.6|−3.93968|−60.67644|40.76191|5093.22|
|3.0|−4.54579|−81.37271|40.76191|6146.05|

**所有实际轨迹图统一取6146.05°/s²**，覆盖声明速度域；不用每条不同实际速度改线，也不因某条结果失败而修改参数。固定v=2.6的5093适用于恒速条件，不直接覆盖实测变速过程。

这给出一个模型内乐观的制动能力上界：允许重力项、转角和转角速度同时最有利，真实执行过程通常达不到。H<0在这套无扰动、理想转向模型假设中排除安全刹住；H≥0仍不保证可恢复。它不是含轮地碰撞、离地和电机动力学的完整物理上界。B越大，H线越宽，这次不为了分出结果而把它缩小。

## 固定初态测试：考虑转角要逐步转过去

预先固定360种初态：3个速度1.8/2.3/2.6 ×5个侧倾角−30/−15/0/15/30° ×8个侧倾角速度±50/100/200/400°/s ×3个转角−0.4/0/0.4rad。速度固定，向停止当前外倾的方向发最大转向速度，转角达到±0.8后速度归零；最长1s。该控制是固定的最大方向制动策略，没有枚举所有可能控制序列，也没有称它是全局最优策略。

用包含delta状态的线性系统矩阵指数精确推进每个恒指令步；1ms与0.5ms各360次，分类一致：190次角速度先停止，170次先越过角度边界，0次超时。停止不是完整路径任务成功，超限也不是全策略不可恢复证明。

同一组最有说明力的例子：v=2.3m/s、phi=0°、omega=+200°/s：

|初始delta|固定制动结果|结果时刻|停止/终止phi|
|---|---|---:|---:|
|−0.4rad|角度超限|0.165s|40.21°|
|0rad|刹住外倾|0.237s|27.25°|
|+0.4rad|刹住外倾|0.111s|11.43°|

所以二维H是一条必要条件诊断线；同一(phi,omega)的恢复过程还取决于转角。后两种测试的停止位移等效B为734和1749°/s²，这些是**由固定初态名义模型试验得到的值**，不是从实际成功案例拟合的值，也不是统一能力上界。

## 正面例子扩展与统一结果

全12工况、五档完整alpha共60条均计算，详见all_full_alpha.csv；其中11条任务C正例，H全程均为正。按预先声明优先顺序[.5,.75,1,0,.25]从每个含C正例的工况选一条，共8个工况；对照固定选full1，若正例本身是full1则对照full.5。这不是新独立测试集。每个图保留对照真实任务标签，即使对照也成功，不改成失败。

完整60条按原结局统计：39条满10s全部H≥0；12条侧倾超限全部曾H<0；9条运行域越界中1条曾H<0。39条满窗只有11条通过C，说明H不能代替路径与速度任务判据。这些是同批已有数据的描述性统计，不是独立预测验证。

主例10cm单脊2.6m/s物理组101：full.5的最小H=23.54°；full1首次H<0在1.940s，1.970s侧倾超限。这比旧B500的报警晚，符合更大制动上界的含义。该时刻也位于此前接触日志定位的后轮再接触冲击阶段。H在本批真实轨迹上的分离是模型诊断一致性，不能自动升级为已经证明包含碰撞的可恢复边界。

**论文故事：** α改变入障状态和速度—转向协同；侧倾角速度及当前转角决定恢复过程与制动需求；某些工况在后轮再接触时需求跃升，超过名义模型所能提供的乐观回正尺度，当前策略随后超限。多组正例则保持正余量，并完成原任务。此轮的贡献是把B从经验数字换成可复算的参数上界，再用固定状态测试说明“当前转角为何重要”。
