## 数学量怎样落到数据

以源码参数计算a1(v)、a2(v)、a4；实际速度和关节角/角速度来自原日志。phi_dot通过刚体四元数及世界角速度做Euler运动学变换，未直接使用IMU x角速度。

z=phi_dot+sqrt(a4)*phi；恢复图比较sqrt(a4)|z|与-sign(z)(a1*delta_dot+a2*delta)。名义维持dot(z)=0的转向速度为-(sqrt(a4)*z+a2*delta)/a1（此处d=0）。图中范围来自真实配置：转角±.8rad，伺服速度命令±3rad/s，转向电机±1Nm。实际转向角速度受接触冲击可以超过命令范围；未把这些线称为安全域或不可恢复边界。

前/后轮法向力与摩擦力按原生count/start索引读取，接触力矩关于质量加权整车质心、投影到负车架x轴。它与绕转向轴的力矩区分；不是已经识别出的地形d。5kHz逐步提取后按5ms保存有效样本均值、最小/最大，峰值没有用单点抽样替代。若画法向/摩擦分项极值之和，阴影是保守包络，不声称两个分项同时达到极值。

## 时刻、任务与终止

灰带：正例前/后轮法向力>1N且接触点世界z>2mm的凸起接触，间隔<=50ms合并；标记精度5ms。对照自身事件见events.csv。绿色线：事件后首次连续200ms满足|phi|<=.18rad、|横向误差|<=.3m、|速度误差|<=.2m/s的入带时刻；若此前未离带，不能解释为新恢复。它是本次时序诊断，不替代原最终保持和任务A/B/C。

原最终保持是最后1s路径误差<=.1m、航向误差<=.05rad、速度误差<=.1m/s且未终止；目标条件沿用原目标截面。距目标锚点仅作辅助，不新设1m目标圈；穿越后继续沿路线前进，距离再次增加不是倒退或目标失格。侧倾阈值终止、越界、未解析终止按原记录标示，不统称触地摔倒。

## 动态公式对照已画，但结论限于局部

[模型对照图](POSITIVE_MODEL_CHECK.png)：每5ms重新以实测phi/phi_dot初始化，使用接下来100ms实测v/delta/delta_dot积分；含接触修正版本用其他两个物理组标定4个法向/摩擦侧倾力矩特征，当前物理组留出。它是实测输入条件下的短窗回放，不是从alpha预测全程。未把同回合侧倾反算的d代回去自证。

|正例|恒侧倾速度100ms RMSE|名义100ms|接触修正100ms|名义500ms|修正500ms|
|---|---:|---:|---:|---:|---:|
|单脊α.5|0.488°|0.415°|0.615°|13.21°|30.03°|
|石子α.75|0.869°|0.849°|0.604°|20.70°|28.41°|

接触修正对石子的100ms回放有帮助，对该单脊正例反而变差；500ms误差已经很大。当前可用于局部诊断，尚不能把它当作准确的长时闭环预测器。不同alpha的频率响应G_alpha、恢复域与频谱反转，本轮没有完成辨识。
