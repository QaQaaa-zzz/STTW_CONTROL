# 高度＋侧推：前两阶段研究结论

先看证据：[高度全部XY](h75_height_scan/RESULTS.md) · [侧推全部XY](h75_force_scan/RESULTS.md)。共192＋672＝864条，原H75＋Local300冻结；这两阶段是熟悉布局DEV，未训练新网络。

**当前最扎实的论文叙述是：越野地形压缩任务可行范围；α改变通过与恢复行为，适合的档位取决于地形、外扰和任务要求。**

## 1. 高度增加把“任务失格”和“提前终止”依次暴露出来

0/5mm时，五档主车道均30/30完整运行并末段保持；10mm为23/30完整、19/30保持；20mm仅6/30完整、5/30保持，A/B/C全部0/30。说明困难不只是停机：5mm下车辆都能走完，但不同任务已经产生明显差异。

5mm石子任务A（窄路径）中α.25为5/6、α1为0/6；任务B（速度更严）中α.25为3/6、α1为5/6。这里存在直接可用的任务条件选档依据，不需要先假设某个α普遍最优。

## 2. 相同侧推在越野地形上更容易引起终止

|世界y侧推|平地完整10s|10mm石子完整10s|
|---:|---:|---:|
|0N|30/30|27/30|
|−16N|30/30|15/30|
|+16N|30/30|16/30|
|−32N|30/30|0/30|
|+32N|29/30|6/30|

均为同速度/物理参数组合的五档主车道汇总；各α不是独立地形重复。实际脉冲全部施加完成。这个对比支持“石子路面使原本可承受的侧推变得难以承受”。因布局与车道接触敏感性，暂不把差值全部归结为拖曳距这一单一机制。

## 3. 跑满10秒不是完成任务

平地−32N虽然30/30完整运行，A/B/C仍全部0/30。应分别报告平衡/未终止、路径与速度任务、末段保持。若只报告存活，会把明显偏离任务的行为算成优势。

## 4. α改变受扰能力，但不是越接近某个端点越好

平地+16N下α1任务A为4/6、α0为0/6；α0的路径偏好权重不等于实际受扰恢复一定最好。石子−16N任务B中α1为4/6，而α.5为1/6。结合5mm窄路径α.25优势，支持针对任务与工况选择档位。

## 5. 重复差异在哪里

高度扫描48对重复中，6对完整标签、7对保持标签不同。侧推扫描平地84对完整/保持均一致；石子84对中分别24/26对不同。差异集中在接触复杂的石子工况。正文保留这些数字，用新布局测试检验选档收益，不据单车道细小差距宣布稳定排名。

高度扫描含全部重复：133满窗、22仅越界、25侧倾阈值、12原因未解析。侧推含全部重复：465满窗、114仅越界、77侧倾阈值、16原因未解析。尚不能给出真实触地摔倒数，不能将全部终止统称摔倒。

## 对论文主线的判断

已经支持：地形难度影响任务可行性；越野地形放大侧推下的失效；α具有任务条件化取舍；Zero不是足够的任务跟踪基线表现。

正在补齐：通道消融解释速度/转向参考各自贡献；新布局测试验证已冻结的任务选档规则是否优于固定档。两阶段不改变已声明的后续选档协议，也不根据这些DEV结果追加训练。完成后才报告选择器实际收益。
