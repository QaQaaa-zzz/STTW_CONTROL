## 1. 前两阶段保留的结论

同布局0/5mm石子，五档主车道均30/30完整运行并末段保持；10mm降至23/30完整、19/30保持；20mm仅6/30完整、A/B/C任务全0/30。

同样−32N、0.1s侧推，平地30/30完整运行，10mm石子0/30；这些主车道都完整施加了规定脉冲。平地−32N的A/B/C也全0/30，说明未停机与完成任务是不同指标。

5mm石子任务A（窄路径）α.25为5/6、α1为0/6；任务B（速度更严）分别3/6、5/6。支持按任务取舍，而非普遍最优α。[详细分析](../FIRST_TWO_RESULTS.md)。

## 2. 通道消融：作用随地形变化

共同起点，各α分别全程使用完整网络、仅速度修正、仅转向修正，底层不变。两地形×两速度×三物理组，每组18车道，共216条。12组执行日志中的通道屏蔽与声明一致。

|地形|完整双通道|仅速度|仅转向|
|---|---:|---:|---:|
|10mm石子：完整10s|23/30|5/30|27/30|
|10mm石子：末段保持|20/30|0/30|26/30|
|10cm单脊：完整10s|16/30|2/30|8/30|
|10cm单脊：末段保持|10/30|0/30|6/30|

每30条＝五α×六上下文，重复车道不计入此表。石子上仅转向整体就能保留较强能力，完整双通道没有普遍增益；单脊上完整双通道更有用。

**最清楚的单脊案例是α=.5：完整6/6末段保持（重复也6/6），仅转向1/6，仅速度0/6。** 支持该工况的双通道协同；不能概括成所有越野任务都必须双通道，也不能说速度通道单独就能抗扰。原高频接触保留在共享batch目录，路径见sources.json；本报告没有把这些行为差异直接归因到某一个接触力学量。

## 3. 新布局选档：收益尚不稳定

四个未参与开发的石子布局×10/20mm×两速度×两物理组，共32上下文、352条。α规则只用高度DEV确定；来源哈希及全部32工况实际α与冻结规则吻合。[冻结规则](frozen_selector.json)。这是未见布局测试，速度、物理参数已见；规则按高度、速度请求和任务从起点选固定α，不是行驶中动态切换。

10mm的16个上下文中：

|任务|对应规则通过|最佳固定档通过|判断|
|---|---:|---:|---|
|A：窄路径|1/16|α.75：3/16|未改善|
|B：速度更严|8/16|α1：9/16|未改善|
|C：折中|5/16|α.75：4/16|仅多1例，收益待确认|

“最佳固定档”是测试后比较五个固定档的参考，不是部署时可调用的先知。20mm下，所有固定档和规则的A/B/C均0/16；换档不能填补当前策略在这个难度下的任务能力缺口。

10mm任务A的规则其实始终选α1；其1/16与固定α1的0/16差别来自同档不同车道，不能称选档增益。任务B在2.3/2.6m/s选.75/1；任务C选.75/.5。后两者是真正随请求变化的规则，但当前任务结果仍不足以采用为优于固定档的选择器。

## 5. 论文该怎么推进

现在可以写：越野地形压缩任务可行范围；α形成可解释的任务取舍；通道贡献具有地形依赖性，单脊中出现明确的双通道配合收益。

当前不把“在线选档普遍优于固定α”作为已证明贡献，也不把20mm失格解释成只需换档。下一步优先利用已有逐步数据解释单脊α.5双通道成功的入障/恢复过程，定位简单规则失效原因；新的选择器方案另行冻结后再测试，本次未自动追加实验。
