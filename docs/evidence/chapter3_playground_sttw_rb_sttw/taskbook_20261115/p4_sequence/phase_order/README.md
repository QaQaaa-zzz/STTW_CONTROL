## 匹配训练协议

从同三个cosine最佳模型及Adam状态各续训1000更新，3e-5余弦降至1e-6；每25更新保存best/last，总预算3000更新、900秒。训练/预测都用约束后的阶段反馈，阶段CE仍监督原始logits，避免被屏蔽类别的固定大损失丢失梯度。其余损失、TRAIN归一化、冻结技能、物理、任务和交回门槛不变。属于监督世界模型续训，0新物理或PPO。

训练结果和行为评测以完成后的trained目录为准；单元测试覆盖不可逆顺序、未约束logits保留及序列化续接。推理补丁/匹配续训分别保存，不混作同一方法。
