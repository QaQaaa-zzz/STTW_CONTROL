## 速度与路径诊断

在每对回合共同已记录时段、且同处phase0或2的样本上，α.5/1相对α0的平均实速变化分别+0.03875/+0.05533m/s；有符号横向误差RMSE的配对差均值分别+0.06146/+0.13851m。它们是同请求速度下的描述性差异，不是已经完成实速匹配的独立α因果收益。

α.5的19个失败中，17个进入目标x窗口且出现路径/航向超限，另外2个在此前退出；α1的61个失败中，28个没有进入目标x窗口，进入窗口的33个均出现路径超限。上述失败在目标x窗口内没有速度门槛超限。各条件可能同时违反多个门槛，计数不互斥，不把这些统计包装成唯一因果证明，也不修改原成功判据。

速度图实线为四元数旋转得到的真实车体前向速度，点线为后轮实测轴速×本车型0.07m；二者不能混称。执行器目标保持实际使用水平航向投影速度，goal窗口诊断按该定义计算。有符号横向法向为(-sin heading,cos heading)，固定原始路径不重定位。本覆盖协议没有奖励定义，不编造奖励曲线。配对基线是冻结H75 α0加ECBC/ESO，不是纯ECBC。
