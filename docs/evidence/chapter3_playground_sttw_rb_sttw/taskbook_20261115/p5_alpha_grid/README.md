## 条件模型接口：已实现，未训练

`HistoryDynamics(alpha_conditioned=True)`在原有速度/参考/髋膝/可选地形特征之后追加阶段α，GRU每步显式接收同一阶段指令。含地形时输入101→102维，无地形26→27维；控制历史初始化、GRU64、128×128输出头和积分保持原结构。`rollout`/`rollout_state`新增尾部可选`alpha_request`参数；`predict_skill_sequence`分别转发`approach_alpha`和`departure_alpha`。这些是预测器输入，不修改冻结H75或真实执行权限。

缺省`alpha_conditioned=False`保留历史权重结构；旧无条件模型拒绝显式α查询，条件模型要求显式α，不静默以0替代缺失指令。条件属性保存在训练contract并由load_history_model读取。旧全链CLI仍是α0流程；非零α全链需要匹配训练后的地面、桥接与跳跃模型，尚未运行，不把API接线当成规划收益。

原prepare/run/train监督入口均支持`--alpha-conditioned`（run读取manifest开关），TRAIN正常化只来自原TRAIN分组，阶段标签来自实际配置及每条记录的continuation_alpha；快照α分支使用实际行标签，不能被父配置覆盖。既有自由phase2预测评测入口传递同一声明阶段α。CLI参数准备不等于训练；当前只有DEV九组合覆盖，未将这些地图改为TRAIN。

行为验证7项通过：原零修正/直接结构/速度语义保持；条件α确实改变预测；10步等于4步＋序列化next_state＋6步，输出逐位一致；带contract的保存加载保持条件输出；旧模型不接受α查询。这里是CPU小型接口行为测试，不是学习能力或GPU吞吐证明。实际训练、三种子best/last和收敛/决策诊断尚未开始。
