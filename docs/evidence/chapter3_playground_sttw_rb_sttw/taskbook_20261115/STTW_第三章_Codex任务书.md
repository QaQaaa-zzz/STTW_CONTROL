# 第三章执行任务书：面向后续任务可行性的单轨两轮机器人跨技能预测与接近规划

2026-11-19 评审定版（依据最新证据包复核回复）。H1–H4 均未获完整验证。本版停止 p3_wide_source 分类器续训、标签/权重/存档搜索，不启动超过 30 分钟的 PPO，不提前接入 LLM。以下五阶段取代旧 P0–P7 的执行顺序；旧编号仅用来定位代码和证据。第一主实验是**同地形换任务的双向反转**。不以跳跃世界模型的接触误差先收敛为开工条件。

## 1. 问题与三章衔接

第一章 STTW 提供地面路线、速度请求和有限偏好 α；第二章 RecoveryBridge 提供原跳跃技能 Source 与恢复增强技能 Full RB 的可比接口。第三章冻结技能，决策“为了远岸任务，沟前如何接近、何时前向跳、落地后怎样走”。地面阶段锁摆，按承重、姿态和控制器就绪状态交回；不停车重置、不凭固定延时切换。沟前后各两米物理平地，其外有越野地形，跳前、跳后均含转弯。不得改变摩擦、控制权限或验收线来凑出反转。区别于一般循迹任务的研究问题是**同一地图、不同任务合同能否要求不同沟前选择**；不把其他论文的能力边界当成本章证据。

## 3. 五阶段路线、产物和推进条件

**Phase 1｜定格动机，定位 RB 交接瓶颈。** 复用 Map 48 原始 5 ms 位姿及已存在的状态/占据图：合并侧倾、航向、转向、世界速度与俯视实际/参考轨迹，标出交回与首次碰墙。只在交回后、障碍纵向邻域内，针对指定墙和各碰撞几何重算最小距离，注明时间、几何对和方法；验证碰撞时刻与接触日志，保留旧统计。Map 48 图标为历史动机，宽沟双落地的正反视频为主物理证据。对原 72 条另出逐例漏斗：主动起跳 → 远岸首触 → 越过远岸与 x>10.8 m → 双轮持续承重（力与时长）→ 满足各项交回条件 → 锁摆续行与保持目标；给 2–3 条代表性 Full RB 失败帧。产物 map48_local_clearance.csv、rb_funnel_diagnosis.md。补核首次接触至实际终止的时间、整车通过远岸唇口、非轮部件碰撞与首触的先后、起跳控制位置及原技能训练域。原 map00 的真实远岸为 10.3+0.3=10.6 m；另报评审指定 x>10.8 m 的进展阈值，两者不能混称。区分物理失稳、接口拒绝和日志未记录项，不能反推未记录的量。交付动机图、局部净空表、双技能漏斗。该诊断与下一阶段用已验证的 Source 建立候选可并行；Full RB 对照须等接口厘清。

**Phase 2｜第一主实验：不训练新网络。** 冻结宽沟双出口地图、技能、有效候选和快照。**2A 前置门禁：**在 0.45/0.55 m 两种宽沟用冻结 Source 同期做有界筛查，GPU 批次串行。覆盖左/直/右或弯道偏置、已验证 1.8/1.9 m/s 和触发提前量；各自保持原接触配置，沟宽比较不称单因素实验。同一完整快照下至少两条不同实际前缀各自真跳、承重、锁摆交回，并记录 y、航向及复跑差异，确认分离可重复，再冻结产出可靠的一档地图和候选子集。已有 0.45 m 的单例回交与 0.55 m 的单例回交不能跨图配对。**2B：**从每一条真实交回快照分叉同一组左/右/直行驶离。对同一物理轨迹按左右必经检查点两份合同计分（若合同改变控制指令，真实执行对应分支，不复用错配轨迹）。表按地图、初态、T 组、任务、接近、驶离逐格记录真跳、承重、交回、检查点、禁区、终点保持与失败时刻。禁止把前缀失败重复数成多次独立物理失败。

T 从实际交回到固定障碍或任务决策截面的首次到达；未到截面记缺失并保留失败。以约 0.7/1.2/2.0 s 为开发设计目标，冻结后报告实际分布。所需横移由整车外廓计算；比较质点尺度 vᵧ₀T + ½aT² 与计入响应延迟的 vᵧ₀T + ½a[max(0,T−τ)]²；a、τ 由开发轨迹估计，二式均不是可达性证明。每档内仅交换任务合同，移动实体墙另列实验。首个交付是 oracle_task_reversal.csv、正反两条视频和实际/参考 XY；近/中/远各报告反转、两边皆可行、两边均不可行及候选覆盖不足的数量。在同一 (map, root, T_bin) 中，对每条合格前缀取穷举后缀的存在性向量 (Left, Right)；须同时出现 (1,0) 和 (0,1) 才计双向独占反转。不合格前缀单列一次，不展开成六次失败；未运行项写 NA。每档列总根数、反转、单向分化、两前缀皆可通用、皆不可行及候选不足。近中远须报告实测；跨新初态/地图复验，不据 TEST 胜负重划档。若覆盖充分后所有合格前缀都可在落地后改道满足左右任务，则记录 H1 的边界，转向落地后动态避障预测与修正。

**Phase 3｜隔离误差，再验证沟前规划。** **3A 零新训练，直接复用已有地面 phase2 / HistoryDynamics。** 2A 首次取得合格快照即准备配对输入；给②③同一真实交回状态，诊断地面短窗预测，不给在线规划器读真实未来。①训练标称交回＋几何占据；②按接近预测交回时刻、位姿与速度，运动学展开整车；③ C 传递动态状态（含侧倾、角速度、转向与必要控制记忆），沿实际闭环预测关键窗口的扫过占据。接口 initialize → rollout → next_state；全关节/接触的现有实现保留，是否增加复杂度以它能否纠正具体规划错误为准。最终按同预算比较①②③、C-R、强回溯，真实 Oracle 仅作离线上界。C-R 只在稳定交回时用实测状态更新未执行后缀，不打断控制。在未见布局逐例记录无计划、误放行撞障/超时、误拒、整程完成、墙边净空、查询次数/耗时；比较相同或交叉裕量。寻找交回位置/航向/速度接近但转向/侧倾动态不同的真实正反例。**3B 门禁：**只在 3A 显示③相对②有清晰的逐例净收益后启动完整跳跃状态预测训练。先建稳定交回发生率及其动态状态分布的预测器；冻结物理域，TRAIN/DEV/TEST 分组且有足够交回正例。若无收益则记录边界和假阳性/假阴性，不用训练绕过门禁。

**Phase 4｜量化前两章贡献。** 先验证冻结域每档 α 有可执行交回样本，再同条件比较阶段固定 α=0/.5/1、只选速度、联合选速度与 α，并匹配实测速度。对冻结 Source 与完整 RB，各用同预算采集与匹配预测器，在同入口、同起跳/空中扰动、同物理及交回协议下评估。输出两份配对表，分解交回、存在可行后续、选中、整程通过；保留负结果。

**Phase 5｜冻结后重配置。** 只改检查点、目标、禁区或时限，验证同图无需重训的任务重配置；新物理布局泛化单独报告。最后接轻量语言接口：自然语言转结构化合同，以 JSON Schema 约束合同；比较规则、无物理反馈 LLM、带 no-plan 拒绝日志反馈 LLM，分别报告解析正确率、硬约束保持率、整程完成率、查询延迟；仅在授权范围调整软约束，不下发扭矩、不修改硬约束，记录解析正确率、任务完成与延迟。

## 4. 此轮停止投入什么，下一项产物是什么

真跳、锁摆和完整快照可复现是必要工作，已核验的版本直接使用。**当前优先级错误是用接触分类器的漏报和更多存档代替了任务反转实验。** 已经在跑的有界批次收取结果即止；不再开新标签、权重、几何近似或 PPO 扫描，不等 P3 数值变好再做 Phase 2。下一项按顺序交付：①现有材料补齐局部净空和原 RB 漏斗；②合格双交回前缀清单及首张左右任务矩阵；③再做真实交回状态上的②/③对照。单次长等按用户约定通知；超过半小时结束等待，保留已授权后台任务。
