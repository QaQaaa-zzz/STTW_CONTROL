# P0 重验：主动起跳、跨沟与落地

[同一快照的实际/参考XY和车身高度](paired_xy_height.png) · [新跑的0.55米跨沟侧视录像](rb_run1_route2_h75_v1.mp4) · [逐帧动作](jump_filmstrip.png)

完整RB在开发地图上从近岸主动起跳，可以在空中跨过0.55米沟。该完整RB样例随后落地失稳。原始Source另有实测后轮蹬地起跳、远岸落地及回交后骑入目标区的连续录像，末端保持超时。

**新物理记录。** 固定路线7的小批试验后，在同一张加宽地图冻结36个交接前快照（9路线×两初态×两速度）。第2路线、v1变体的RB与锁摆分支在3.0秒时位姿、速度、地面控制历史、RB历史逐值相同。RB提示延后0.15米时，轮胎与车身地形支撑载荷连续消失618毫秒。有效无支撑位姿从5.325秒至5.935秒；初段整车质心竖直速度约+2.58m/s，质心上升0.353m。以两轴中心中点位于沟上方的时段统计，两轮碰撞椭球下缘相对岸面的最小净高0.207m。开始时前轴x=10.196m（近岸边缘10.30），结束时后轴x=10.879m（远岸边缘10.85）。空中末段侧倾28.0°、俯仰−37.3°，5.980秒时侧倾42.1°触发物理终止。没有STTW交回。锁摆分支36例均未接触远岸。视频以0.5倍回放保存位姿，终态定格1秒。

**旧录像更正。** 地图48的shared225两条旧记录，在沟上双轮与车身无载最长均为7毫秒，卸载前车身向下运动，持续段无车身升高。历史goal只保留为旧统计。[旧案例与完整RB的轮心路径及实际XY](comparison.png)。独立启动的锁摆复测两例均物理终止，存在跳前轨迹微差；上段36例改为完整快照配对。

**协议。** 0.55米沟为新开发难度，近远岸各保留2米平地，沿用地面转弯、冻结H75、1ms物理和已记录的终止条件。测量入口为 `learning/cli/audit_playground_jump.py`。位姿每5ms一帧，接触力每1ms一帧。对正向飞越使用保守的完整轴距条件，分别记录起跳、空中跨过两岸、远岸接触、双轮支撑、回交和最终goal。未满足完整轴距条件的轨迹需按具体动作解释。此轮为已知地图的工程诊断。

逐例载荷与仿真状态保存在数据盘 `chapter3_playground_sttw_rb_sttw/active_jump_rebuild_map48/`。宽沟配对分支按 `wide_map00/paired_snapshot/plan.json` 执行，每组完整结束后生成 `jump_validation.json`。

**完整RB同快照复测。** 每设置9路线×2初态×2速度，共36例。锁摆、原提示、提示延后0.15m、延后0.25m的完整空中跨岸数分别为0、0、1、0；远岸接触分别为0、8、21、6；双轮支撑并稳定交回、最终任务完成均为0。144个方法条件共用36个快照。[逐例记录](wide_gap_cases.json)。

原始Source提前到x=8.35m交接并使用最高点关闭提示时，第6路线v0在5.825s前后由后轮从近岸蹬离地面。前轮轮心此时已经越过近岸边缘约6.6cm。起跳前后轮载荷峰值约262N，随后轮与车身连续卸载606ms；质心初始向上2.63m/s，升高0.372m，沟上两轮最低净高0.110m。6.885s前后轮同时在远岸承重（约128N、145N）；7.030s交回锁摆STTW，9.685s进入目标区，10s时到达x=17.078m，y=−0.100m。按控制器的5ms计数保持0.320s，合同要求0.500s，终止原因timeout。原先登记的“起跳时前轴仍在近岸”严格指标此例为0，另列后轮从近岸承重起跳的证据。视频从3s实测快照开始，两段连续，无重置。

同36例的空间提示对照提前交接时，Source有8/36满足原先严格空中跨岸判据，其中2例远岸双轮同时承重，最终0/36。第7路线v2腾空660ms、质心升高0.437m，6.340s双轮接地时车辆已转至168°航向，随后侧翻。启用最高点关闭提示时严格空中跨岸8/36、其中双轮远岸承重1例；上段成功回交的后轮起跳样例单列。异次GPU物理重复中，部分轨迹在最高点前已出现数值差异，不能仅凭两次的成功数差给输入信号作因果归因。

轮地接触移植诊断每种4例，原接触/原生轮胎接触对的远岸接触0/4和2/4，整程均0/4。按原训练几何触发位置测试冻结完整RecoveryBridge Run 1与Run 2，各36例各14例触及远岸，严格空中跨岸和最终目标均0。原模型在各自原协议的历史成功率不用于第三章宽沟。新评测沿用10s、已验证的1.8/1.9m/s与终点连续保持条件；保存每组运行合同、实际CLI、完整失败数据与Bark退出回执。
