# 粗糙高台真实交回后的预测对照

[实际 XY 和两种预测](xy.png) · [逐根误放行和误拒](per_root.csv) · [逐条 XY 误差](xy_errors.csv)

在同一张开发地图的 32 个真实交回状态上，各实际执行三个驶离，共 96 条物理后缀。按近、中、远截面与左右任务评分，共 576 项合同。两个预测器从同一实测交回起算，使用该次驶离实际发布的参考线、同一台上终点和车体碰撞外廓。动态模型沿用既有 residual_seed2 的 best.pt（update 575）；原地图 06/07 校准的共享裕量直接迁移。预测输入的高台地形从碰撞模型测得，墙体另行检查。此项评估检验原地面预测器在高台上的迁移表现。

| 技能及共享裕量 | 合同正 / 负例 | 运动学误放行 / 误拒 | 动态模型误放行 / 误拒 |
|---|---:|---:|---:|
| Source | 81 / 207 | 3 / 45 | 0 / 72 |
| Full RB | 90 / 198 | 0 / 54 | 0 / 81 |

共享裕量下，两种预测器均检出了 Source 的 3/3 条真实碰墙以及 Full RB 的 5/5 条真实碰墙。动态模型对两种技能分别多拒了 27 个可行合同，仅在 Source 上少放行了 3 个失败合同。零裕量下，运动学与动态模型分别漏掉 Source 的 1/3 与 2/3 条真实碰墙，在 Full RB 上均漏掉 4/5 条。从这些开发结果无法建立启动跳跃状态预测训练所需的净收益。[两种裕量和全部计数](comparison.csv)

XY 误差按 0.24、0.5、1、2 s 计，只覆盖仍有实测轨迹的时刻。同技能、同接近、同驶离和同任务截面内列出初态不同、整程结论相反的配对。以位置 0.1 m、航向 5°、速度 0.2 m/s 作为描述性排序尺度，同时列出侧倾、转向和转向速率差。[逐对实测与预测](opposite_outcomes.csv)

物理前缀、交回快照和原始预测保存在 platform_test0_20261120/approach_alignment/rough_oracle，预测在 ground_predictions 子目录。技能间共用 8 个开发初态；对每条真实驶离重计六份合同。

Full RB 的初态 1 和 7 构成一个实测正反例。两者均为右接近、直行驶离和远档右任务，交回位置相差 2.25 mm、航向相差 1.51°、前进速度相差 0.064 m/s。初态 1 完成任务，初态 7 失败；两种预测器在共享裕量下均拒绝两条。侧倾与转向角的差分别为 0.26°、0.67°，这对样本不能单独确定成败原因。
