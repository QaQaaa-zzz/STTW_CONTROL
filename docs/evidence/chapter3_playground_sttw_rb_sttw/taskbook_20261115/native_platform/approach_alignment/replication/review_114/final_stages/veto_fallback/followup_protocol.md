# 两批顺序执行
第一批维持原冻结合同，初态 1071–1120，3 图 × 3150 环境 = 9450 条物理轨迹。结束后核实两组前缀、准入、实际切换位置；按同一接近下三出口的物理结果区分可避免和现有出口均无法避免的否决碰撞。
第二批使用 1121–1170 独立初态，同三图、R9、15/15 ms、两组、三档推力、三个左门及 9450 条物理轨迹。第一批达到原采用判据时按原 30 根保底库复制。未达到且仍有可避免的保底碰撞时，仅将已揭盲第一批的同批出口观察加入保底库，增加到 80 个校准初态，原 30 根接近先验、5 邻居和支配投票、裕量与控制器不动。第一批未通过且保底剩余碰撞均无替代出口时结束，不重复运行同类实验。两批单独按初态聚类统计，不择优、不合并作为独立证据。
每批采用标准为碰撞率差的配对 95% 上限低于零，通关率差的下限高于 −5 个百分点，准入与前缀保持一致。共享 GPU 锁逐任务获取。任何执行异常记录并通知，全部完成自动生成 RESULTS.md 与 Bark 回执。
