# 全部出口被否决后的保底选择

[错位双墙的实际与参考 XY：避免碰撞、丢失通关和三出口均撞墙各一例](development_xy.png) · [图中轨迹索引](illustrated_cases.json)

原有 R9 扩库组在 810 个左门任务中出现 75 次否决后撞墙。同一已选接近、同一已测交回前缀和完整三出口的物理轨迹表明，左偏墙的 8 次中有 5 次可用另一个出口避撞，错位双墙的 67 次中有 35 次可避撞。其余 35 个合同三个出口都实撞。这里按任务合同计，同一运动在多个门截面可以重复计数。

|开发样本，每图 270 项|原保底通关 / 撞墙|第一版通关 / 撞墙|第二版通关 / 撞墙|
|---|---:|---:|---:|
|左偏墙|78 / 8|48 / 9|74 / 7|
|右偏墙|189 / 0|189 / 0|189 / 1|
|错位双墙|94 / 67|75 / 51|91 / 56|
|三图合计|361 / 75|312 / 61|354 / 64|

第一版在当前墙布局和接近曲线上取交回状态最接近的五个历史样本，先按三出口的实际碰撞票数、再按指定门的整程通关票数排序。第二版只有在另一出口碰撞票数严格更少、同时通关票数不少于原保底出口时才换道。两版均在全部出口被预测否决后才调用；查询通过的选择保持原逻辑。状态由车体位置、姿态、转角和速度构成，运行时不读取推力标签、初态编号或该次轨迹的未来状态。

逐根留一物理分支回放覆盖全部 30 个开发初态，旧选择的交回前缀、碰撞和成功标签逐项复现；新选择与同批已实际执行的分支按接近、α、截面和推力对应。第二版共改动 53/810 项，少撞 11 项，少通关 7 项。按初态配对重采样，碰撞差为 −1.36 个百分点（描述性 95% 区间 −2.84 至 +0.12），通关差 −0.86 个百分点（−2.35 至 +0.12）。同一组结果参与了规则迭代。

独立在线复验使用相同三图上的 50 个新初态 1071–1120、原速度、原模型、原裕量和 15/15 ms 物理时延，两臂每图各 450 份任务。实际任务、同批三出口分支和至少 1024 的并行约束已经组入 3×3150 的预算。新初态结果待收取；本轮覆盖已校准墙图上的初态泛化。
