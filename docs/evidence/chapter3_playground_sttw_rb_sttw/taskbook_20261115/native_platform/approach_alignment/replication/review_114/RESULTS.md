## P3　在线 C / C-R 与两技能的系统比较

[冻结运行协议](online_protocol.json)。两图使用同样的 30 个预留根 464–493，未进 P1、P2 或预跳预测标定。条件为 0、+5、−5 N，首次真实上升卸载时施加世界横向推力 0.1 s。每个物理条件并行执行固定任务规则、标称交回、连续条件预测 C、一次实测交回重选 C-R 和九种物理候选。标称规划采用每接近一个代表交回；C 在起步时从当图 70 个校准根的初态中取最近五个，形成经验交回分布；二者使用同一运动学预测候选表。C 与 C-R 的起步计划相同，前者只记录交回查询，后者可以更改驶离。遇到无预测可行候选仍按统一风险顺序执行，记录预测否决与实际失败。交回实时使用该时刻的实测物理状态重新预测三种驶离；每次批查询记录墙钟，仿真时钟在计算期间暂停，不能据此宣称满足实时时限。

最终统计按布局、根、合同、扰动和技能进行配对，比较真跳交回、可解上界、实际通关、撞障、救回及误改损失；相同 qpos/qvel 前缀才计 C 与 C-R 救回。保留不同扰动的实际力作用步数。按照既定规则，净救回不足时将 C-R 降为辅助消融。全批原始轨迹与评分保存在 review_114/online。速度匹配的 α 消融与独立盲测后置。

## 对第三章的取舍

把跨布局的任务条件选路作为 H1 主结果，固定规则作为强基线。每个在线方法都执行 2160 个指派合同：固定规则完成 873、撞墙 165；C 完成 717、撞墙 60；C-R 完成 718、撞墙 32。C-R 相对 C 净救回 1 个合同，达到既定降级条件，作为减少撞墙的辅助消融。预跳规划对壁障更保守，同时少完成任务，当前数据不足以主张在线方法普遍优于固定规则。Full RB 与 Source 同用 C-R 时多完成 120/1080，保留新右切线的显著退化。α 实速匹配与独立 TEST 仍未验证。

每个 ±5 N 组各 3960 条轨迹，全部实际施力 20 个 5 ms 控制间隔，无扰组 3960 条均未施力。Full RB 为原归档高成功率 R9 rb_run1，seed 8113001，transition_128000；本批运行声明中的 actor SHA-256 为 c3eae39c7c116d5db56122d5aff4f29a6f95b8971a51c4c46864754ecb58b040。
