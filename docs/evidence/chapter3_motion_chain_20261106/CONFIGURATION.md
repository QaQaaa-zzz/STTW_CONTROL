# 当前模型、仿真与控制详细配置

本页对应完整22秒复杂链的单次名义DEV结果；不是所有历史训练的通用配置。机器可读原值见 [protocol.json](protocol.json) 和 [configuration](configuration/)。

## 物理模型

|项目|实际配置|
|---|---|
|平台|原RecoveryBridge完整带摆双轮车；不是Go2，也不是原STTW车加摆的早期重车|
|总质量|5.091 kg|
|轮半径 / 全宽|0.07 m / 0.05 m|
|车轮接触表示|每轮21圆柱组合圆角轮；由运行代码替换导入车轮碰撞形状|

[导入URDF及其网格](physical_model/)保存质量、惯量、关节轴、关节范围和初始几何。实际运行还叠加 `IsaacLabVectorPlant` 的21圆柱轮、接触材质及执行器处理，因此不能单独加载URDF后就假定与结果完全一致。URDF中1000的effort/velocity是导入上限，不是实际伺服力矩配置；执行器实现与运行配置共同决定实际输出。模型来源见 [model_config.json](model_config.json)，实际碰撞记录见protocol。

## 仿真与控制频率

|层级|周期|频率|关系|
|---|---:|---:|---|
|PhysX物理积分|0.0025 s|400 Hz|全任务统一，包括地面、跳跃及落地|
|地面ECBC/ESO控制|0.005 s|200 Hz|每次底层控制推进2个物理步|
|H75中层策略|0.02 s|50 Hz|每次中层更新覆盖4个底层周期、8个物理步|
|跳跃策略|0.02 s|50 Hz|策略目标保持，执行器随物理过程作用|
|交接监测主循环|0.005 s|200 Hz|地面非跳跃阶段入口按0.02 s批块推进；不是每个阶段都逐0.005 s记录主轨迹|

22秒共8800物理步。H75与跳跃在同一物理实例中顺序交接，没有切换仿真步长或重置车体状态。早期简单链使用0.005 s物理；当前起伏复杂链改为0.0025 s，不能混写为同一运行配置。

## 控制器、网络与交接

|项目|配置|
|---|---|
|地面底层|ECBC＋ESO，zero_lower=true；本次没有Local300残差输出|
|ECBC/ESO|wc=8、wo=10、disturbance_filter=8；最大转向角速度4 rad/s；参数完整见configuration/ecbc_controller.json|
|H75|原actor_0077.pkl的冻结权重精确转换；本次alpha=0.5。H75网络/观测/归一化等见ground_policy_config.json|
|跳跃|原Phase U初始化后Isaac适配的update2，不是未经适配的原RB学生；身份、训练来源、映射及哈希见jump_policy_identity.json|
|跳跃网络|身份记录：Actor 76→256→256→256→8，Critic 106→256→256→256→1，SiLU；输出到4维控制目标的映射由现有TorchPendulumSkill处理|
|跳跃转向增益|kp=2.5、kd=0.4|
|地面接近请求|2.0 m/s，地面阶段锁摆；锁摆为关节制动约束（半游隙1e-4 rad），不是有限电机力矩保持|
|进入跳跃|位置门槛x=6 m后同车释放摆，冻结跳跃策略接管；平台前沿x=7.6 m|
|落地过渡|双轮接触/姿态连续稳定1 s后恢复速度，目标1.5 m/s、加速度0.8 m/s²；实测速度≥1.2 m/s后锁摆并交回H75＋ECBC|

当前评估使用固定名义条件，没有把随机化训练称为随机化评测。既有Go2式训练随机化配置仍保留在训练代码中，本轮0优化更新，不声称本轮重新训练或完成鲁棒性验证。详细路径、初态依赖、策略哈希、空间几何和通过标准以config/protocol为准。
