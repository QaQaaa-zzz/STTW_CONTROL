# 三臂固定末端结果与路线决定

2026-10-24；单训练种子DEV，最终77固定checkpoint，不选中间最佳。当前研究事实同步到共享台账。

## 本组为了检验什么，具体怎么做

问题是：近似容扰物理信息能否帮助现有α中层，在相同训练量下比普通PPO及同容量通用特征实现更多真实防摔？

三臂都从同一H75父模型开始，冻结local300，保留原V3奖励与原参考修正权限、160个真实低速TRAIN状态、19200保留锚点、相同扰动采样和随机种子。各2次critic预热＋75次PPO；普通组已完成的25次PPO经身份/Adam/RNG认证后复用。物理与通用特征各增加六维、768个参数，新列零初始化；同一27更新边界明确重置完整物理bank，优化器连续恢复。

新增13,369,344个策略转移、53,476,115个训练lower ticks，在声明上限内。四个固定最终模型（含H75）评测880例、1,350,351个新增评测lower ticks；原物理/参考/奖励未改变。每策略/α/路径/速度内部从同一完整前缀分支不同力，跨策略的前缀状态可不同。保存了全部220上下文的四模型XY、真实终点、逐控制步奖励与有符号分项。

## 完整结果

下表仅受扰案例；每个低速面板每模型80例，另外各20例零力。原速度名义面板每模型20例。所有模型三个面板的60个名义案例都完成原任务。

|面板|模型|完整无触地|触地|UNKNOWN|原任务通过|
|---|---|---:|---:|---:|---:|
|原低速/原几何|H75|30|10|40|7/80|
|原低速/原几何|普通PPO|30|9|41|7/80|
|原低速/原几何|物理特征|30|9|41|6/80|
|原低速/原几何|通用特征|30|9|41|8/80|
|新低速/新几何|H75|40|0|40|9/80|
|新低速/新几何|普通PPO|54|0|26|17/80|
|新低速/新几何|物理特征|46|0|34|12/80|
|新低速/新几何|通用特征|52|0|28|20/80|

原低速面板三新模型的物理标签逐工况相同。相对H75少的一次触地变成UNKNOWN，零个“触地→完整无触地”。新几何没有任何模型观察到触地，改善是UNKNOWN减少/完整任务观察增加；不能把这些数量直接写作真实摔倒率下降。

物理特征相对普通PPO，两个受扰面板的任务配对分别0改善/1退化、0改善/5退化；相对通用特征分别0改善/2退化、0改善/8退化。新几何物理特征的完整无触地数量也低于两个对照。本次结果不支持这组六维表征的额外收益，也不支持“再加一点同类特征就能获得方法贡献”。它不证明所有物理先验或更充分训练都不可能有效。

## 已有偏好功能是否还在

原速度名义面板的弯道RMSE按四个相同工况平均，下面只摘要α端点；完整五α逐例、覆盖tick与真实轨迹保留在原报告。没有把这些相关工况当独立训练重复。

|模型|α=0速度RMSE m/s|α=1速度RMSE m/s|α=0路径RMSE m|α=1路径RMSE m|
|---|---:|---:|---:|---:|
|H75|0.36655|0.04751|0.11992|0.32975|
|普通PPO|0.35197|0.05216|0.12384|0.31565|
|物理特征|0.36371|0.05990|0.11973|0.30984|
|通用特征|0.36321|0.05400|0.12224|0.33135|

速度优先端点保持更紧的速度跟踪并容许更多弯道路径偏离；路径优先端点允许更明显减速。部分中间α路径误差小于α=0，不声称严格单调或完整Pareto最优。低速两目标较容易兼得，不能强求同样的冲突关系。训练后的偏好功能没有整体消失，但“物理特征带来额外抗扰”的联合增量没有得到支持。

## 去留与下一步

1. 停止当前六维物理特征的继续加训/改T、γ、阈值；不采用它替换已有策略，不启动新种子三臂大重复来追赶本次负结果。
2. 保留普通PPO为后续候选基线：新几何任务配对H75有8改善、0退化，原几何3改善、3退化。它是开发证据，尚未证明实际接触减少或独立复现；原H75仍保留。
3. 大量UNKNOWN仍限制真实防摔阈值的辨识。若专门补物理观察，必须对相关工况全部模型使用同一域退出后hold-last-reference合同，保留原标签；该合同改变不能记作学习收益。旧4s其他Actor结果不能替代本次10s结局。
4. 转入已获授权的A3问题检验：首推后多快、在哪个方向恢复再次抗扰的能力，以及原参考权限能否改善这个过程。先复用[既有60例双脉冲的零新增仿真分析](../../../../runs/repeated_disturbance_recovery_reuse_v1/REPORT.md)，再根据可控性缺口声明小实验。它必须最终回到完整α中层的控制收益，不能只测预测精度。

没有因此开展B2/B3/B4或实机部署。实机尚未运行；RA-L目标未完成。Scientific Agent Skills的critical-thinking/experimental-design用于区分实测结果、替代解释、实验单位与路线决定，非独立人类同行评审；分析工具引用见[贡献讨论](CONTRIBUTION_DECISION.md#分析工具引用)。
