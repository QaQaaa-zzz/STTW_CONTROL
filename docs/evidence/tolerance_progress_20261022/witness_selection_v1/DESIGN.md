# 恢复见证筛选是否有额外教学价值？

当前教学收益还缺一个关键对照：成功轨迹模仿本身也可能带来提升。此实验比较同样10条示范的“原策略失败→干预成功且回报提高”筛选，与从成功干预轨迹中随机选10条。只用已声明TRAIN的72+168例数据；34条非零扰动speed_off成功轨迹，10条满足见证规则。

三组配对：优化seed918501/918502/918503；随机选择seed923501/923502/923503预固定。随机组实际分别含3/1/3条有效见证，全部保留，不重抽更有利子集。每组从同一u325开始，400次Adam、3e-5学习率、四组各128帧、相同control/nominal保留数据。intervention组均1000帧；tail长度受两个采集窗口不同而变化，保持现有逐帧采样和等组权重，不宣称所有原始帧数完全一致。三组是优化/子集重复，不是独立环境重复。

双方使用相同已采集240例，466564lower ticks共同计入；另有共同继承nominal锚数据成本，466564不是全历史总成本。此次数据准备0仿真、0训练，不宣称节省采集。保留两个来源的声明/结果SHA及每条教学源SHA；数据manifest保持TRAIN角色，未导入DEV轨迹。

六套数据与训练声明已准备，尚未训练；当前75PPO及其固定评测不改变。拟在启动前冻结相同DEV评测，优先强扰动、无扰保留和低速困难集，固定最终400更新；不按最佳点筛选。若见证组不优于随机成功组，就不能把提升归因于见证筛选；若改善，仍需更广状态和独立场景验证，并与额外PPO作成本说明。此对照检验经验恢复集合差的教学作用，不能证明解析公式有益。

准备脚本在原run目录执行，拒绝覆盖已有六套数据；本目录脚本是原始执行脚本副本。实际数据保留服务器runs/preference_witness_selection_v1，原始历史数据不改。
