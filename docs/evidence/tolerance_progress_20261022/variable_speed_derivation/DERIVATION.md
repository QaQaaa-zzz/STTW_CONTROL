# 变速时，原容扰度坐标需要补什么？

本节核对的是本仓库简化模型及其坐标变换，不是新颖性主张，也不是实车安全证明。来源：`controller._system`、`tolerance_state_features.unstable_features`。符号和冻结极限由同目录verify.py实际验证。

## 1. 固定的假设与单位

记φ为侧倾、ω=φ̇、δ为实际转向角、u=δ̇；v为控制器使用的后轮速度代理，不偷换成真实车体速度。令I=m h²+0.043929 m/5.434，λ²=mgh/I，固定几何和质量时λ不随v变化。在未激活m₂幅值下限的区间，模型为

\[
\dot\omega=a_1(v)u+a_2(v)\delta+\lambda^2\phi+d+\gamma F,\qquad
 a_1(v)=-\frac{mah\cos\theta}{LI}v,\quad
 a_2(v)=-\frac{(mhv^2-ma c g)\cos\theta}{LI}.
\]

此处c是trail、L是wheelbase；d为剩余模型扰动，F为另行分离出的外力，避免把同一个F在d和γF中重复加入。ESO输出d̂可能包含外力响应，其误差必须留在残差中。当前中层输出参考修正，并不能任意直接指定这里的u。

原坐标为z=ω+λφ+a₂(v)δ/λ+d̂/λ。z的单位为1/s（角度按无量纲处理）。原式冻结v、d̂且忽略估计误差时：ż=λz+b(v)u+γF，b=a₁+a₂/λ。

## 2. 速度变化时的精确坐标恒等式

对上述**简化模型**求导，得到

\[
\boxed{\dot z=\lambda z+b(v)u+
 \underbrace{\frac{a_2'(v)\delta\dot v}{\lambda}}_{r_v}
 +\underbrace{\frac{\dot{\hat d}}{\lambda}+d-\hat d}_{r_d}
 +\gamma F.}
\]

λ是常数，因此本模型没有λ̇项。若以后使用随工况变化的λ，则必须重新求导。m₂下限、速度下限处须按分段函数处理；此次160条轨迹所核区间未激活m₂下限。

rv不是新发现的物理外力，而是随速度变化的坐标系求导项。也可保持a₂(v₀)不动定义坐标z₀，此时不用速度导数，但会出现(a₂(v)−a₂(v₀))δ，以及输入系数a₁(v)+a₂(v₀)/λ。两种写法只是坐标选择，不能把改写本身当成新控制方法。

## 3. 能量式可以如何推广，以及为什么还不够

若未来速度轨迹v(t)和残差r(t)=rv+rd已给定，终点z(T)=0要求

\[
z(0)+\int_0^T e^{-\lambda t}(r(t)+\gamma F(t))dt
 +\int_0^T e^{-\lambda t}b(v(t))u(t)dt=0.
\]

定义η为上式前两项，Wv=∫₀ᵀe⁻²λt b(v(t))²dt，则在标量、无限幅、无额外状态约束的问题中，最小L₂控制能量为η²/Wv（Wv>0）。若仅考虑|u|≤umax而无其它约束，则可达条件是

\[
|\eta|\le u_{max}\int_0^T e^{-\lambda t}|b(v(t))|dt.
\]

**这些都是给定未来轨迹/残差后的条件式。** 真实v、d̂与闭环控制相关，不是独立可任意预先指定的输入；转向角限幅、轮胎/动力学、路径与末段速度要求仍未被这个一维条件覆盖。不能用实际未来轨迹计算后，把结果称为在线预测。它也不是冻结local300+中层参考控制器的能力认证。

冻结v、r=0时回到旧W与脉冲K，因此旧公式在原假设下没有被推翻。补项不需要重新调E_b来掩盖，是否提高预测必须另用未见数据验证。

## 4. 已有轨迹上的量级检查

对两个TRAIN获取面板control/speed_off共160条非零力轨迹，使用实际未来轮速代理和实际转角，对干预窗口中的

\[
 S_v=\int e^{-\lambda(t-t_0)}\frac{\delta(t)}\lambda\,d a_2(v(t))
\]

作中点离散积分。144条窗口完整；其|Sv|相对旧的√(E_b W(v₀,1s))标度，中位数约0.1817，最大约0.9532。**分母是旧经验预算标度，不是物理安全上限**。源SHA、逐条值和窗口完整性均在verification.json。

这说明速度冻结近似在这些记录上不是严格零项；不证明补项可以改善成功预测。ESO导数和模型误差尚未重建，160条包含同前缀的相关分支，量级也受离散求积影响。不能把这个比例当准确误差率或安全余量。

## 5. 对研究路线的实际决定

- 不立即给奖励加rv，不在本轮续训中改变公式或奖励，训练长度对照继续保持单变量。
- 不再期待同一前缀的单个冻结风险值独自区分“保留减速修正”和“取消减速修正”的未来结果。若用于干预选择，模型必须显式考虑干预及其闭环后果。
- 容扰度主线优先采用指定策略/偏好/扰动下的实测恢复集合；在同完整状态上验证干预能否增加成功见证，再检验教学效果。解析量作为可能有帮助的解释或特征，贡献由对照决定。
- 下一步如果试修正式，先做短预测模型与旧式、纯数据方法的冻结比较；不使用真实未来轨迹作为输入，不以调参后样本内拟合声称改进。

当前结果支持把“偏好引起的减速—恢复能力耦合”作为机制假设；尚不支持一个普遍的加速/减速安全法则，也不支持解析容扰度已经成为有效训练信号。
