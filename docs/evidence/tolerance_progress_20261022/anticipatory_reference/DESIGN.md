# 更早的有限二维参考协调：历史核对、设计与实施

日期2026-10-25。研究目标保持：原用户alpha下，以有限合法参考改动保留真实闭环抗扰与任务能力；先证明简单规则之外的可用空间，不强留旧解析容扰式，也不先训练评分器。

## 为什么不是旧试验改名

已读取原设计和结果：

- low_speed_reference_authority_v1：六个lower-only稳态/转弯快照，±.24m/s、提前1s或同刻加速、已知t1脉冲，24非零条件hold19→pre23/react22；没有完整Actor/原路径/偏好代价，且准确起扰时刻已知。
- balance_proactive_references_v1：四个较高速快照，提前.2s，hold/减速.2/转向×.85，±72N；相对匹配hold转向0增0失、减速0增1失，不继续调旧提前量。
- reference_authority_expansion_v1：六个±.28rad状态24非零条件hold/react均饱和；pre_accel另有1退化，理想余量选恒加速无独立控制收益。
- temporal_reference_opportunity_v1_attempt2：已知受扰快照后.04s启动、.4s两段库，右1增2失、左无防摔收益/1联合任务丢失；该后缀库停止。
- causal_reference_full_task_v1_attempt2：ESO因果简单规则在8非零配对5→7不触地；应作为已有强基线资产，不能说之前没有因果完整任务尝试。
- live_path_rejoin_pilot_v3：锁参考改成实时原路径零修正，任务1→2/18、存活14/18不变；4接触中1无尾段、3尾段仅.015–.285s，12存活仍振荡或朝向错。已完成接口保留为共同基线。

新问题是**完整任务进入过程**：同一冻结偏好Actor之前/弯中，通过基于原路径进度的二维平滑参考安排，能否在不知道此次推力符号与具体时间时，优于速度下限并降低原alpha任务代价？不是换一个旧模态阈值，不是再搜旧受扰后时间库。

## 先比较的三个选择

1. 简单速度下限/已有ESO规则：必要强对照，低开发成本，收益不能归于新协调。
2. 固定少量进度门控的速度、转向和联合参考：本次选择，用途是机会验证；没有收益便停止这份库，不加段/改系数补考。
3. 参考条件能力预测与在线选择：只有2存在跨隐藏事件的额外收益才开发，当前Critic没有候选参考/力查询，不能直接顶替。

## 候选与权限

H75父、task_only64、physical_credit64、父＋1.5m/s参考下限，以及父＋speed_gate、steer_gate、joint_gate。七种角色各alpha0/.5；另唯一零中层。所有alpha仍为用户原偏好，始终对原请求/原路径评分。

门控只读取已走过的原路径进度s及原路径几何：从s=1.5m至直线前缀末3m用smoothstep升至1，保持至原turn_end，再在1.5m内平滑降为0。speed_gate将速度修正目标平滑混合到+.24m/s；steer_gate将转向修正目标混合到−.15×当前原nominal转角（即given steer趋向nominal的.85倍）；joint同时进行。其余通道保留原Actor目标。系数沿旧探针，避免事后选新幅度。均先转换为原latent，再经过同一correction_tick的滤波/slew/限幅/反饱和；不直接设置实际车速、转角或姿态。

新完整任务共同允许domain退出后live-zero续行，历史和原路径投影每20ms更新。控制动作按50Hz采样保持完整四个5ms tick；domain首次出现不再缩短该控制周期，下一50Hz边界才切零目标。接触/故障立即停止。**这与旧domain截断控制块最多有15ms调度差别，是显式新合同；全部本批对照重新匹配，不把旧36/488标签冒充新基线。** Actor不向域外发布动作；累计domain标志不清，原alpha保留。当前只验证提前安排，尚不实现域外重新启用Actor。

## 推荐固定DEV矩阵（需执行前封存实际清单）

原完整bank3/task0、右90度/R1.1m，请求1.5m/s，alpha0/.5。世界力向量沿既有右弯定义固定，所有候选共享，不能随候选姿态改变；幅值两符号32N、持续.1s。隐藏起扰取2.1/2.6s，另零力：每角色5条件，七角色×两alpha×5，加零中层5，再加原ESO因果规则alpha0的5条件，共80真实回合。ESO规则逐字复用causal_reference_baseline.py（.015检测阈值、.4s目标锁定、原条件与+.15速度修正），不私改成alpha.5也生效；alpha.5原规则本就不动作，可引用同条件parent作逻辑alias，不新增重复物理回合。控制器只能读实际历史/当前任务进度，不读实际未来F/t；此组只有一个路线/初态来源，是开发机会验证，不是独立测试。

主结果为完整窗无非轮触地＋原目标＋末1s原带；同时完整原V3状态/修正成本、物理终止罚、原alpha累计回报及连续路径/速度/航向、峰侧倾、参考干预量。各候选零力条件保留，不以改小请求/新路径制造好结果。每完整起点/alpha在所有设计事件上选择**同一个**候选的表现，与逐事件事后oracle分开。不存在机会时不训练选择器。

最多160000实际5ms步，0优化/训练；工程性能核对另≤960实际步记账。无需墙钟截止，不自动扩矩阵或重试物理。80清单当前尚未封存或执行。
