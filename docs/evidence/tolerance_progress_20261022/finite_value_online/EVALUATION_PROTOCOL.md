# 固定64终点：偏好抗扰训练信号的控制后果检验

这是已封存训练设计的评价实现说明；研究事实与活动状态见共享台账。三臂训练尚在执行，本文不是结果报告。

## 问题与比较角色

目的：有限时域价值参数化或完整回合MC，是否能保留抗扰训练的防摔作用，同时减少无扰和受扰后的路径—速度任务损失？预测误差下降本身不回答这个问题。

六角色共用原任务、完整初态、原始用户alpha、冻结底层和真实参考权限：原task64 A；A加现时侧倾角速度触发的短时速度支持；A加恒定速度支持；free_GAE、finite_GAE、free_MC固定第64轮Actor。前两种支持沿用已试过的profile7目标及原限幅、滤波与slew，不是实际速度硬保证。因果支持只读推进前的实测角速度，沿用0.8/0.4 rad/s滞回及0.6s保持；不读取真实未来起扰时刻、方向或幅值。

## 固定条件与执行

训练开始前已写入`runs/finite_value_online_v1/evaluation_cases.json`并封存哈希，seed2026102574。两条旧左右R1.1路线，请求速度1.8/1.5m/s，五个alpha；每组一个zero与正负32N各两个隐藏起扰时刻，脉冲0.1s、10s观察窗。50共同事件乘六角色，共300逻辑回合，zero不重复计数。三种父控制共享Actor，不算三个独立训练重复。

严格等训练实际完成64/64且源进程终止后，认证三新模型：各自新schema、配置、mode/rate/lambda、完整boundary与64轮/248次Actor和256次各Critic更新、checkpoint指纹及导出Actor逐叶一致。即使不同角色Actor字节相同，也逐角色认证训练状态，不能因Actor哈希相同跳过。

评价工具：`learning/cli/evaluate_finite_value.py`。顺序为prepare、shape、execute、analyze；prepare在训练未完成时拒绝且不创建评价目录。全300新物理的上限为600000个5ms lower控制转移槽，实际步数另记，0训练/optimizer；0.2ms积分子步不与lower转移混称。仅一次固定评价，不选best、不自动重试、扩事件或改门槛。训练中的新代码不修改已封存训练模块。

## 如何分析

- 从实际非轮接触及完整观察窗区分防摔；从原目标与末段保持区分任务。记录未摔且完成、未摔但任务失败、触地、未知四类。
- 同一完整事件配对，核对路径、alpha、速度、作用方向、时长、起扰时刻。报告新增与丢失，不把未知填失败。按alpha、无扰/受扰分别汇总，并保留每个模型自己的zero变化。
- 用实际日志重建原alpha奖励及有符号分量；几何任务误差独立重投影，不能用重投影替换原日志奖励。保存每20ms奖励、累计奖励、每分量与累计分量、参考/实际/轮速代理、真实失败终点。
- 因果支持逐次重放原gate，核对新推进前输入等于上一已完成物理测量；门控与实际合法执行分别记录，不将请求干预都算成已执行。
- 生成50组完整配对图及逐分量图、两张全部150轨迹XY概览和按原alpha分面的“无扰成本—受扰防摔/联合任务”散点。它们是有限已测候选点，不是连续Pareto前沿、连续安全边界或独立置信区间。生成图仍需人工目视裁决。

## 去留与论文边界

有限结构若只改善预测、不改善实际控制，停止结构。普通MC覆盖收益则保留简单方法。改善需同时报告防摔、名义任务保留、受扰末段及路径/速度连续误差与代价；允许失败，不要求策略无敌。若有实用控制增量，再选择一个主方法做独立路线/准备状态/时刻/持续时间及训练重复确认。

价值结构、MC或已知参考支持本身不承担首次贡献。论文主问题仍是：在有限参考权限下，用户偏好怎样改变实际闭环抗扰能力，以及怎样以较小的任务代价协调它。旧解析E_min只保留解释/基线，不重新拟合E_b、外力增益或时域维持故事。

## 一次性训练退出接续

`learning/cli/finish_finite_value.py`绑定当前真实训练PID的boot/start/cwd/argv身份和pidfd；只在原进程退出后读取一次训练状态，要求完整64轮和同一PID，再执行prepare→shape→execute→analyze。源运行只允许一个独占owner；评价目录与每阶段日志只创建一次，不重试、不重启训练、不增加条件或采用模型。

接续时封存训练计划、原输入、运行源码和本评价实现；每个阶段前重新核验。状态文件区分等待、实际评价和只读出图。完成仅表示数字与图已生成，仍需人工目视裁决与强对照判断，绝不等同于达到RA-L目标。等待为内核事件，不读取中间奖励或频繁轮询训练进度；Bark沿既有注册发送中文完成/错误，邮件与自动Codex修复保持禁用。
