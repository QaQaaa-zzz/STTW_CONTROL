## 3 新裁决：与速度排序相容，但没有速度因果结论

8个状态按实际捕获速度排序，两个方向的网格前缀均不下降：共28状态对×2方向=56个描述性比较，0次反转。这不需要拟合新参数或选择阈值；许多前缀相同，16N粗网格分辨率会遮蔽差异。本分析在既有结果之后提出，只是排序相容性，不是训练/验证/泛化准确率。

四组α1都更快（约+0.251至+0.454m/s），但侧倾、转向、ESO、历史与捕获时刻也共同变化。没有固定其他量单独改变速度，不能证明“提高速度必然增加容扰度”，也不能证明速度是充分状态或α没有额外信息。现有排序只削弱本面板上额外α容扰选择器的必要性证据，不构成全局否定。

更重要的扰动约定核对：原probe_balance_boundary.py以每个快照的heading生成[-sin(heading), cos(heading), 0]，后续固定这个世界向量。由原expected_impulse/(F×0.1)重建，四组α0/1的世界推力方向夹角分别为：
- left90_R1p1 / 1.5m/s：11.673度。
- left90_R1p1 / 1.8m/s：13.450度。
- right90_R1p1 / 1.5m/s：12.139度。
- right90_R1p1 / 1.8m/s：12.395度。

因此本面板的配对是同一“相对车体横向施扰规则”，不是同一世界推力向量。不同偏好导致姿态不同，这既改变进入状态，也改变所施世界方向。不能把9增0失写成固定世界外力下α的纯效应；更不能从不同完整状态得出“切α即可救回”。该约定不使原标签无效，但缩小了它能回答的问题。
