## 4. 对研究路线的影响

**容扰度仍是研究对象，旧解析公式尚非已证有效控制模块。** 理想局部最小努力E_min(F)=(z+KF)²/W与真实有限参考接口下的全过程不触地不同；这里没有新证据恢复它的训练/控制用途。

本轮把证据分成三层：①偏好策略是否到达原目标；②在规定力、方向、波形、持续时间和窗口下是否真实不倒；③根据闭环容扰能力选参考，是否优于规则/普通续训。第一层已有可复用基线；第二层部分历史记录有域停、指标语义不一致；第三层仍缺足够控制增量。不能用“有抗扰测试”替代“容扰度指导控制已有效”。

按scientific-brainstorming的反审原则，本轮判断依据信息增益、强对照区分力和可复用性，不作任意加权新颖性分数：

- **不采取立即补训双网**：身份核实后已找到真实受扰来源；没有依据认为训练本身是当前关键缺口。单网负结果保留为对应协议的负结果，不推广为双网不可能。
- **不采取重跑饱和名义面板**：四学习方法当前口径全24/24，不能辨别新的抗扰协调机制。
- **保留下一研究问题**：在确实有触地风险的、用户偏好不改的条件下，可执行参考的提前调整能否优于简单速度规则并减少任务代价。仅在既有进入状态/事后动作/强对照审查确认仍有未回答机会后设计新实验；不得扩已关闭90/80/72面板寻找正结果，不预称新颖或保证。

路线仍是“偏好—工作状态—抗扰—受扰后到达”的协调。重规划保留原目标和用户α，不冒充容扰度估计器。改路后的原α任务代价定义尚未收到用户明确答复，两个几何诊断并列，不阻塞物理结果/到达审计，也不擅自更换评价目标。
