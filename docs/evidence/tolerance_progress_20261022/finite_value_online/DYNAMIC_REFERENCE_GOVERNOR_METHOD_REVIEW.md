# 动态参考治理：可借鉴方法与本系统的适用边界

## 这次补充了什么

上轮32条阶段复盘没有识别特殊动态补偿机制；因此不能仅把静态规则未覆盖的低roll当作学习优于动态治理。本轮补读三类原方法，定位可用比较器及不能借用的保证。检索为定向方法核对，不是系统综述。

“冻结闭环外修改参考”“NN加最小修正”已有上述先例；结构组合不能独占新颖性。文献不同应用与我们的不同任务可以形成应用研究问题，但差别仍需具体知识或控制后果证明。

## 实际控制变量不能换层

对本项目，可用以下**接口记号**组织问题（不是新模型定理）：

```text
X[k+1] = F_4(X[k], z[k], P, v_user, external_force)
r_nom = follower(P, measured pose/progress, v_user)
r_cmd = original_filter_slew_bounds(X, r_nom, map_latent(z))
```

X需包含物理、ECBC/ESO、执行器、local300与中层历史、参考滤波/offset、投影/跟随器和权限状态；F_4是原4个5ms步。z是原中层latent，经过非对称映射后才成为参考偏移，不能直接当实际转向速率或电机力矩。接触/fault使推进终止，不能清状态后再预测。用户α、原速度与世界goal保持。

这里有三个不同的“保持”：

1. 固定z：名义跟随器仍在变，滤波/速率/闭环也继续变；不等于固定r_cmd。
2. 固定最终参考：需使用对应接口，不能用z=0冒充。
3. 固定参考下不变安全：还需要额外证明；前两种操作均不自动获得该性质。

全世界位姿在持续运动时不收敛到固定点，不直接满足点平衡表述；相对坐标/轨道等替代表述可能适用，但本项目尚未建立。硬clip、局部投影/分支和接触等意味着不能直接把全闭环视为已证明C2，再套敏感度余项界；这不排除局部/分段分析或其它治理方法。没有Lyapunov/终端集证书是**当前证明缺口**，不是单轨机器人无法使用RG的结论。

## 现有代码已做了什么，没做什么

`path_reference_governor.py`已实现，不再新建同类模块：在前一与当前神经proposal的物理偏移间取0/.25/.5/.75/1五点，完整carry前向，未来外力按零假设；不是知道本次事件已结束。实际未来NN不会被逐步重算，预览内持候选latent；即使真实pulse仍在持续，预测也不包含其剩余部分，保留ESO并不等于预知未来力。

选择器按最大已测通过fraction保留请求，不按Jα最小化，记录cost字段不代表已做偏好优化。源码明确使用GoalPreviewEnv+ContactOnlyPhysics、原几何反馈.1、10s任务limit，没有host重规划过程；**不能直接当成原生H75或新legacy90归档栈的匹配比较器**。若未来确需比较，必须显式适配同一个env/权限/规划/终止合同，而不是重用名字就算相同。先前纯接口AST一致也不是完整控制栈相同。

旧数值记录仅一次五候选×1秒预览：1000预测ticks/slots，五个通过且选fraction1，编译24.63秒、执行12.21秒，闭环governor回合数0。编译与一次执行分开，**没有已证明20ms实时、在线改善或递归安全**；本轮未重新积分来测墙钟。全部候选通过只说明该工程点未触发筛选，不构成一般无效证据。全部触地时previous proposal只是未认证fallback，不称保底安全。

## 决策：后续怎样用

- 将动态预测参考治理保留为**已有方法基线**，不把再加NN、候选插值或有限窗预测列成新方法创新。未验证的证书前提不作为禁止经验比较的门槛。
- 目前不启动其闭环实验：legacy90/新80的简单zero/floor已覆盖二元主终点，旧预览没有可用排序差异，直接跑新governor并不能自动回答剩余偏好价值；已有原生H75收益也不能由静态规则比较扩成对全部动态RG优势。
- 如果后续发现同权限、同原用户评价下确有简单方法未覆盖的机会，优先复用该预览器作为经验比较器；预测成本和实际执行计费分列，明确全状态特权/未知外力/有限窗/无认证backup。先证明控制用途，再考虑小模型加速；不能由预测准确率代替任务增量。
- 继续保留容扰研究对象，但旧Emin和工作roll代理不因此变成真实不倒阈值。不要求零失败或严格认证才可做研究，也不把安全理论借成已获得成果。

下一具体工作是把“可复用工程基线”与“还需证明的控制差异”对齐；不恢复已封存家族，不自动启用大网络、训练或更密力扫描。新提案必须先明确原用户α代价、真实参考层级、强简单替代和可推翻观察。
