# 同状态恢复机制对照（声明后执行）

固定u325/V3/local300、120°R2.5左右弯、2.35m/s、α0/.125、力0±20N，2s开始0.1s脉冲。四组共48案例，最多96,000底层tick，0PPO。2.1s从原策略control完整状态复制各组物理/历史/控制器/滤波器与前缀，2.1–4.1s分别保留、速度目标修正归零、转向目标修正归零、两目标归零；通过原滤波与变化率限制，不改物理状态/α/原任务参考。4.1s交回原策略到10s，末1s任务口径保持。

主结果：各干预相对同状态control的任务恢复新增/退化，末段路径/航向/速度连续误差、5–10s偏摆。无扰分支检查干预副作用；提前退出保留未知后续物理时域。时间段在结果前声明，不根据结果反复挑选。原control与旧面板比较是实现检查，接受既有小数值差异，不做新的严格回放门槛。不同干预返回不同观测，属于闭环机制试验；不能将效果归因于单步静态增益，也不直接部署或改奖励。若无一致改善，记录负结果后回到训练覆盖/完整恢复时域假设，不扫描干预时长。

CPU边界、状态映射、旧协议不变测试已通过；实际GPU行为尚待本次验证。仅已有筛选入口增加声明式可选干预，默认不改变旧评测语义。保存新增latent/target/offset/lower-action/clip标志用于诊断。
