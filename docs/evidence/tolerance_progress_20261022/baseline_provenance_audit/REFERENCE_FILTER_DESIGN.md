τ固定取原中层转向修正滤波的.08s。令dt=.005，a=exp(−dt/τ)，r为已发布转向参考，目标偏移t=−a/(1−a)dt*nominal_rate，经原steer_scale*tanh(z)逆映射后，仍走原correction_tick的滤波、slew/参考幅限。速度目标偏移恒零，不绕过任何限幅或修改实际offset/物理状态。无截断且offset=filtered时，y=r+filtered满足y_n=a*y_(n−1)+(1−a)*r_n。
