# 防摔目标与论文主张再对齐（2026-10-24）

## 纠正隐性门槛

用户已明确：容扰度按不摔倒定义；到达任务是上层表现另列；策略允许失败。此前反复强调“原触地→联合任务成功仍为0”有把联合恢复变成隐性门槛的风险。现在明确撤回这种解释：完整有限观察窗中“触地→无触地”就是有效的局部防摔见证，不能因为路径没到达而抹掉。原联合标签和所有任务失败继续保留，不改历史数值。

当前24条因果DEV对照的主要结果是8个非零力配对中的物理gain/loss及其净值；4个零力配对单列。任务/速度/路径/参考变化/fallback代价和联合成功同时报告，但不是防摔收益成立的必要条件。没有要求100%成功或零失败。若无净防摔收益，停止本门控的防摔增益主张；仅任务改善可作为另一现象保留，不能替代主要目标。此澄清发生于24条结果未知时，阈值、场景、样本、模型和执行停止合同未改。

## 当前证据能承担什么

| 主张 | 所需证据 | 当前边界 |
|---|---|---|
| 有局部防摔作用 | 同完整状态、力和权限下，原触地而干预完整无触地 | 40ms延迟诊断bank3/0各1例，已成立；后见选例，不当普遍收益 |
| 因果闭环能提高防摔能力 | 不读真实力/起扰，全配对gain/loss、zero/反向/提前终止、真实接触与UNKNOWN分开 | 24条正在执行，尚未裁决 |
| 保留用户偏好接口且干预代价可接受 | 原单网alpha接口不变；速度、路径、动作、无扰代价分别量化 | 接口冻结；当前新基线仅alpha0两情境，不能声称覆盖连续alpha或扰后偏好单调 |
| 扰后完成原任务 | 在原截止与原任务定义下联合成功 | 只在声称任务恢复时要求；不作为防摔定义 |
| 系统/任务贡献 | 具体耦合问题、针对性设计、合理对照和独立于开发选择的有限确认 | 有问题和局部见证；仍待整链结果及后续有限确认，不要求另造RL算法 |

规则简单不能自动否定系统论文，平台特殊也不能自动证明贡献。候选叙事是：在单轨车既有偏好中层与冻结底层之间，利用受限速度/转向参考调整改善有限窗防摔能力，并量化为此付出的偏好代价。因果ESO规则先作为简单可实现方案/对照；是否承担系统论文核心，由效果、适用范围和相近方法比较裁决。若引入容扰预测，必须交代它相对简单规则的用途，而非为保留旧公式而添加模块。

## 新核读的原始文献与背景边界

2026-10-24核读[CycleRL原文](https://arxiv.org/html/2603.15013)的III-B、III-D和IV-A/D：其使用固定复合奖励，并分别报告平衡与跟踪；平衡成功定义为侧倾小于0.5rad。它已覆盖自行车学习控制及鲁棒性，不能把“自行车RL抗扰”当首次，也不能把它的成功率直接与本项目非轮触地标签比较。“分层”一词在该文指输入处理/策略推理/执行器处理，不能仅凭术语认定等同本项目冻结local300＋偏好中层结构。该文也讨论高速机动时的耦合退化；本项目低速固定场景的速度优势不能扩成全工况单调定理。

核读[Boyi Wang等EABC原文](https://arxiv.org/html/2410.19615)的II-A Assumption1与Theorem1：其理论使用可微、导数有界的慢变扰动及额外闭环条件，关注跟踪误差；理想矩形推力的边沿不能直接套该慢变假设，更没有由此得到实际接触阈值。它可以支持观察扰动、调整受扰平衡点的设计思想，不能认证当前0.1s瞬态防摔边界。这是对相关原始论文的有限阅读，不冒充重新审完上传博士论文或确认当前代码完整实现了EABC。
