# 容扰选择的现有机会：相同观察防摔表现下减少不必要干预

先看原始XY：[六个低速状态全部轨迹](../../low_speed_reference_authority/all_paths.png)、[六个扩展状态全部轨迹](../../reference_authority_expansion/all_paths.png)。这些是原始已完成试验，不是本轮新控制器执行图。

目的：检查上一轮“低速风险区参考选择”建议是否重复旧路线，以及既有数据中是否存在超越始终加速的选择价值。本轮0新物理、0优化，仅处理已有DEV。

做法：复用两次完整实验的12个真实状态、每状态0/±40/±56N、每种参考5秒观察。仅比较共同拥有的hold/pre_accel/react_accel三个模式，共180条旧轨迹；受扰事件为48个，每事件三种模式。验证每个零扰候选完整1000个5ms采样且不触地，读取零扰速度参考相对原请求的绝对偏差积分。每状态事后选择一种模式，要求保留react_accel通过的每一个力档事件，随后最小化该参考干预量。没有按未来方向逐事件换动作。

## 更正与决策

“扰动前参考选择尚未做过”过于笼统：提前/同时加速已经实测，原理想公式已在两批状态中全选react_accel，未优于简单规则；转角候选模型选择也已有9/16对hold9/16负结果。停止重复这些参数扫描。

本轮证据只支持一个潜在目标：在不降低指定风险水平下，减少不必要参考改变，使原alpha偏好有更多执行空间。不支持容扰公式已会识别上述3个状态，也不支持新安全控制器已实现。此表是标签可见的可行参考点，不是部署收益；没有拟合阈值或报告学习准确率。

下一步：先验证仅用施扰前可用观测、已知风险包络估计“hold是否已经足够”；在独立状态上与速度/侧倾/角速度简单规则比较，评价干预量和逐事件防摔损失，再决定是否接回偏好网络。任何同批拟合须标TRAIN，不再当本表外推验证。若简单规则覆盖或预测无分辨力，保留负结果，不重扫原gamma/T。实际防摔续观测与路径任务终止仍需完整分开，已隔离的failure_contract模块不是完整训练实现。

## 实际扰动前评分核查（后续追加）

运行predict.py，使用每状态真实准备前缀的车轮速度、转角、侧倾/侧倾角速度和ESO（距施扰1秒），不读未来零力轨迹。不能使用这些lower-only快照中未同步推进的中层history作为真实当前观测。固定原T=.3、gamma=.7192241548921705、脉冲.1s及真实执行器限幅，计算最小方向力余量；比较负速度、绝对侧倾、绝对侧倾角速度风险评分。历史标签已被看过，此为回顾性DEV诊断，文件先保存评分不使其成为前瞻注册。

在12状态中，hold至少一个力档触地的状态4个，全部位于原低速实验；扩展实验6状态全安全。描述性状态AUC：公式.6875、负速度.9375、绝对侧倾0、绝对侧倾角速度.28125。方向按事先物理直觉固定，不因AUC低反转侧倾评分。相关性很强、不作显著性/泛化结论，也不与旧逐方向事件AUC1混用。

固定以56N风险包络检查公式：10/12状态加速，保留46/48，无新增通过→触地，命令积分9.02798m对始终加速10.83358m（少约16.7%）。被跳过的是两个v2.55状态；该数据上的选择与轮速代理<2.4m/s完全一致（事后诊断，不把2.4当预注册竞争者）。因此没有建立公式超越速度的增量，不能用这16.7%作为已证实物理方法创新。

另做两campaign互换留出：只在另一campaign上拟合单阈值，固定先最少漏报风险状态、再最少干预；四评分留出后都43/48，漏4个风险状态。公式/侧倾/角速度各干预6状态，速度2状态。原因之一是扩展训练折没有正类，规则无法从它校准原低速失稳风险；这反映分布与类支持缺口，不证明所有预测方法都不可能。无随机拆分同状态的力档造成信息泄漏；两campaign仍非独立祖先或最终TEST。

决定：保留公式作物理解释与保守候选，不采用为已验证优越调度器；停止这12状态上的阈值/系数/符号追调。进一步闭环数据应同时包含安全、边界与触地工作区间，且需要完整物理观察，避免用全安全批次校准失败边界；中层任务终止与防摔风险学习分开仍是实现缺口。先修该数据/续观测接口，再做同样本、同输入权限的简单状态模型对照。报告不得将事后75%机会写成已实现节省。
