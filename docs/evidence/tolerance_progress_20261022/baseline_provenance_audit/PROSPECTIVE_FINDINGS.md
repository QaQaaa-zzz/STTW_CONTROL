# 新工况确认：公式可以排序，但不是可信防摔阈值

目的：在未用来调整公式的新路径/速度上，检验原解析评分是否包含超过单一速度、侧倾指标的方向性信息。冻结H75/local300、公式T=.3s、脉冲.1s及原gamma；不训练策略，不重调阈值。

做法：左右110°、R2.6m，2.35/2.75m/s，α0/1，几何20%/70%，16真实完整前缀，各续行0/±80N共48分支。每侧原预测先于首次力扫描manifest约11.8秒保存；输入历史逐值核对。新增23188 lower ticks，低于54400上限。全部48结局和24配对图完成。

结果：16零力全部不触地；32受扰有6例完整4秒不触地、26例触地。原公式排序AUC=1，速度代理=.88462，方向侧倾=.94872。然而原F≥80判据有6真通过、10假通过、0假拒绝、16真拒绝。不能把AUC解释成100%预测准确，更不能当安全认证或真实临界力。

低速2.35m/s的16受扰例全部触地，组内排序无定义。高速2.75m/s下6/16不触地，公式AUC1、速度.7、方向侧倾.93333。因此总体排序并不完全来自高低速分离，但独立单位只有4个路线×速度块、8条轨迹链，不能把32当独立训练重复。α0有2/16通过，α1有4/16；两例差异均为右弯2.75m/s、+80N。各策略自己的进入状态不同，不是同状态改变α救回证据。

## 追加联合基线

独立反审指出多状态公式对单变量评分的优势不足以证明物理表征必要。遂在读取新标签前固定一个旧DEV48拟合的六变量逻辑回归（速度及平方、带施力方向符号的侧倾/侧倾速度/转角/ESO移位），仅旧DEV标准化，固定L2=1，无参数搜索或策略ID。系数和32新输入评分先冻结，再读新标签。

这是**实验启动后追加的次要分析**；自动primary分析器已访问新标签，人工尚未查看，不能称预注册或施扰前预测。原primary文件、评分和停止规则不改。该基线记1次统计模型拟合，0新PPO/物理；原解析方法本次0标签拟合，但gamma的历史标定成本不可抹除。

联合基线AUC=.96795，公式1；6×26=156对通过/触地比较中，只差5对的排序，且共享状态、有相关性。两α组内联合基线也均为1。它说明直接组合状态已能解释大部分信号，尚不足以主张公式相对联合模型有实质优势或显著性。不得继续增加特征、换正则、调gamma/T或用这批数据挑新牛顿阈值。

## 对主线的影响

保留“偏好取舍塑造进入弯道的实际状态，伴随方向性防摔能力差异；解析量提供无需本次结局拟合的可解释排序”这一候选研究问题。当前没有证明其改善闭环控制，也未证明α1普遍优于简单跟随器。特征训练无增量、同状态临时换α零救回的负结果不变。

下一步先复用已有轨迹，把名义速度/路径/姿态代价、物理防摔结局与公式解释按同一控制器身份整理为一张证据矩阵，找出缺的简单基线及未覆盖域，再决定单项必要确认。停止追本组精确力阈值、反应式调度及重复六特征训练。实机未部署，RA-L目标尚未完成，B2/B3/B4不做。

另一个零物理反证：四组名义零中层轨迹的非饱和转向命令/实测速率增益为.99985–1.00023，RMSE约.00040–.00048rad/s。因此不能以未经测量的“.8执行器增益”修正公式；大力冲击下的饱和与耦合未由该核对覆盖。
