# 偏好功能仍有有限任务价值，尚无抗扰增量

目的：新几何zero对照否定当前额外防摔主张后，判断现有α功能是否只是改变行为，还是提供固定行为无法覆盖的任务效用。全部复用24条10s名义轨迹（zero四条、H75五α×四上下文），0新物理/训练。

方法：对每条事实轨迹在五个用户α下交叉评分，V3只替换依赖α的speed/path/primary项，其余成本及真实日志remainder保留。原路径精简包只有xy/s/goal，故用原builder恢复曲率并核对已有三字段；不猜缺失字段。原α分量最大误差1.72e-5、累计return误差1.45e-6。最初两次离线字段错误留在attempt1/2，未重跑仿真，中文Bark错误/完成登记均保留。

## 真正保留下来的内容

- 20个用户α/上下文中，匹配α行为相对zero及固定α1中较高效用者8胜、3平、9负。八胜全部来自两条2.65m/s上下文，不能当作八次独立实证；低2.45m/s几乎由zero覆盖。
- 进一步加入全部固定α参照后，两个2.65上下文里五个H75行为均在非零宽度的用户α区间成为既有六条轨迹中的效用最高者。因此这两个开发工况上，一个固定保守α无法覆盖所有用户偏好。
- 固定轨迹的V3效用对评分α为仿射，五点线性残差仅1.63e-6；据此计算的是已有轨迹的效用上包络，不是插值物理轨迹或新部署算法。输入某α时网络实际行为未必正好在上包络：例如右2.65、α=.25/.5分别距既有最佳约1.03/.14return。
- 左2.65匹配α0相对固定α1的+28.61return，主要来自路径成本+25.16与primary+4.94，速度成本−2.03、roll约+.54；不是全靠roll惩罚。
- 右2.65匹配α0相对zero的+35.22，主要来自roll+14.61、working_roll+23.67，路径−1.77、速度−1.43。两侧收益机制不同；真实姿态改善不等于更抗冲击。

物理代价仍看原始速度/路径/roll和出弯时序，而非只看return。旧zero四条都到达且无触地，严格保持未过仅因尾航向约4–6°超原0.05rad；即使其效用较高，也不自动称严格任务达标。H75所测五α20条严格任务保持通过。完整三指标、Pareto支配、6×5矩阵、逐固定行为差值与成本差全部保存，数值非支配性不代表实用显著性。

## 研究决策

保留“存在任务冲突时，条件化参考协调提供不同用途”这一有限开发证据。它不能复活物理特征、即时切α或公式独立预测优势，也未证明新几何/实机泛化或RA-L完成。

独立AI反审先要求补齐全部固定行为，现已完成；复审认为值得只做一次新几何完整名义迁移确认：既定110°/R2.6、2.35/2.75，zero四条＋H75五α20条，完整10s、不施力、不训练，不改奖励/模型。此前该几何已有受扰结果，必须称名义迁移验证，不能称完全未见TEST。此时还未准备/启动新24，结果PENDING。

若新面板被zero或一种固定行为覆盖，或效用差无清楚物理取舍，则停止系统泛化主张，不换速度/奖励/checkpoint补考。正结果也仅支持有限名义任务价值，防摔增量的停止决定不变。该新项必须单独完成执行前声明/身份/监视与预算后才能启动；B2/B3/B4不做，无push。
