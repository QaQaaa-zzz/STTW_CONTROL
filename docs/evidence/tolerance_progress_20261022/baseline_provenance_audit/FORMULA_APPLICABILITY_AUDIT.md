# 公式适用性审查：保留物理坐标，撤回真实防摔阈值解释

目的：落实用户“可能推导错了、背景不同，不要死磕”的要求，区分代数正确、模型适用、控制权限与防摔语义。本轮直接核对controller.py、tolerance_state_features.py、旧变速推导及既有闭环代理/参考选择负结果；不是新物理实验。Scientific Agent Skills用于证据分层，SymPy用于精确代数检查。

## 1. 核验后成立的部分

简化模型为δ̇=u，φ̇=ω，ω̇=a₄φ+a₂(v)δ+a₁(v)u+d+γF。固定λ=√a₄，定义z=ω+λφ+[a₂(v)δ+d̂]/λ，则精确求导为

ż=λz+[a₁+a₂/λ]u+γF+(d−d̂)+[a₂′(v)v̇δ+d̂̇]/λ。

原坐标变换的符号本轮未发现错误；旧简式缺少最后三项，只有恒速、估计匹配且ESO近似不变时才可忽略。此漏项已在旧VARIABLE_SPEED_MODEL_NOTE.md发现，本轮复核而非新发现。截断minimum_speed和m₂下限拐点须分段处理。

矩形脉冲在延迟τ发生、持续Δ时，其对指数折算坐标的输入为KτF=γ exp(−λτ)[1−exp(−λΔ)]F/λ，SymPy核验通过。常值b、自由u、固定T时W=b²[1−exp(−2λT)]/(2λ)，E_min=(z₀+KF)²/W是该标量终端控制问题的最小L2输入能量；没有由此得到物理触地阈值。

## 2. 与实际任务的五个错配

| 问题 | 已知情况 | 影响/处理 |
|---|---|---|
| 输入权限 | u是实际转向角速度；中层输出有界速度/转角参考，经过滤波、ECBC/ESO、local300和执行器 | 自由选择u的存在性不能推出冻结控制器实际会执行该轨迹。必须显式包含闭环映射；不是重新拟合能量预算即可解决。 |
| 状态不闭合 | 固定反馈下ż依赖完整δ/φ/ω及ESO/执行器历史 | 一个z不足以定义真实状态；同z不保证相同防摔能力。 |
| 终点与全过程 | E_min约束z(T)，真实目标是在完整观察窗无非轮触地 | z(T)=0不限制中间峰值或机械接触。甚至φ任意大、ω=−λφ、δ=d̂=0时z仍为0，足以反驳“z=0必不倒”的一般性解释。此为代数反例，非真实可达状态声明。 |
| 输入/位置限制 | L2预算不等于峰值、角度、延迟限制；按(δmax−δ₀)/T截断恒速率只描述受限候选类 | 理想自由输入的乐观能力与候选类限制的保守性叠加，没有统一误差方向，不能自动宣称预测偏小安全。 |
| 非线性及外扰 | γ来自旧局部响应，实际力臂、车身方向、速度、ESO跟随和大侧倾接触改变响应 | γ不是已验证的全域常数。明确d是否已包含外力，避免把同一扰动同时算入d和γF；不能把初始ESO估计一直视为真实未知力。 |

## 3. 直接代入当前反馈的数学证据

x=[δ,φ,ω]ᵀ，A=[[0,0,0],[0,0,1],[a₂,a₄,0]]，B=[1,0,a₁]ᵀ。固定参考、恒定ESO近似、无饱和下，实际ECBC给出Δu=−gᵀΔx，故A_cl=A−Bgᵀ。使用当前真实controller配置和_system实现：

- 三个轮速代理1.5/1.8/2.55m/s下，开环发散指数均λ≈6.38451。
- 对应理想ECBC闭环极点实部均约−5（wc=5，数值重复极点有小浮点分裂）。
- C=[a₂/λ,λ,1]满足CA=λC，但三速度下rank([C; CA_cl])均为2，投影后的闭环不能只用一个标量z自治描述。

这些结果说明开环发散坐标不等于实际闭环失稳速率；不否定用该坐标设计反馈，也不证明真实含local300/延迟/饱和闭环稳定或不摔。上述近似不重新冒充完整系统模型。

## 4. 结合已有实测的决定

旧闭环低阶代理已纳入部分ECBC/ESO/执行器并测试过；首轮24例较好不等于扩检有效，不能把“加入反馈”重新包装为未试过的突破。低速参考加速有真实防摔增益，但旧公式选择没有超过加速规则。本轮selection_opportunity的12状态固定56N判断保留46/48、干预少16.7%，只是跳过两个高速状态；未建立超越速度规则的增量。

因此：

1. 原公式保留作开环物理坐标和解释性基线，暂停充当已校准牛顿阈值、奖励或在线安全判据，不继续扫gamma/T/Eb来追旧标签。
2. 目标改为明确固定策略π和候选参考r的有限窗防摔能力r_sigma^π(s,r,Δ,H)。完整状态s含物理、ESO、执行器/滤波、必要历史；要求从0到所报半径的所有力幅都在H内不触地，离散扫描只能给已测点证据，不默认连续单调或无限期安全。中层改变参考/策略，能力对象也随之改变。
3. 后续采用闭环响应/数据估计，原z可作候选特征而非强制正确结构；与相同输入、相同数据的小容量原始状态模型、简单速度规则比较。首先完成路径任务退出后有效参考和完整物理续观测接口，避免标签被任务失败截断。只有独立工作状态证实预测/决策增量才发展成方法主张。

“状态条件下满足指定风险时最小参考干预、保留alpha偏好”仍是候选研究问题；不是已经成立的新方法或RA-L完成证据。不为迁就原公式而挑场景。
