# 用实测闭环能力连接容扰度：条件性下一步

2026-10-24，当前因果24条仍未出最终结果。本文件只是下一步选择，未启动补测或训练，不改变正在运行的规则。

## 要计算的对象

固定完整任务初态s₀、整个闭环Π（H75/alpha、gate、local300、ESO、滤波及执行器）、环境推力时刻τ、世界方向σ、脉冲时长Δ=.1s和原观察截止H=10s。定义

Sᴾᴵ = {F≥0：从任务0到H未发生非轮部件触地，且无工程故障、无未观察区间}。

这直接对应本项目“不摔倒”。路径任务达标、速度/路径偏好代价另列，不进入S。原观察合同允许任务域退出后按最后参考继续物理观察；此时属于固定闭环fallback的防摔结果，不声称仍在追踪原路径。若物理观察不足或故障，标UNKNOWN/ENGINEERING，不加入通过集合。

理想连续半径可定义ρᴾᴵ=sup{r≥0：[0,r]⊆Sᴾᴵ}，但有限扫描不能证明整个区间包含关系。若零力本身失败，明确记录名义失败，不能把报告ρ=0误读成已证明0力安全。控制器按阈值切换可能使S不连续或非单调，不假设“更大力一定更难”。

实际只报告给定网格G上的通过集合Sᴾᴵ∩G，以及按力幅排序后、已测相邻安全/触地档位的经验转变区间。连续ρ不是已认证结果，最高测试点通过时标“上侧未辨识”；不能继续自动加力寻找失败。

## 为什么比重新拟合旧公式更贴任务

旧最小能量式对应自由实际转向速率和终端坐标；这里闭环固定、权限真实、标签为全过程接触，Π已包含检测延迟与真实参考响应。解析z仍可解释状态，但不要求它给出精确牛顿阈值，不扫E_b/gamma/T。

当前只有±32N因果对照，即使出现触地→不触地，也只能证明该工作点的能力成员关系改变，不能立即声称连续容扰半径提升。

### 下一方法假设：保留父策略的实时参考变化，而不是锁住目标

焦点仍是原目标：冻结底层、用户alpha不变，防摔反馈改善实际能力，同时保留原偏好中层的任务取舍。已验证的检测时目标锁定规则保留为强简单基线，不包装为新容扰理论。当前只覆盖alpha0，这个缺口没有由上述迁移自动解决。

**假设而非发现。** 锁定目标会在80ticks内忽略父Actor选中通道的后续变化；保留这些变化可能减少与原任务偏好的冲突，也可能破坏已经有效的救回。候选只改窗口内参考合成方式，不改检测信息、起点、alpha、幅度、时长、滤波/slew/绝对权限或fallback。实时补偿本身不是新颖性，实际增量必须对强简单基线成立。

记p(t)=map_latent(pi_alpha(o(t)))为父策略目标修正，c(t0)为检测时实际offset，m为既有选中通道。旧基线的可执行锁定目标为q0=sat_C(c(t0)+Delta)。候选在同一窗口用

q_follow(t)=sat_C(q0 + m⊙[p(t)−p(t0)])，未选通道保留原Actor。

窗口外直接交回原Actor。q0取旧fixed_latent映射回的实际可执行目标，不取未夹紧target_offset。该写法在检测时与锁定基线相同，避免把“改为父目标锚定”与“随父变化”混成一个干预；无饱和时只在目标层保留父增量，不承诺滤波后轨迹或alpha偏好完全保持。所有输出仍经原逆映射/滤波/slew/幅值限制。原首次事件锁存与域退出held-reference合同保持，不能在离域后让过时Actor继续输入。

实现前先复用既有因果轨迹量化父目标在干预窗内到底变化多少，并做反事实目标的权限/初值一致性核查；那不是新闭环轨迹。若父目标几乎不变，此机制缺少机会，不为小数误差添加模块。然后才实现独立candidate模块，以TDD核初始动作一致、选中通道保留父变化、未选通道原Actor、目标夹紧/80tick交回/故障；不改已冻结baseline。之后由同信息/权限的锁定与跟随候选做一次冻结比较，实际协议/范围须先入台账，不立即扩alpha或训练网络。

跨alpha的后续比较需两臂采用同一匹配的事件资格，明确共享补偿接口如何适用于既有alpha策略，而非只给候选删除alpha0条件；同时报告各alpha的真实速度/路径/名义表现，不用不同alpha的reward互排。若候选不超过已有简单反馈，或只把不同alpha压成同一行为，则停止该方法主张，不靠补场景维持。当前这一方法仍是待核查假设，未实施或运行。
