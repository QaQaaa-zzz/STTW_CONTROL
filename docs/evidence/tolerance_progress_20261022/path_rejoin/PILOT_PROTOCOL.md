## 两臂共同评价

不能继续把held尾的路径误差标成不可观测后直接判任务失败。新日志记录真实yaw与XY，离线按原固定路径、原局部投影窗口和单调进度重算**两臂**全过程几何误差；这只是影子测量，不反馈到held控制。原投影函数对照测试覆盖向后运动/局部投影语义；不由速度方向近似航向，不插值缺失观测。

新任务联合成功：10s完整无非轮触地，越原目标且末1s路径≤.1m、航向≤.05rad、速度误差≤.1m/s。域退出是中间事件，不自动等于新任务失败；原488标签与奖励合同不回填。触地、完整无触地任务失败、完整联合成功、UNKNOWN分别列出。同步给XY、实际参考、路径/速度/航向/姿态曲线、接触端点、真实积分和绕行距离。原Actor前缀奖励保留；旧域退出终止罚不能直接作为新恢复任务总回报。

本批全部有扰动、仅两个相关物理情境，无独立种子，也无名义保持面板，不能据此宣称泛化、性能保留或实机能力。指标带沿旧合同用于一致描述，不要求策略100%成功。特别检查新增任务成功与丢失成功、触地增减及代价，不能只看一个总成功数。

## 执行与停止

CPU行为与几何测试先红后绿；真实六批接口零积分通过后首次执行。工程错误保存原日志/状态，不自动重试物理；已完成阶段不重复收费。仅一次固定矩阵，不看结果增加alpha、时域、候选或训练。

有任务增量且代价可用：先把live作为共同基线，检查还剩哪些失败值得稳定/几何连接。若简单live覆盖收益，不把复杂接回或容扰评分作为独有贡献。若live没有实用机会，保留负结果，检查实际失败机制后再决定稳定阶段或转入提前参考；本实验不能否定所有接回方法。
