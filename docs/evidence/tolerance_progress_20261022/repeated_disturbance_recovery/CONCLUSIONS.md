# A3首组结论：储备随恢复过程变化，但固定速度干预没有带来救回

2026-10-24。研究目的与完整合同见[DESIGN.md](DESIGN.md)，结果见[全部270例及90工况图](../../../../runs/repeated_disturbance_authority_v1/report/REPORT.md)。

## 目的与做法

检验同一真实首推历史后，原有速度参考权限能否改善再次受扰的物理结局。六个完整lower-only快照，1.65/2.55m/s、转向+.28rad、首推0/±24N、.1s。首推开始后.15s保存状态，三种事先固定动作保持/目标+.24/−.24m/s按原滤波、slew与速度界生成；不读取未来第二推、不恢复无效的上层历史。

第二推0/±24/±48N、.1s，保存状态后延迟0/.25/.6s；从保存状态起观察4s。三动作使用相同世界力向量，由保存状态heading定义，延迟后不随干预方向变化。240新增分支179421lower ticks≤192000声明上限；另30条0延迟保持结果经身份核对复用，0训练。全部270原NPZ接触/故障/有效ticks与新参考逐帧核对通过，90工况图保留全部模式和真实终点。

每模式72非零二推＋18零二推。所有54条零二推都完整无触地，无工程错误或UNKNOWN。

这里的“救回”严格为同状态同外力的触地→完整4s无触地，丢失对称报告；未用域退出或仅侧倾阈值替代真实触地。上述比例是相关开发工况描述，不是独立训练重复的统计估计。

## 可以得到什么判断

- 当前给定参考闭环确实有首推后的再次抗扰过程：在这个离散网格，保持组随着间隔增加，观察到的通过数量20→23→24。不能由三个时刻断言连续时间单调或给出精确“恢复时间”。
- 原保持策略可以自然经历显著降速与转向回摆而重新稳定。例如2.55、prime−24、延迟.25、第二推+48时，保持完整无触地，加速干预反而触地。实际速度/转向变化提供机制线索，未隔离单一因果环节。
- 低速单次脉冲中发现的加速收益不能推广成重复扰动下的一条通用规则；这里加速与减速均无救回。不能以该组数据主张条件选择器优于保持，因为在所有已测二元结局中保持没有被两个干预救回。
- 本组不是完整α中层测试，没有路径任务或V3 reward，不把lower-only参考实验包装成新偏好方法。

## 去留

停止当前单速度通道的A3加速/减速参数迭代，不据这组负结果立即训练新Actor。保留所有真实历史、270条结果、延迟与方向网格，作为未来闭环容扰定义和方法对照。

继续研究目标前，必须回答更根本的问题：已有α偏好在实际发生速度—路径冲突的工况，是否真的改变触地容扰能力？当前低速三臂物理标签几乎相同，原速度新880只有名义面板，早期较高速门控面板小扰动没有触地。因此这项能力差异尚未由适当面板验证；不能说已不存在，也不应继续通过加网络掩盖缺口。
