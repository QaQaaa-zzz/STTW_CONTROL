# 容扰度公式与本轮结果的关系

以下是**本项目先前推导的局部理想输入模型**，不是把博士论文原公式直接复制成当前仿真的防摔阈值。本轮64训练和200评价没有使用它。

局部固定速度模型取实际转向速率为自由输入u：

\[
\dot\delta=u,\quad \dot\phi=\omega,\quad
\dot\omega=a_4\phi+a_2(v)\delta+a_1(v)u+d+\gamma F.
\]

定义

\[
\lambda=\sqrt{a_4},\quad b=a_1+a_2/\lambda,\quad
z=\omega+\lambda\phi+(a_2\delta+\hat d)/\lambda.
\]

完整求导包含

\[
\dot z=\lambda z+bu+\gamma F+(d-\hat d)
+\frac{a_2'(v)\dot v\delta+\dot{\hat d}}{\lambda}.
\]

忽略估计误差和变速/观测器变化项、假设能自由选择u，在时域T内把终点z拉回0，若脉冲从tau开始、持续Delta且完整落在T内：

\[
K_\tau=\frac{\gamma e^{-\lambda\tau}(1-e^{-\lambda\Delta})}{\lambda},\quad
W=\frac{b^2(1-e^{-2\lambda T})}{2\lambda},\quad
E_{\min}(F)=\frac{(z+K_\tau F)^2}{W}.
\]

对给定能量预算E_b，记R=sqrt(E_b W)，W>0、K不为0时，对两个有符号力方向的理想余量可写为

\[
F^\pm=\frac{R\mp\operatorname{sgn}(K_\tau)z}{|K_\tau|}.
\]

它回答的是**理想转向输入、局部模型下的终端恢复努力**。当前中层实际只能输出有界速度/转向参考，再经过滤波、变化率、ECBC/ESO/local300及执行器，且真正的防摔标签是整个有限窗不发生非轮触地。自由输入的最优解未必能由该接口实现；终点z=0也不保证中途没倒。γ和有效恢复努力还会随状态/闭环变化，低估不自动保证保守。

因此不继续靠拟合E_b/gamma/T把它包装成真实牛顿阈值；保留作解释或比较基线。原论文值得借鉴的方向是选择较有恢复能力的工作状态及过渡过程，本增补包不重新鉴定原论文原式，原文截图和页码请并读此前完整审阅包。

本轮研究的量是：在固定完整初态、原alpha、实际闭环及参考规则、方向/作用点、脉冲波形/时长/时刻和观察窗下，真实是否触地及任务代价。50/50通过只是这50个相关条件的结果，不是无限或连续容扰保证。下一2×2诊断用来区分“先形成更好的工作状态”和“受扰后才恢复”的作用；仍然不是旧E_min有效性的证明。
