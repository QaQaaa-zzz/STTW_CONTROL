# 同合同普通PPO64轮与固定200评价：结果裁决

日期：2026-10-25。先看[全部左路25条件XY](../../../../runs/matched_live_ppo_v1_fixed64_evaluation/review/all_xy_left.png)和[全部右路25条件XY](../../../../runs/matched_live_ppo_v1_fixed64_evaluation/review/all_xy_right.png)。当前采用状态：新模型冻结为候选/强对照，不替换原偏好策略。

## 目的、做法与条件

检验固定速度支持损害任务是否仅因为原Actor没有适应新执行合同。认证task64同源Actor/价值网络/log_std初始化，两臂新Adam、beta=0普通PPO；唯一臂差为profile0原参考映射与profile7已有速度支持。共同使用实时几何回退、16clean-block合法交回、全部真实任务奖励、原alpha/V3及冻结底层。熵与Actor项按相同30000槽位归一。

每臂64轮×60完整10秒回合，前2轮仅Critic、4epoch/轮。两旧R1.1路线请求1.8/1.5m/s，五alpha，0/±32N持续.1s，起扰在[1.6,3.4]秒抽取并隐藏于Actor；作用点和固定世界方向不改。全部64轮原始SHA、声明源与冻结父模型均认证；各臂Actor248步、Critic各256步，0unknown。

训练实际15234239个5ms步/15360000分配槽位，各3840回合；训练循环约9421秒。训练中的接触计数不是冻结终点性能。TensorBoard真实reward核验至64轮。源模型与新终点的代码、配置、权重身份见FROZEN_MODELS.json及原run/source_at_launch，不改best指针。

固定终点200回合全部完成，实际396974个5ms步/400000槽位、0optimizer/unknown。50共同条件×4角色，零力不重复；同条件四角色使用相同事件，保持原用户alpha。未在测试中挑中间权重。两条旧路线/相关初态、一个配对训练重复，属于DEV证据，不是独立泛化或多种子。

## 冻结终点结果

每角色50回合，含10无扰与40受扰。联合任务=完整窗不触地、原目标/进度和原末1秒路径/航向/速度条件；工作侧倾另报，不能替代真实触地。

|角色|不触地|联合任务|名义联合任务/10|受扰联合任务/40|名义原alpha平均成本|受扰原alpha平均成本|
|---|---:|---:|---:|---:|---:|---:|
|原task64，无支持|48/50|19/50|8|11|19.613|312.571|
|原task64，固定支持|50/50|13/50|4|9|46.552|77.779|
|新plain64，无支持|50/50|14/50|5|9|42.159|80.241|
|新support64，固定支持|50/50|3/50|0|3|50.157|69.536|

原无支持的2次接触都在右弯：alpha.25负32N/1.94s，alpha.5负32N/1.90s。新plain相对原plain防摔+2/−0，联合任务+2/−7；新support相对原support防摔0/0、联合任务+3/−13。新support对新plain同样防摔、联合任务+3/−14。

不能把联合任务下降全部归于几毫米门槛：新plain右路无扰alpha.5末路径最大约1.542m/航向.567rad；新support左路无扰alpha0约.640m/.709rad。它们是实际任务损失，不需要再收紧门槛解释。

也不能称训练完全无用：新support受扰平均成本77.779→69.536；全部轨迹平均路径RMSE1.025→.831m、速度RMSE.146→.126m/s。原support与新support均未触地，故该比较不只是去掉接触罚。与此同时名义成本46.552→50.157、名义路径成本分项34.402→37.045，未实现整体兼顾。

DEV表无扰占20%，训练占1/3，不能把未加说明的总体均值直接当训练混合目标。按1/3名义+2/3受扰重加权，原support67.370、新support63.076；这是同一批数据的描述性查询，不是新样本。原plain受扰均值包含两次巨大终止成本，不可仅凭其大幅下降宣称路径偏好改善。

## 学到了什么、还不能断言什么

1. **已获得强普通训练基线**：在这50个已测条件中，新plain无需固定支持也不触地。因此后续方法必须与它比较，不能只比旧父模型。
2. **训练不足不是现成结论**：完整64轮/所有原始数据已核，混合成本下降而名义/联合任务恶化，与目标取舍和名义能力漂移一致；但没有证明优化收敛，单种子波动、价值估计和局部最优仍是竞争解释。既不宣布“永远不可行”，也不立即追加64轮。
3. **旧解析公式没有因此变有效**：本实验未用E_min、E_b、gamma拟合或解析容扰奖励。50/50只表示指定力/时长/时刻/闭环的有限网格通过，不是连续阈值或全局安全。
4. **静态候选选择空间仍有限**：四角色逐事件事后任务并集24/50，优于最佳单角色19/50，但这是知道结局的上限；按route/alpha在本表所有事件均未摔候选中选名义成本最低者，为50/50未摔、17/50任务、6/10名义任务。这个事后表不是部署策略，也没有超越原偏好任务能力，不据此训练大型选择器。

## 决策与下一步

保留两个新终点、源码/配置、全部失败及负结果，暂不作为整回合替换策略；不追加普通PPO轮数，不扫floor/phase/旧37结点，也不复活旧解析预算拟合。

用新出现的真实后续控制器做一个有限2×2机制诊断：A=原task64/profile0，B=新plain64/profile0，比较原/新进入过程与原/新后续策略。先分清收益来自进入状态还是受扰后动作，再决定是否值得做因果触发、原alpha恢复或参考条件能力。详细条件、缓存与停止边界见[机制设计](../../../superpowers/plans/2026-10-25-entry-recovery-factorial.md)。当前仅设计，尚未运行；离线按已知事件时刻切换属于机制特权，不能直接说是可部署方法。
