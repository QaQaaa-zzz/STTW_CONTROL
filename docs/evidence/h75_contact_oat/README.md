## 预先固定的问题

1. 坡高、位置与车辆相同时，坡长增加（坡缓）是否减少卸载和物理终止？
2. 同一单脊沿弯道移动时，各alpha的完整运行/物理终止曲线是否单调，还是存在适用区间？
3. 改变轴距后，前后轮时延L/v及地形长度/轴距比是否对应恢复变化？先检查同车型平地能力。
4. 障碍斜交角是否改变接触序列与档位排序？
5. 整体坐标旋转能否维持总体趋势，以区分绝对航向与相对入障状态？

曲线方向与优选alpha均由实验决定；不根据结果增加条件。配对保持同一物理组、初态、策略、控制器、执行器和全部非目标因素。完整实验原数据在外盘root，不把准备文件当成已执行结果。
