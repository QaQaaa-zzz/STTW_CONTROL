# 接触事件标定

每个轮首次高地接触后250ms，比较有符号力矩积分和绝对力矩积分。包含全部五档、4个高度、4个速度；101/102拟合，103留出。窗口不足250ms的失败记录仍保留在events，单独标明观察长度。模型使用实际接触速度，因此它解释接触机制，不直接作为入障前选档输入。

|轮|拟合/留出|有符号MAE Nm·s|绝对量MAE Nm·s|常数基线的两项MAE|
|---|---:|---:|---:|---|
|front|160/80|0.00354|0.00796|[0.0057115189035539474, 0.01515694299247117]|
|rear|160/80|0.00937|0.01225|[0.010419191010228705, 0.014653234414290641]|

这里的接触力矩包含支撑与摩擦。其积分单位为Nm·s，不能直接代入以rad/s定义的J_sat；完整车辆惯量与约束接触投影仍需要动力学映射。S3采用已标定的运行响应/余量网格预测，名义冲量方程用于解释两轮作用间隔及转向能力，不将其当作已验证的成功概率公式。
