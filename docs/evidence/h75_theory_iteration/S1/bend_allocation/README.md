## 得到的结论

无外力、平滑弯道的40个路径—初态面板中，96/96条相邻alpha比较均为实际速度上升、减速承担的需求削减份额下降；路径向弯外偏移增加94/96。H03五档提供32条比较，H05三档提供64条。该结果支持“alpha增大时，车辆由更多减速转向更多改变行驶曲率”的协调趋势。

这里的份额按实际速度和实际XY曲率计算。它是局部运动分解，不是对神经网络两输出的独立因果消融。

## 推导和可检验预测

取原路径曲率绝对值K、请求速度v0、减速量s=v0−v、向弯外偏移e≥0。对于局部近似同心圆，曲率削减为K−1/(1/K+e)≈K²e。因此横向加速度需求削减

D≈2v0K s+v0²K²e。

令x=s/sv、y=e/se，gs=2v0K sv、ge=v0²K²se。在固定D下最小化wv x²+wp y²，约束gs x+ge y=D，拉格朗日条件得到速度份额

f_speed=gs x/D = r/(r+rho_g)，r=wp/wv，rho_g=(ge/gs)²。

在chi=1、sv=se的数值尺度下，r=(10−9alpha)/(1+9alpha)，随alpha递减，因此固定几何时预测速度承担份额随alpha递减。源码实际基础权重为wv=10−9chi(1−alpha)、wp=10(1−0.9alpha)；配置文字中的path_weight字符串不能替代源码中的path_secondary_ratio实现。本轮用源码有效权重，同时保留方案chi=1版本的预测值。

对Huber h(x)=x²（x≤1）或2x−1（x>1），内点最优条件是

wv min(x,1)/gs = wp min(y,1)/ge。

只有两通道都处于线性区时，比较才简化为wp/wv与ge/gs；chi=1时相等点alpha_c=(10−ge/gs)/[9(1+ge/gs)]。实际常有一项在二次区、另一项在线性区，不能把整个策略的行为概括成在alpha_c处突然切换。图中的Huber虚线给定同一时刻实测D后求解上述约束最小化，无拟合参数；它检验条件分配，不是入障前预测。

MAE先逐回合计算再平均，份额1对应100%；0.267即26.7个百分点，不是2.67%。两项均削减需求且总一阶削减>0.05m/s²时才定义分配份额。其余样本保留原数据和掩码。

一阶运动分解与精确v²κ差的平均绝对误差：H03为0.147m/s²，H05无力为0.0888m/s²。但K²e与实际曲率削减的误差分别为0.179、0.109m⁻¹，表明真实转弯过程不等于同心圆外移。同时，两项都处于二次误差区的样本只占份额可计算样本的726/10869（H03）与2040/29773（H05无力）。因此简化二次模型说明了方向，但不能准确指定份额或最优alpha；把它强行拟合到数据并不能补上真实动态机制。
