# S2：机制预测候选

目标：根据地形、请求速度和 alpha，先预测运行状态，再用侧倾恢复能力与原路径跟踪域判断是否存在明显瓶颈。

**主结论：10 cm 单脊、2.6 m/s 的候选选档为 alpha=0.5。** 两端档位的失败已有接触与角动量解释；此处将解释转为下一轮可以检验的预测。

本文件是冻结前候选，不表示 S3 已开始。

## 方法

物理组 101、102 分别建立临界运行状态映射；在五个已测 alpha 之间插值状态，再计算固定转向角速度、转角行程约束下的恢复余量和原跟踪器前视/航向余量。按两组可行票数、平均最小归一化余量排序。接触力作为机制诊断保留，尚未直接修正名义恢复包络。

这是数据确定运行点、模型计算余量的预测。两组投票不是已校准的成功概率；未以任务完成标签拟合预测器。
