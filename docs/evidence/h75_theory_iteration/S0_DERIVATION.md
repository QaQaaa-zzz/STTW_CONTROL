# S0：公式、源码与可检验命题

适用模型：固定前进速度v≥0.5m/s，小角度侧倾，转向速度u=δ̇；先讨论无外扰、无ESO/残差的名义系统。a=a₄>0、b=a₂(v)、c=a₁(v)。转向速度上限记为U；当前评测最终命令限速为3rad/s，基础控制配置中的限速另行区分。

## 1. 系数、闭环与参考零点

φ̈=aφ+bδ+cu，δ̇=u。

源码参数给出c≈−1.51526v，b≈1.78195−9.23941v²，a≈40.7619。u=−kδδ−kφφ−kωω+γδref，γ=kδ+kφ/q。

特征多项式为s³+(kδ+ckω)s²+(ckφ+bkω−a)s+(bkφ−akδ)=(s+5)³。

零初态下，将侧倾方程和转向反馈联立，得到

φ(s)/d(s)=(s+kδ)/(s+5)³；δ(s)/δref(s)=γ(s²−a)/(s+5)³。

参考通道的正零点为√a。相同闭环极点下，扰动通道分子仍随速度变化。单位角速度冲量的侧倾响应为exp(−5t)[t+(kδ−5)t²/2]。速度2.25→2.567m/s时峰值增加约4.87%。

## 2. 包络核符号：连续时间解析证明

任意可积控制|u(t)|≤U下，侧倾角的精确名义解为

φ(t)=φfree(t)+∫₀ᵗ Kφ(t−s)u(s)ds，

φfree(t)=φ₀cosh(λt)+ω₀sinh(λt)/λ+bδ₀[cosh(λt)−1]/a，λ=√a，

Kφ(τ)=c sinh(λτ)/λ+b[cosh(λτ)−1]/a。

其导数Kω(τ)=c cosh(λτ)+b sinh(λτ)/λ。

在v≥0.5时，c<0；b≤1.78195−9.23941×0.5²<0。源码对b的幅值下限处理保持符号。因此对于所有τ≥0，Kω<0；对所有τ>0，Kφ<0。这个结论来自系数符号与双曲函数正性，不依赖时间网格。

令

I(t)=∫₀ᵗKφ(τ)dτ=c[cosh(λt)−1]/a+b[sinh(λt)/λ−t]/a≤0。

逐点乘以−U≤u≤U再积分，可得对所有允许控制同时成立的包络：

φfree(t)+U I(t) ≤ φ(t) ≤ φfree(t)−U I(t)。

上下边界分别由恒定u=+U与u=−U达到。若某个t时下边界已超过+φc，或上边界已低于−φc，那么所有允许控制在该时刻都越过侧倾约束；由连续性，必在此前或该时刻碰到边界。反过来，包络与安全带相交并不保证存在一条控制能在整个时间段内保持安全。

加入转角行程|δ|≤D时，用分部积分改写为

φ(t)=φ₀cosh(λt)+(ω₀−cδ₀)sinh(λt)/λ+∫₀ᵗKω(t−s)δ(s)ds。

由于|δ̇|≤U且δ(0)=δ₀，任意可行转向满足δmin(s)=max(−D,δ₀−Us)≤δ(s)≤min(D,δ₀+Us)=δmax(s)。Kω恒负，因此将δmax代入积分得到最小侧倾包络，将δmin代入得到最大包络。这两条转向曲线均可实现：以极限速度转到行程边缘，再保持。由此同时处理转向速度和转角限制，与方案中的ψ=ω−cδ消元命题一致。

这是名义模型的精确控制包络。接触、速度变化、执行器滞后要进入对应动力学后再判断真实车辆。

## 3. 制动距离H和不饱和冲量容量的区别

外倾方向取σ=±1、r=σω>0。若从当前状态直到停止外倾，所有可用控制的回正加速度都不超过B，即ṙ≥−B，则外倾至少继续r²/(2B)。因此Hσ=φc−σφ−max(σω,0)²/(2B)<0是该假设下必越界的充分判据。必须沿整个制动段使用有效上界B；单个时刻测得的加速度不能替代它。

J_sat=U/max_t|u_unit(t)|是固定速度线性反馈对角速度冲量不触发转向速率限幅的上限。超过J_sat说明线性不饱和响应失效，不直接等于车辆不可恢复。它与H中的B、实际接触力矩积分分别具有rad/s、rad/s²、Nm·s单位。

## 4. 仿射奖励与偏好单调性的准确对象

对同一固定轨迹，完整折扣代价Fθ=(1−θ)F₀+θF₁；共同项分别包含在两个端点。逐项限幅保持源码中的仿射结构；实际终止替换也按同一轨迹计入。

对θ₂>θ₁，若策略π₁、π₂分别确实最小化对应Fθ，令ΔFj=Fj(π₂)−Fj(π₁)。最优性给出(1−θ₁)ΔF₀+θ₁ΔF₁≥0及(1−θ₂)ΔF₀+θ₂ΔF₁≤0，故ΔF₀≥0、ΔF₁≤0（内点；端点有并列最优时需一致的Pareto择优）。若共同代价随策略变化，不能把该结论直接套到删去共同项的裸速度/路径代价。

S1检验实际共享策略是否满足这些前提，不将训练目标的数学结构自动等同于网络已经达到最优。
