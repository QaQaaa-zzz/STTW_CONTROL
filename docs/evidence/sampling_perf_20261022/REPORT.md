# 容扰度采样优化实测

512并行环境，同输入分别运行原入口和packed reset候选。每情形每实现1次热身、3次交替计时，未停止共享GPU上的其他训练。结果为当前共享负载下短样本实测，不是独占GPU吞吐。

| 情形 | 原入口中位秒 | packed中位秒 | 实际重置槽 |
|---|---:|---:|---:|
| 无重置 | 0.653611 | 0.660347 | 0 |
| 17槽重置 | 0.667095 | 0.665524 | 17 |

两情形全部离散叶一致、全部数值有限；reward最大绝对差3.688e-7。全部浮点叶最大差分别0.004128/0.010132（不同量纲及聚合量的总览，不是物理状态统一误差）。用户允许微小数值差异，不追加逐位检查。原/候选编译29.55/31.69秒，独立于运行计时。

结论：本次没有可辨别吞吐收益，不为该候选重启当前训练，也暂不切换后续训练入口。保留实现与结果；优先完成模型效用评估。单步仿真约0.65秒，与此前128步采样约80秒数量级一致，说明当前采样主体已解释主要耗时；不能据此认定具体MuJoCo算子的耗时分布。

工程测试使用原真实初始状态；reset情形仅修改17槽终止计时器以触发重置，不作恢复能力或训练结果证据。累计32768 lower ticks。原始结果：runs/sampling_perf_v1/results.json；脚本：learning/cli/benchmark_tolerance_sampling.py。
