## 每组 6 条轨迹的判据

每格为原 OAT → 新回放，两个新回放结果相同。C10 表示满 10 秒，Hhold 要求完整末秒的横向、航向、速度误差都在门槛内，任务 C 还要求全程峰值横向误差 ≤0.40 m、速度 RMSE ≤0.15 m/s。提前终止保留在分母。

|场景|物理组|C10|Hhold|任务 C|
|---|---:|---:|---:|---:|
|平地|401|6 → 6|5 → 5|4 → 4|
|平地|402|6 → 6|5 → 5|4 → 4|
|4.2 m 脊|401|2 → 3|2 → 3|1 → 2|
|4.2 m 脊|402|2 → 2|2 → 2|2 → 2|
|4.5 m 脊|401|2 → 2|2 → 2|1 → 0|
|4.5 m 脊|402|2 → 2|1 → 2|1 → 1|
|全部 36 条| |20 → 21|17 → 19|13 → 13|

4.2 m 脊、401 组、α=0 是唯一 C10 翻转。原档在 2.745 s 到达侧倾终止线，本批走满 10 秒并满足保持条件，全程路径偏差峰值 1.482 m，任务 C 仍然失败。该组 α=.25 两次均走满且保持，峰值横向误差从 0.412 降至 0.234 m，任务 C 从失败转为通过。4.5 m 脊、401 组、α=.5 的峰值横向误差从 0.177 升至 0.516 m，任务 C 从通过转为失败。两条 C 翻转的速度 RMSE 均在 0.15 m/s 内。[三份数据的逐档终点、A/B/C、Ep、Ev 与 V](episodes.csv)
