## 效果是否达到

没有。主场景固定冲突窗口[2.5,4.5)秒：

| 方法 | 速度RMSE m/s | 转角RMSE rad | 全程峰值侧倾 rad |
|---|---:|---:|---:|
| 冻结残差底层B0 | 0.0094 | 0.1291 | 0.3753 |
| 加上层alpha0 | 0.1361 | 0.09146 | 0.4373 |
| 加上层alpha1 | 0.1375 | 0.09149 | 0.4377 |

上层把转角误差减小约29%，代价是速度跟踪变差，峰值侧倾反而更高；两alpha行为几乎相同，alpha1没有保住速度。超0.30rad工作界时长从基线2.75秒降至约0.89秒，但峰值仍越界，不能称姿态要求达标。

两场景均未满足回正0.5秒保持。最后[14,16)秒，主场景上层速度/转角/累计航向RMSE约0.25m/s、0.198rad、2.62rad；随机场景约0.235m/s、0.210rad、0.398rad，均高于恢复要求0.1m/s、0.04rad、0.05rad。相对于本次底层基线，累计航向误差明显减小，仍没有恢复。六回合无物理失败，不等于任务成功。

## 训练的主要问题

1. alpha区分没有形成：主场景两alpha全程速度差RMSE仅0.0040m/s，转角差0.00090rad，图中基本重合。
2. 成本触顶严重：全训练约37.6%，最后20轮约47.5%–47.8%；主场景恢复分类区间约90.6%的上层步触顶。触顶后的当步奖励无法区分更严重误差，是值得优先排查的学习障碍，不能仅据此断言唯一原因。
3. 有梯度且正常完成，但未形成稳定恢复：无硬KL或非有限停止，31轮按软KL提前结束epoch，实际接受1921epochs。全训练0/40960已结束回合物理失败，同时工作界违反约4.6%；不能把不倒等同收敛。
4. 新底层在此迁移任务中本身不可靠回正：基线最后2秒转角RMSE主场景0.232rad、随机0.281rad。旧Actor原任务为固定几何弯道，本次使用governed指令历史路径适配，且源XML与V3不同。不能把旧任务效果直接当新任务底层能力保证，也不能断言ECBC弱是上层学不好的唯一原因。

建议下一步先检查冻结底层能否独立跟好转向撤销及变速指令，再定位成本触顶与alpha区分问题；不建议仅在当前设置继续增加轮数。本次未启动新训练或物理回放。
