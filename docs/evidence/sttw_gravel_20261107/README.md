## 本轮结论

冻结 H75、橙色 Local300 与 ECBC/ESO，物理／底层／中层周期分别为 **0.2／5／20 ms**。G0–P4 均为评测，**零训练更新**。

|P4方法|任务合格／40|物理失败／40|
|---|---:|---:|
|固定 α=0|5|3|
|固定 α=0.5|10|2|
|固定 α=1|11|7|
|Task-only|15|2|
|Task+Phase|16|2|

Task+Phase 相对 Task-only 为 **2胜1负，净增1/40＝2.5个百分点**，低于冻结的10个百分点门槛。因此不采用本次 Phase 增量，不扩展至500条，不在 TEST 上重调能力表或新增 PPO。[原始门槛判定](p4/selection_gate.json)。Task-only 相对已测最佳固定档11/40具有描述性收益；这来自两个新布局种子，不是普适保证。

P4 的200条是五方法×40配对上下文的**逻辑结果**，对应152条独立实际采样轨迹；同上下文相同 α 复用一条物理轨迹。别名和选档保存在 [contexts.json](p4/contexts.json)。选择器仅在共同热启动状态下利用理想地图预瞄选一次档，此后保持，未验证在线感知或残余状态自适应。

## 各阶段发现

- **G0：4条**。实际前后轮触石已确认；10/5 mm 网格比较未通过全部工程容差，按既定回退采用5 mm。没有宣称5 mm已独立收敛。
- **P0：144条**。平地／单脊／S2／S5各36条，存活36／30／32／4；S5没有任务合格。存活与任务合格分别统计。
- **P1：360条矩阵**。复用72条匹配P0轨迹，新采288条。高度、密度、聚集改变真实接触和任务偏好排名；2 cm石子超出本次已证明的任务合格能力。聚集并非所有任务都更困难。
- **P2：150条**。独立延长路线，不能与旧路线混排。三簇间距0.2／0.4／0.8 m的前后轮触石重叠均值9.22%／18.49%／0%；43组配对第三簇入障状态在0.4 m下残余响应更大。这是布局相关相位证据，未证明普适共振定律。
- **P3：75条**。15组同起点候选的切档前保存状态与指令完全一致；仅新增1条Task A合格，B/C无新增。不采用恢复阶段选择器、不扩至300条。
- **P4：200逻辑结果／152实际轨迹**。按上述冻结门槛结束，保留原STTW固定偏好和接触相位证据。
