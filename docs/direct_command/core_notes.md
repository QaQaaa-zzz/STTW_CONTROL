# V3 core interfaces

`direct_command_policy.py` consumes the frozen JSON spec as a dictionary. All physical and policy arrays are JAX arrays; operations are pure and can run inside a JAX scan. No function advances a simulation or samples a command.

- `initial_correction(dtype)` returns `CorrectionState(offsets[2])`. `map_latent(z,spec)` gives the unfiltered target correction. `correction_tick(offsets,z,raw,spec)` returns `(new_offsets[2], governed[2], flags)` for one 5 ms tick. `flags` contains `rate_clipped`, `reference_clipped`, and `policy_fault`.
- `raw_context(raw[2],rates[2],settle_clock,cc,spec)` returns `(chi,g,eligible,next_clock)`. `cc` is the existing `ControllerConfig`. Use the current `g` for both Actor observation and reward in this interval, then store `next_clock` once after the interval. New ineligible raw commands force current `g=0` and `next_clock=0`.
- `make_frame(*,measurement,forward_speed,previous_governed,previous_final_command,previous_bounded_residual,raw,raw_rates,eso_equilibrium_shift,cc)` returns 20 **raw** fields in the JSON order. `measurement[7]` follows existing `RecoveryEnv.measure`: roll, roll rate, steer, steer rate, yaw rate, forward rear shaft rate, forward front shaft rate. The previous values must come from the preceding physical control tick. `previous_bounded_residual` is the pre-final-clip additive residual.
- `initial_history(spec)` and `push_history(history,frame)` maintain oldest-to-newest `(16,20)` frames and 16 masks. `assemble_observation(history,alpha,epsi,chi,g,settle_clock,offsets,spec)` returns `(obs[345], clip_fraction, policy_fault)`. The context starts at index 336, with α at index 336. The function does not hide nonfinite observations.
- `DirectCommandActor` is the Flax 345→128→128→64→2 mean network. `initialize_policy(policy)` initializes an RSL ActorCritic's `.actor`, `.critic`, and `.log_std` to the V3 contract; `export_actor(policy)` returns Flax parameters. The caller should verify raw Gaussian mean parity on a batch before publishing a checkpoint.

`direct_command_reward.interval_cost(*,alpha,chi,g,raw,actual_speed,actual_steer,heading_error,roll,roll_rate,executed_offsets,final_command,previous_final_command,spec)` returns raw/effective nine-component dictionaries, raw/effective cost rates, cap indicator, reward for one 5 ms interval, and speed/steer weights. `failure_reward(remaining_including_current,spec)` replaces the entire 20 ms reward on the first physical failure; the caller must omit the four ordinary interval rewards for that failed policy step.
