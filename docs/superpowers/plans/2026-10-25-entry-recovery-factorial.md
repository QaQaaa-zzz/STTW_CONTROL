## 待区分的候选解释

1. **进入过程重要**：B提前改变速度、转向与侧倾/历史，使同一脉冲更容易扛住。预测B→A仍存活，而A→B不能保住相同事件。
2. **后续动作重要**：真正的可用增量在受扰后的参考。预测A→B能够保住原A的失败，B→A失去B的收益。
3. **两者交互**：只有B→B有效，不能单归于任何一段。
4. **任务/训练目标取舍**：跨组合不能减少名义代价或增加任务完成；此时不以混合控制或新评分器继续维护故事。

这些是待检验解释，不是按假设自动评分或宣布因果机制；只对已选DEV事件作解释，不对其他路线外推。

## 指标与研究判断

逐事件比较不触地、原目标联合任务、原alpha运行/终止成本、速度/路径/航向连续误差及完整XY。记录交接前后实际v、delta、phi、phi_dot、参考与饱和、Actor合法性；精确ESO若未逐tick导出需标未知，不补造。保留完整初末状态。观察不同方法在交接前形成的真实状态，不要求强行相等或制造新的bitwise门槛。

按同一进入过程比较不同后续，以及同一后续比较不同进入过程；报告所有相反方向/晚时刻/无扰损失。缓存对角与新交叉分支保持原真实成本，不把缓存运行计成新积分。

若存在任务代价可接受的交叉增量，再单独提出不读取真实事件的因果触发与原alpha恢复测试，并比较同触发下的简单速度/ESO规则。若只有oracle切换有用，不能直接发布为控制方法；若交叉也没有用途，停止这项组合，保留强基线与能力耦合证据，再审视约束训练或任务范围，不调切换点反复搜索。

## 与容扰度及论文的关系

这里检验的是同一扰动合同下，完整闭环可承受能力在进入与恢复两段如何形成。旧自由转向速率E_min公式未被修复或当约束使用，不拟合E_b/gamma/T。若发现明确进入状态作用，才有理由考虑参考条件能力与提前状态塑造；若主要是后续动作，则优先研究何时需要恢复控制、何时能回到用户偏好。

这个factorial自身不是算法新颖性。可发表的主方法仍需在无未来信息、同参考权限和原alpha代价下超过普通PPO/简单规则，并作独立确认。方法辅助采用Scientific Agent Skills hypothesis-generation、scientific-critical-thinking与experimental-design；Kassis等（2026），https://doi.org/10.48550/arXiv.2609.00065 。
