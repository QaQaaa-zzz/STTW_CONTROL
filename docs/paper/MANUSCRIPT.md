# 冻结底层单轨机器人的偏好条件参考控制与闭环抗扰表现

**Preference Conditioned Reference Control and Closed Loop Disturbance Response of a Single Track Robot with a Frozen Lower Controller**

> 内部研究主稿，证据截止2026-10-27，非投稿就绪。人类作者核验、具体Transactions期刊和最终独立验证尚未完成。主文按科学问题组织；全部旧试验、反例、工程审查与证据索引原文保留于[EVIDENCE_DETAILS.md](EVIDENCE_DETAILS.md)，精简前26页PDF及哈希另行归档。本次不新增实验，不改变数字、标签、模型采用或台账路线。

## 摘要

单轨机器人必须在任务执行中动态保持平衡，路径与速度偏好因而可能同时改变跟踪表现和受扰状态。本文研究冻结ECBC、ESO和local300底层外的偏好条件参考修正，并区分原用户效用、原目标首达与真实触地。在原生四上下文中，匹配用户偏好的H75端点相对固定中点在8/8相关配对中费用更低；固定新几何验证中，匹配偏好相对其他固定执行偏好20/24费用更低，但相对zero仅3/12总费用更低，任务三项均未更低。低速受扰面板中，后继权重相对H75到达由66/96变为75/96，整窗存活均85/96且有逐例增失；与zero比较也存在任务—存活取舍。普通重规划可改善目标接续，但强简单控制覆盖若干主要结局。因此，现有证据支持条件偏好用途及参考对闭环表现的影响，尚未建立普遍优于简单控制的容扰协调方法。旧解析能量式仅保留为模型解释，不作为经过验证的防摔阈值。

## 1 研究问题与相邻方法

研究问题是：用户的路径—速度偏好怎样改变动态平衡机器人完成任务和承受扰动的表现；在不重训底层、只允许有限参考修正时，这些变化能否带来普通控制未覆盖的实际用途？用户alpha始终不变，任务目标始终是原世界坐标目的地。这里不要求策略无敌，也不以一次成功或比弱父策略好就认定方法创新。

本文当前已实现的对象是偏好条件参考控制。现阶段的可核结果包括原生偏好响应、强普通控制下的适用范围，以及任务到达和真实触地可分离的配对证据；尚未成立的是一个可部署且具有独有防摔增量的容扰选择器。本文不把上述证据点包装成三个新算法。

偏好条件多目标控制[1,6,7]、恢复预测与任务调度[8]、参考治理及预测安全过滤[2,9–11]已有直接近邻；自行车学习控制亦非空白[3]。分层、冻结底层或加入alpha本身不足以支持首次性。区别必须落实为真实可执行参考权限下的具体控制后果，并由强对照支持；既有理论中的模型误差、终端集或稳定性前提尚未在本系统建立，不能借用其安全保证。定向阅读范围及出版方访问限制完整保留于证据明细，不冒系统综述或同条件复现。[E035,E049,E061]

## 2 系统与已实现方法

![当前评测控制结构](figures/control_architecture.svg)

图1：中层改变参考，不直接输出电机动作。灰色比较项在不同实验中按协议固定；近期扩展接口比较中的zero中层仍包含共同底层、路径跟随、几何反馈和短速度支持；原生偏好面板保留原配置。该图为近期扩展评测栈的结构说明，不是新优化器或安全证明。

给定原始空间路径p(s)与速度请求，路径跟随器产生名义参考r0=[v0,δ0]。中层读取351维观测：16帧×20字段、16个有效掩码和15个上下文字段，包含外部偏好α；输出两个latent，顺序为速度、转角。当前单网络采用已冻结的alpha调制结构；评测时权重不更新。[E017–E018]

```text
z_mid = πθ(history, context, α)
Δr_target = tanh(z_mid) × existing asymmetric scales
r_command = original filter/slew/bounds applied to (r0, Δr_target)
```

α=0表示路径优先，α=1表示速度优先。原用户α用于原任务代价评价，不能为安全把它偷偷改成另一个偏好后重新打分。底层自身的lower_alpha与中层α不同，冻结底层身份不随用户偏好变化。

共同底层为ECBC、ESO及冻结local300学习残差，最终经统一执行器约束作用于仿真机器人。底层残差与中层参考网络是不同模型。执行参考改变后，底层实际输出取决于完整物理状态、ESO、历史和执行器状态，不能把转向角速度当成中层可自由选择的输入。

原生实验与后续共同迁移接口分别冻结配置；它们的速度修正范围、几何反馈、短支持及域外接续可能不同，不能从一个接口的结果推断另一个接口的能力。所有比较先绑定完整起始状态、权重、normalizer、路径、时间和参考权限。中层50Hz、底层200Hz，每底层tick含25物理子步；5Hz对照只保持中层target，底层、跟随器、滤波和历史仍继续演化。[E008,E017–E018,E078]

双网络、蒸馏单网络、H75及后续训练分支的代码/权重身份和真实迭代关系保留于[冻结版本入口](../FROZEN_MIDDLE_NETWORKS.md)。H75是固定主要对照，后继权重不因训练较晚就默认在所有任务更强；本文不将不同架构、奖励和课程同时变化的比较解释为单因素因果消融。[E012,E014–E016,E050]

## 3 评价与数据角色

### 3.1 原目的地与物理结局

到达：按各试验预声明的观察窗（旧面板10秒，重规划比较20秒并另报同轨迹10秒前缀），在首次触地或故障之前，有真实记录XY进入原世界目标点1米圆。它不要求末速度、航向或保持窗口，不以几何域退出否决已经发生的到达。1米是当前工作口径；0.5、0.75米和近期预声明1.25米仅作相应敏感性，原标签保留。

整窗不触地：完整观察该试验声明的10秒或20秒且未发生真实非轮触地；数值/控制故障或不完整记录单列，不强行作控制失败。近期contact-only诊断保留侧倾/任务域标记作遥测，不将工作侧倾阈值当真实摔倒。原生评测仍按各自冻结合同，将首个native physical/domain/fault停止作为到达观测终点，不能直接用contact-only口径替换；第4.1节H75/current原四上下文的16条实际均完整且没有原生物理/域失败，这不涵盖全部历史native面板。[E001,E011]

四类结局应分别报告：到达且全窗活、未到达但全窗活、到达后触地、未到达且触地；另保留未知。到达不是仅穿过路径终点截面，不触地也不是已经回到任务或具备环境避障安全。

### 3.2 原用户效用与实际容扰对象

原用户代价Jα由同一配置的原奖励分项逐实际tick重算；失败终止替代、全部轨迹均值和共同存活条件均值分开。不同α的原始成本不直接互相排名。同一条实测轨迹可以在不同用户效用下重评分，但这不是换α后真实闭环的反事实轨迹。重规划之后，沿新执行路径计算的V3路径误差只作该执行路径诊断，不能静默冒作原用户路径效用；当前尚未建立可跨所有原路/改路合同直接比较的统一Jα，故重规划结果主要分报原目标首达和物理结局。

闭环容扰对象必须指定完整状态ξ、策略π、参考方案、力方向/波形/持续时间、起扰与观察窗。对这些条件固定后，记录实测通过、触地失败与未知标签。未经单调性检查的离散成功档不能视为连续安全区间，也不能断言超过某个已测成功档必然摔倒。本文当前主要报告指定扰动事件的真实结局，不宣称已获得通用牛顿阈值。

为使研究对象可检验，定义（研究定义，不是新增已测结果）：

```text
xi = 完整物理/ESO/控制器/local300历史/FIFO/参考滤波与限幅/时钟
     + 路径与投影/follower/relay与gate/适用的随机状态
sigma = (方向d, 波形h, 持续时间Delta, 起扰时刻tau, 观察窗H)
C(pi, r; xi, sigma) = { F >= 0 : 完整闭环在[0,H]内无非轮触地 }
```

其中r是经原接口执行的参考方案，π包括冻结底层及所声明的中层决策。只有完整、无故障且整窗未触地者才记实测通过；在故障或截断前已明确触地者记触地失败，其余未能完整观察的分支记未知，不放入已测整窗不触地样本集合。比较不同用户α的完整回合，回答“偏好形成的进入过程与抗扰表现如何耦合”；克隆同一完整中途状态后再改参考，回答“此状态下参考干预是否有局部作用”。两种问题不能互相冒充；更换路径/投影后不再称完整闭环状态相同。

实际报告已测事件的通过、触地失败与UNKNOWN三态观测，而不是为所有力档给出完整的C成员判定。若汇总从零开始连续通过的已测网格前缀，其最大档仅为网格摘要，不证明档间连续安全或更大力一定失败。方向、时长和时刻改变后须重新标明条件；当前物理Critic或E_min的标量不能直接换算为该集合的牛顿半径。

### 3.3 配对与推广范围

同一实际轨迹在多个评价权重下重评分不增加物理样本数；同一祖先的力档/时刻也不是独立训练重复。不同任务栈分别报告，不合并分母或把几项局部正例拼成安全方法。原生停止、contact-only续观测、域外held和重入的语义按各冻结合同解释；域退出没有触地时，其后物理结局可能未知，不能算整窗存活或摔倒。完整中途快照需包括ESO、历史、FIFO、滤波、投影与时钟，位置和速度相同不足以称同状态。

同源原设计小扰动也需单独检查。固定原有±8/±12N、1/2秒起扰、.1秒持续的全部96条H75历史轨迹（execution0/.5/1，每种32条），不新增力档或物理；192用户评分形成64个相关端点—中点比较。用户α0对应端点在29/32总成本、28/32三任务通道较低；用户α1分别30/32及32/32，原无扰逐例优势并非全部保留。原目标1m到达按执行0/.5/1分别31/32、32/32、28/32；五个未达最近距仅1.010–1.083m，应解释为原圆边界附近的标签损失，不能渲染为严重失败。96条均完整10秒、无原physical/domain/fault记录；本面板没有防摔二元增量，不能用费用优势代替更高容扰能力。[E064–E065]

这些力在各策略自身起扰航向下取横向后固定于世界，实际配对方向差最大8.5063°，不是同世界力向量反事实。全部96条有20个5ms非零冲量记录且覆盖脉冲；没有同受扰zero强对照，不判断学习抗扰必要性。完整8组XY、五次总费用翻转、五个目标边界损失及连续距离均保留。结论仅为原已测小扰动下偏好效用多数保留，不是新控制方法、独立测试或连续安全力边界。[E064–E065]

### 4.2 固定新几何与强普通控制

在前组之后固定75°/R2.1米与110°/R2.65米左右四路线、请求2.6米/秒、用户α0/.5/1，执行原native10秒及原停止合同。H75的50Hz、5Hz、既定26候选/1秒预测/5Hz普通动态参考选择、原静态平衡规则各12条，zero每路线1条共4条；共52真实轨迹、156固定轨迹跨用户评分。沿用同prepared bank3/seed77001，经原native reset，未换权重、训练或外力；同源初态及可能与课程邻近的几何不称独立TEST或训练重复。[E078–E079]

|---|---:|---:|---|
|H75 50Hz|12/12|12/12|对zero原J较低3/12、较高9/12|

全部52条无physical/contact/domain/fault，故本组不提供防摔增益或容扰力阈值证据。H75 50Hz对zero的原J差值为−2.150688至+13.314258；其任务三通道在12/12均高于zero，不能以总J的3例降低宣称任务项全胜。静态规则在本面板未激活，和zero不是两个不同有效干预；小数值差异不包装机制增量。110°两路线的6个用户组合，H75原J均高于zero；75°的6组则3低3高。[E078–E079]

同一H75匹配用户α执行，对其余两个固定执行α共24个非自配对，原J20低4高；这支持条件偏好而非“原α总是最佳”的校准主张。50Hz对自身5Hz仅4/12原J较低、8/12较高，不能把频率本身当作稳定优势；同频对普通预测8/12较低、4例反向全保留。普通预测需要完整模拟状态和暂停仿真计算，且此处仅固定候选/视界；它的失利不证明全部RG/MPC劣于学习。[E078–E079]

独立非提出者从52 raw重建156项十通道评分，并核全部50实际块、150预测候选组、argmin及实际发布。原J重建最大差5.842×10⁻⁶，主/独立156评分最大差约1.107×10⁻⁶。预测2,919,084有效lower、3,120,000槽；610条短候选均因预测域停止，无物理停止或未知，不能误写成真实执行摔倒。实际104,000lower/槽，0训练；编译48.211秒、预测1,610.789秒、实际推进157.200秒、全流程1,836.719秒，非实时性能证明。[E078–E079]

裁决：本固定验证保留H75相对自身固定偏好和本有限预测基线的条件用途，同时明确zero多数原J及全部任务三项更低。它收缩普遍任务优越性的主张，不因原J负结果继续调候选、几何或加训。全部三张XY、12时序与12分量图、52逐例、156评分和全部费用反例见[完整结果](../../runs/native_frozen_geometry_validation_v1/analysis/RESULTS.md)；图形已目视三张全XY及一张时序，未声称全部24诊断图均独立目视。当前仍不足以认定Transactions投稿证据充分。

### 4.5 参考确可改变防摔，但尚无联合选择方法

右90度/R1.1米、请求1.5米/秒、五alpha、0/±16/32/48/64N的旧90条配对中，原task64/CONSTANT参考支持各45条，整窗不触地20/45与30/45，配对10增0失；一米到达14/45与13/45，4增5失。规则在受扰前已经改变进入状态，不能称同受扰状态的救回；它也不是旧解析公式驱动的控制。结果支持有限参考能改变实际防摔及任务代价，尚不证明学习选择器必要。[E030–E031]

同合同补齐的zero子集以及完整434条方向性审查进一步限制主张：zero覆盖已测配对防摔，却没有覆盖所有条件目标到达；六角色对zero均有到达增失。完整434中的alpha存活反转仅2/360、只在一个路线/时刻，不能包装普遍机制。参考库、即时切alpha、支持/门控、信用学习、特权见证及局部模型试验的正负结果均保留，但未建立新的联合容扰决策方法。相应固定家族封存，不因本文表述收窄而删除条件资产或重开调参。[E070–E077]

## 5 旧解析式的物理含义与适用限制

早期固定速度局部模型采用不稳定模态坐标和折算脉冲：

```text
λ = sqrt(a4),     b = a1 + a2/λ
z = ω + λφ + (a2 δ + d_hat)/λ
Kτ = γ exp(−λτ) [1 − exp(−λΔ)] / λ
W = b² [1 − exp(−2λT)] / (2λ)
E_min(F) = (z + Kτ F)² / W
```

该式在其假设下衡量自由实际转向速率使终点z归零的最小L2控制努力。实际中层只能改有界参考，经过冻结闭环、历史、滤波与执行器后才改变实际速率；终点归零不保证中途不触地。变速和ESO变化也改变坐标导数。故本文不将能量预算拟合成经过验证的全过程防摔阈值，也不把代理的性能标签误判直接写成真实摔倒误判。原推导和适用性审计保留于[公式解释报告](../evidence/tolerance_progress_20261022/formula_explainer/README.md)，当前仅作解释对照。

一个额外的代数检查限制了“低速不可恢复”的解释。对原固定速度三状态模型，能控矩阵行列式D=a4·a1²−a2²；当前系数在约1.206865米/秒处D=0，但失去控制的是稳定极点−sqrt(a4)，不稳定方向b_plus仍约−3.65743/s。因此不能从该根断言物理不可稳定，也不能以既有gain hold分支直接解释此前实际触地。该检查没有ESO/local300/执行器积分，不修改任何底层；一般的稳定模态不可控现象已有自行车研究先例[15]。完整推导、适用边界与图见[数学核查](../../runs/ecbc_modal_authority_math_v1/REPORT.md)。[E080–E081]

## 6 讨论与尚缺证据

偏好网络内部能表达取舍，不等于比所有外部控制器更好；目标首达改善不等于整窗防摔改善；更低侧倾或更小局部能量指标也不等于更大可承受推力。当前最强证据是这些对象可分别测量且存在条件性任务收益。它没有形成在原alpha下、强简单控制尚未覆盖的普遍安全协调能力。

任务和系统研究可以形成论文贡献，不要求凭空发明全新算法，但必须明确相邻工作未回答的具体问题，并提供对应证据。本稿目前缺少足以支持Transactions贡献强度的独立新知识或控制增量；大量相关DEV轨迹、不同栈正例或AI审查均不能替代独立确认。已有训练重复若配方不同，不能当同方法重复；当前实机部署未开始，不能补写硬件、作者、资助或审批事实。

用户已明确一米首达优先。原整窗V3包含首达后跟踪费用，它与任务期间代价是不同用途，不能事后互换以改变既有排序。改变执行路径也会改变路径误差的空间语义；同原alpha并不足以让新路径V3等同于原任务效用，须保留原路径与改路诊断的区别。新首达前后费用分账仅是已实现的离线工具，未接训练、不作为新控制模块。下一方法必须有可执行的控制差异与收益假设，先经过scientific收益/反证审查，再决定必要验证；不要求零失败，也不靠挑情境或修改目标让神经方法胜出。
