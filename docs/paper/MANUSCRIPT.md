# 冻结底层单轨机器人的偏好条件参考控制与闭环抗扰表现

**Preference Conditioned Reference Control and Closed Loop Disturbance Response of a Single Track Robot with a Frozen Lower Controller**

> 内部研究草稿；证据截止2026-10-27。当前稿更新任务、真实参考接口及已完成仿真结果，不宣称新抗扰协调算法、形式安全保证或实机验证已经成立。它不是投稿就绪稿，人类作者核验与具体Transactions期刊尚未确定。旧2026-09-12直接电机残差稿、导出件和图已逐文件校验归档到history/20260912_snapshot，不与本稿合并计数。

## 摘要

必须动态保持平衡的单轨机器人在跟踪弯道时，路径与速度偏好会改变其进入状态及受扰后的运动。本文研究冻结底层控制器下的偏好条件参考控制，并分别评价原任务效用、目标到达和真实触地。中层输出速度与转角参考修正，经原滤波、变化率和幅值限制后，由ECBC、ESO及冻结local300残差底层执行。已有原生四上下文试验及新增匹配zero对照显示H75可表达路径—速度取舍并降低工作侧倾，但H75/zero均8/8到达，不能以此宣称完成率提升；在匹配低速受扰面板中，当前权重的1米目标到达由H75的66/96提高到75/96，但整窗存活均为85/96，且逐例存在存活新增与丢失。原生较高速任务中H75又保留更好的到达和路径表现，故后继权重不是全域升级。另两路线20秒比较中，标准几何重规划使H75到达从9/12变为12/12、未新增存活；强zero原路亦12/12到达存活，故不构成新抗扰机制证据。另在新70度/R2.1、2.2米/秒的共同20秒重规划合同中，四法均20/20不触地，H75/current各18/20到达，zero/静态规则均20/20；未建立比较性容扰增量。同完整中途状态分支证明有限参考干预存在局部机会，但所用切点具有事件时刻特权。名义参考优化、固定参考选择迁移及解析支持权限分离未建立超过强简单对照的新抗扰机制。现有证据支持条件性的任务收益和任务—稳定性取舍，尚需针对具体任务差异的独立验证，不能把各模块的小正例拼成普遍安全方法。

## 1 研究问题和贡献边界

研究问题是：对于必须动态平衡的两轮机器人，用户路径—速度偏好如何改变任务收益和抗扰表现？在底层不重训、上层仅能修改有界参考的条件下，哪些收益可以兑现，哪些来自进入状态、任务标签或普通反馈？

例如，同一条弯道上，路径优先策略与速度优先策略可能进入不同速度、侧倾和转向状态。随后同一世界方向外力产生的结果可以不同。但“更快”“更平稳”或某个解析余量更大都不自动意味着整段过程不摔，也不意味着受扰后能够到达原目标。

本研究拟发展的核心是**偏好条件下的闭环容扰能力及其有限参考协调**：用户偏好不仅改变任务误差，还可能改变机器人进入怎样的动态平衡状态；中层是否能在保留原用户评价的条件下，用可执行参考调整改善不触地能力，是待检验的控制问题。容扰度仍是研究对象，旧解析能量式不再承担已验证控制模块的角色。此定位是研究命题，不是“偏好必然改变防摔能力”的既成结论。

### 1.1 从已完成实验提炼的研究切入点

|研究切入点|现有证据能支持什么|尚缺什么、何时放弃强主张|
|---|---|---|
|偏好、进入状态与闭环能力的耦合|原生H75在路径优先时更贴路、速度优先时更保速，并保持较低工作侧倾；存在可解释的行为取舍。[E025–E027]|无扰偏好收益不是防摔收益。需冻结方法后在新情境配对比较触地与原任务代价；若只剩侧倾成本优势，就按具体任务效用贡献表述。|
|真实参考权限下的动态协调|固定静态规则的参考目标满足其工作侧倾预算，但实际动态仍超过预算，H75保留条件收益；静态参考评价不能代替执行后果。[E026–E027]|只挑战这套静态规则；没有证明所有动态参考治理或传统控制不如学习。需检验同权限简单动态方法能否覆盖收益。|
|防摔与任务接续的分工|标准重规划使H75目标到达9/12→12/12，而两臂均12/12存活；任务接续与防摔可分别发生，且zero原路已12/12到达存活。[E021–E023]|标准Dubins和延长时限不是算法创新。潜在增量须来自重规划共同存在时仍能兑现的偏好—容扰协调，不能把几何成功算作救车。|

以上是具有具体反例约束的研究切入点与系统发现，不是三个已经成立的新算法。任务贡献可以成立于动态平衡、用户偏好、冻结学习底层和有限参考接口这一明确问题，但组合这些词本身不足以证明新颖性。

### 1.2 拟发展的控制贡献及其可证伪性

**方法提案，尚未实现或验证：**保留用户α与原速度请求，比较现有接口真正可执行的参考方案；在满足指定扰动设计范围内的闭环表现要求的候选中，选择原α任务代价与参考变化代价较小者。若没有候选达到要求，报告能力不足并执行预声明退化方案，不虚构安全保证。容扰评价必须针对“采用该参考方案后的完整闭环”，不能只看当前侧倾或旧z。

这一提案的研究价值在于检验“同等抗扰表现下能否减少偏好代价，或同等任务代价下能否改善抗扰表现”。固定规则、充分普通训练、共同重规划和零中层必须保留；若收益被它们覆盖，则不把选择器或额外网络继续列作主要贡献。现有证据没有完成这项比较，因此正文不将该提案写成已提出并验证的方法，也不宣称Transactions投稿充分性。

### 1.3 相邻方法与本文尚待建立的差异

相关工作已有单策略偏好输入和跟踪—外力顺应取舍[1]、通过修改参考避免侧翻[2]及自行车机器人学习动态行为[3]。进一步的PROMO将运行时任务偏好与固定运动先验分开[6]；PCHC研究偏好条件单策略及分目标Critic[7]；RAYA以有限窗可恢复性预测修改MPC约束，并以有界调度改变任务权重[8]。因此“偏好＋抗扰＋调整参考或优先级”的组合本身不承担首次性。

本文的约束是只能改变冻结闭环外的有限参考，不能直接自由选择执行器输入或修改底层优化问题。这一区别需要通过同权限强对照证明其控制后果，不能仅凭接口不同宣称新方法。固定奖励先验也不等于冻结底层网络。文献[1]还包含瞬时扰动测试，外力顺应目标与本文防摔力扫描仍应区分。上述新近文献按预印本引用；本轮核对[1,6–8]原文方法及相关评价段落，[2–3]仍限既有摘要范围，未完成系统综述或同条件复现。[E035]

## 2 系统与真实控制权限

### 2.1 分层接口

![当前评测控制结构](figures/control_architecture.svg)

图1：中层改变参考，不直接输出电机动作。灰色比较项在不同实验中按协议固定；近期扩展接口比较中的zero中层仍包含共同底层、路径跟随、几何反馈和短速度支持；原生偏好面板保留原配置。该图为近期扩展评测栈的结构说明，不是新优化器或安全证明。

给定原始空间路径p(s)与速度请求，路径跟随器产生名义参考r0=[v0,δ0]。中层读取351维观测：16帧×20字段、16个有效掩码和15个上下文字段，包含外部偏好α；输出两个latent，顺序为速度、转角。当前单网络采用已冻结的alpha调制结构；评测时权重不更新。[E017–E018]

```text
z_mid = πθ(history, context, α)
Δr_target = tanh(z_mid) × existing asymmetric scales
r_command = original filter/slew/bounds applied to (r0, Δr_target)
```

α=0表示路径优先，α=1表示速度优先。原用户α用于原任务代价评价，不能为安全把它偷偷改成另一个偏好后重新打分。底层自身的lower_alpha与中层α不同，冻结底层身份不随用户偏好变化。

共同底层为ECBC、ESO及冻结local300学习残差，最终经统一执行器约束作用于仿真机器人。底层残差与中层参考网络是不同模型。执行参考改变后，底层实际输出取决于完整物理状态、ESO、历史和执行器状态，不能把转向角速度当成中层可自由选择的输入。

## 3 评价对象和数据角色

### 3.1 目标到达与不触地分开

到达：按各试验预声明的观察窗（旧面板10秒，重规划比较20秒并另报同轨迹10秒前缀），在首次触地或故障之前，有真实记录XY进入原世界目标点1米圆。它不要求末速度、航向或保持窗口，不以几何域退出否决已经发生的到达。1米是当前工作口径；0.5、0.75米和近期预声明1.25米仅作相应敏感性，原标签保留。

整窗不触地：完整观察该试验声明的10秒或20秒且未发生真实非轮触地；数值/控制故障或不完整记录单列，不强行作控制失败。近期contact-only诊断保留侧倾/任务域标记作遥测，不将工作侧倾阈值当真实摔倒。原生评测仍保留原生停止语义；其16条实际均完整且没有原生物理/域失败。[E001,E011]

四类结局应分别报告：到达且全窗活、未到达但全窗活、到达后触地、未到达且触地；另保留未知。到达不是仅穿过路径终点截面，不触地也不是已经回到任务或具备环境避障安全。

### 3.2 原用户效用与实测容扰能力

原用户代价Jα由同一配置的原奖励分项逐实际tick重算；失败终止替代、全部轨迹均值和共同存活条件均值分开。不同α的原始成本不直接互相排名。同一条实测轨迹可以在不同用户效用下重评分，但这不是换α后真实闭环的反事实轨迹。

闭环容扰对象必须指定完整状态ξ、策略π、参考方案、力方向/波形/持续时间、起扰与观察窗。对这些条件固定后，记录实测通过、触地失败与未知标签。未经单调性检查的离散成功档不能视为连续安全区间，也不能断言超过某个已测成功档必然摔倒。本文当前主要报告指定扰动事件的真实结局，不宣称已获得通用牛顿阈值。

为使研究对象可检验，定义（研究定义，不是新增已测结果）：

```text
xi = 完整物理/ESO/控制器/local300历史/FIFO/参考滤波与限幅/时钟
     + 路径与投影/follower/relay与gate/适用的随机状态
sigma = (方向d, 波形h, 持续时间Delta, 起扰时刻tau, 观察窗H)
C(pi, r; xi, sigma) = { F >= 0 : 完整闭环在[0,H]内无非轮触地 }
```

其中r是经原接口执行的参考方案，π包括冻结底层及所声明的中层决策。只有完整、无故障且整窗未触地者才记实测通过；在故障或截断前已明确触地者记触地失败，其余未能完整观察的分支记未知，不放入已测整窗不触地样本集合。比较不同用户α的完整回合，回答“偏好形成的进入过程与抗扰表现如何耦合”；克隆同一完整中途状态后再改参考，回答“此状态下参考干预是否有局部作用”。两种问题不能互相冒充；更换路径/投影后不再称完整闭环状态相同。

实际报告已测事件的通过、触地失败与UNKNOWN三态观测，而不是为所有力档给出完整的C成员判定。若汇总从零开始连续通过的已测网格前缀，其最大档仅为网格摘要，不证明档间连续安全或更大力一定失败。方向、时长和时刻改变后须重新标明条件；当前物理Critic或E_min的标量不能直接换算为该集合的牛顿半径。

候选参考协调的简写为：

```text
min over executable reference plans r:  J_alpha_original(r) + rho * D_reference(r, r0)
subject to:  frozen closed loop meets the declared disturbance-design requirement
```

此式只澄清决策对象，不构成新优化算法或形式安全证明。扰动设计范围可对控制器公开，本次具体起扰时刻与方向不可泄漏。J始终使用原用户α、原速度请求和声明任务；规划后当前路径的V3成本需另作诊断，不能悄悄替换原任务效用。实测容扰集合、预测器有效性与选择器收益必须分别验证。新增正则D及其权重rho尚未确定；它可能改变原J_alpha对候选的排序，因此原用户代价与参考变化须分开报告，不能仅凭组合目标声称用户效用排序完全保持。

### 3.3 比较边界

原生较高速面板、低速迁移面板、新时刻面板和旧教学面板具有不同条件，分别报告，不能合并分母。低速三权重比较匹配原完整task0、路径、用户α和每个实际事件的力/时刻/持续时间；不同力档的旧起扰时刻可能不同，不能将其画成同状态力幅阈值扫描。各策略在受扰前已经可能形成不同状态，不能把完整回合差异全部解释为同状态的受扰后救车动作。

同中途状态实验则继承完整物理、ESO、local300历史/FIFO、滤波、limiter、gate与clock，逐叶克隆，不只匹配位置和速度。当前实验多数来自相关祖先、有限进入状态和已用于开发的面板。新起扰时刻检查仍是DEV迁移证据，不是独立最终TEST；跨力档或同快照多轨迹不是独立训练重复。

## 5 早期解析容扰代理回答的是什么

早期固定速度局部模型采用不稳定模态坐标和折算脉冲：

```text
λ = sqrt(a4),     b = a1 + a2/λ
z = ω + λφ + (a2 δ + d_hat)/λ
Kτ = γ exp(−λτ) [1 − exp(−λΔ)] / λ
W = b² [1 − exp(−2λT)] / (2λ)
E_min(F) = (z + Kτ F)² / W
```

该式在其假设下衡量自由实际转向速率使终点z归零的最小L2控制努力。实际中层只能改有界参考，经过冻结闭环、历史、滤波与执行器后才改变实际速率；终点归零不保证中途不触地。变速和ESO变化也改变坐标导数。故本文不将能量预算拟合成经过验证的全过程防摔阈值，也不把代理的性能标签误判直接写成真实摔倒误判。原推导和适用性审计保留于[公式解释报告](../evidence/tolerance_progress_20261022/formula_explainer/README.md)，当前仅作解释对照。

### 5.1 当前保留的实测容扰度

实测容扰能力针对指定完整状态、闭环及参考规则、力方向/施力点/波形/时长/起扰时刻和观察窗。输出是各已测力档的PASS、CONTACT或UNKNOWN，并分别记录原目标首达；不是从旧解析式直接输出一个认证牛顿阈值。α及扰动前参考改变可同时改变进入状态，此时比较的是完整闭环结果，不是同一受扰状态的恢复。[E030–E031,E035]

对固定方向的幅值网格0=a0<a1<…<am，只汇总从0开始逐档PASS的最长已测前缀；零力不通过或未知时该前缀能力未定义。UNKNOWN或CONTACT均阻断前缀，后续孤立PASS仍保留。此汇总不填补网格间隙、不证明单调性，也不把最大成功力档称连续安全边界。任务接续改善与该物理能力增量分开；第4.5节重规划的到达收益不能代替防摔收益。[E021–E023,E035]

### 5.2 旧低速捕获状态：偏好差异与速度排序解释

复核既有H75左右90度/R1.1、请求1.5/1.8米/秒、α0/1的8个真实进入状态。原几何进度50%首次控制步跨越处捕获完整状态，随后停用中层更新，保持捕获时已经执行的参考，由原ECBC/ESO/local300及执行器继续控制；不锁实际速度或实际舵角。每状态0/±16/32/48/64N持续0.1秒，后缀观察4秒。72原始轨迹、8快照及归档运行源码身份核对，原标签不改。[E036–E037]

|路线/请求速度|α0实际速度|α1实际速度|α0负/正网格前缀|α1负/正网格前缀|
|---|---:|---:|---|---|
|左 / 1.5m/s|1.178m/s|1.429m/s|16 / 16N|32 / 32N|
|左 / 1.8m/s|1.407m/s|1.685m/s|32 / 32N|48 / 48N|
|右 / 1.5m/s|1.076m/s|1.472m/s|16 / 16N|48 / 32N|

非零64分支为33未触地、31触地；按同路线/请求速度及本地施扰规则比较，α1为9增0失。但8状态按实际速度排序，两个方向前缀均不下降：28状态对×2方向共56个派生序比较无反转。它们不是56个独立样本，16N粗网格也可能隐藏差异。该事后诊断与速度排序解释相容，未证明速度因果、速度充分性或α无额外信息，不据此开发选择器。[E036–E037]

施扰轴由各自捕获姿态的横向单位向量确定，后续保持该世界方向。四组α配对的世界施力方向相差11.67–13.45度，因此并非固定同一世界推力、只改变α的反事实。侧倾、转向、ESO、历史与捕获时刻也同时变化。这些结果只描述偏好生成状态及捕获参考的4秒能力，不代表持续中层、同状态恢复、原目标到达或10/20秒存活能力。全部零力通过、全部±64N触地；前缀仍不是连续阈值。[E036–E037]

## 6 讨论：现有成果和剩余科学问题

已有证据并不为空：偏好功能在原生上下文中成立，当前权重有低速到达用途，合法参考存在局部后缀机会。困难在于这些事实尚未组成一个在原α下兼顾正常任务与抗扰、且强简单对照不能解释的可部署决策。将任务失败改叫摔倒、相对弱父模型的改善改叫方法创新，或将特权见证改叫在线选择，都会超出现有证据。

当前拟检验的组织假设是“偏好可能塑造进入状态，真实参考权限可能约束可兑现的闭环容扰表现，规划用于接续到原目标”；已有条件差异尚不足以识别整条因果链，三个环节必须有各自证据，不能由任务到达替代不触地。旧解析式失去控制模块地位，不代表容扰问题消失。

任务与系统贡献仍是允许路线，并不要求每篇论文必须提出全新算法。但需要明确动态平衡、偏好和真实参考权限耦合所带来的具体问题，解释既有工作为什么没有在相同条件下回答它，并给出公平、独立的证据。当前不把更多曲线或一次小正例当作已经达到Transactions要求，也不要求策略无敌、每个指标全胜。
