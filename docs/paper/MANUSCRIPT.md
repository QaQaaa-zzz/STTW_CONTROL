# 冻结底层单轨机器人的偏好条件参考控制与闭环抗扰表现

**Preference Conditioned Reference Control and Closed Loop Disturbance Response of a Single Track Robot with a Frozen Lower Controller**

> 内部研究主稿，证据截止2026-10-28，目标期刊为IEEE Transactions on Control Systems Technology（TCST），非投稿就绪。人类作者核验及最终独立验证尚未完成。主文按科学问题组织；旧试验和反例保留于[EVIDENCE_DETAILS.md](EVIDENCE_DETAILS.md)，新增证据见主文E087–E143及源报告。普通目标学习、共同重规划和原生S弯筛查均已完成；本稿保留旧名义动态α负结果，并纳入修订后的在线几何原型，新增小型容扰MLP离线试点，尚未接入在线协调。

## 摘要

单轨机器人必须在任务执行中动态保持平衡，路径与速度偏好因而可能同时改变跟踪表现和受扰状态。本文研究冻结ECBC、ESO和local300底层外的偏好条件参考修正，并区分原用户效用、原目标首达与真实触地。已有原生四上下文中，匹配用户偏好的H75端点相对固定中点在8/8相关配对中费用更低；新增原生S弯中，H75严格任务通过10/12，而zero为0/4，但原目标首达分别为10/12与4/4。普通目标学习在另一低速紧弯接口中提高了目标到达；共同确定性重规划进一步改变所有方案的到达结局，不能将其收益归于新网络。一个预先固定参数的名义几何α往返规则仅严格通过3/4，原用户总代价高于固定α=0.5，因而未采用。新增准备时间诊断中，右紧S保持α1会触地，提前0.6秒切至α0.5则不触地且到达，施扰同刻切换仍触地；另有左S提前切换丢失到达的反例。进一步的因果几何预瞻原型在18个熟悉开发条件中到达17例、无触地，相对固定α1新增8例到达并消除1例触地；其二元结局与固定α0.5相同，16/18最终恢复用户α。随后冻结规则的两个准备初态100回合确认中，在线原目标首达18/20，对固定α1为9/20、固定0.5为16/20、固定0和Zero均20/20，全部不触地。该结果复现任务用途但不新增防摔证据；所有新增试验均为相关开发证据，尚无实车验证。按来源划分的首版容扰MLP改善了保留条件的概率评分，但α候选排序尚不稳定，未作为在线安全门使用。旧解析能量式仅作模型解释，不作为真实防摔阈值。[E062–E063,E087–E094,E099–E111,E116–E122]

## 1 研究问题与相邻方法

研究问题是：用户的路径—速度偏好怎样改变动态平衡机器人完成任务和承受扰动的表现；在不重训底层、只允许有限参考修正时，这些变化能否带来可重复且有实际意义的任务与抗扰改善？用户alpha始终不变，任务目标始终是原世界坐标目的地。这里不要求策略无敌，也不以一次成功或比弱父策略好就认定方法创新。

本文当前已实现的对象是偏好条件参考控制。现阶段的可核结果包括原生偏好响应、强普通控制下的适用范围，以及任务到达和真实触地可分离的配对证据；尚未成立的是一个可部署且具有独有防摔增量的容扰选择器。本文不把上述证据点包装成三个新算法。

偏好条件多目标控制[1,6,7]、恢复预测与任务调度[8]、参考治理及预测安全过滤[2,9–11]已有直接近邻；自行车学习控制亦非空白[3]。分层、冻结底层或加入alpha本身不足以支持首次性。区别必须落实为真实可执行参考权限下的具体控制后果，并由强对照支持；既有理论中的模型误差、终端集或稳定性前提尚未在本系统建立，不能借用其安全保证。定向阅读范围及出版方访问限制完整保留于证据明细，不冒系统综述或同条件复现。[E035,E049,E061]

给定原始空间路径p(s)与速度请求，路径跟随器产生名义参考r0=[v0,δ0]。中层读取351维观测：16帧×20字段、16个有效掩码和15个上下文字段，包含外部偏好α；输出两个latent，顺序为速度、转角。当前单网络采用已冻结的alpha调制结构；评测时权重不更新。[E017–E018]

```text
z_mid = πθ(history, context, α)
Δr_target = tanh(z_mid) × existing asymmetric scales
r_command = original filter/slew/bounds applied to (r0, Δr_target)
```

α=0表示路径优先，α=1表示速度优先。原用户α用于原任务代价评价，不能为安全把它偷偷改成另一个偏好后重新打分。底层自身的lower_alpha与中层α不同，冻结底层身份不随用户偏好变化。

共同底层为ECBC、ESO及冻结local300学习残差，最终经统一执行器约束作用于仿真机器人。底层残差与中层参考网络是不同模型。执行参考改变后，底层实际输出取决于完整物理状态、ESO、历史和执行器状态，不能把转向角速度当成中层可自由选择的输入。

原生实验与后续共同迁移接口分别冻结配置；它们的速度修正范围、几何反馈、短支持及域外接续可能不同，不能从一个接口的结果推断另一个接口的能力。所有比较先绑定完整起始状态、权重、normalizer、路径、时间和参考权限。中层50Hz、底层200Hz，每底层tick含25物理子步；5Hz对照只保持中层target，底层、跟随器、滤波和历史仍继续演化。[E008,E017–E018,E078]

双网络、蒸馏单网络、H75及后续训练分支的代码/权重身份和真实迭代关系保留于[冻结版本入口](../FROZEN_MIDDLE_NETWORKS.md)。H75是固定主要对照，后继权重不因训练较晚就默认在所有任务更强；本文不将不同架构、奖励和课程同时变化的比较解释为单因素因果消融。[E012,E014–E016,E050]

### 2.1 普通目标学习基线：已完成，作为强对照

旧V3任务费用与“进入原目的地圆”并非相同目标。为检查任务信号缺失是否限制既有策略，本研究另设普通目标学习基线；它用于建立强对照，不将增加目标观测、三个值头或PPO本身列为新算法。本分支由task_only64的Actor及log标准差权重初始化，采用新Adam，并非从H75精确恢复训练。[E082]

在原351维中层观测外，新增五维决策前上下文：车体坐标下的原目标相对位置两维、剩余时间比例、历史首达标记和目标圆半径。目标距离尺度为10米；力的幅值、方向和精确起扰时刻不进入策略。原Actor仍可训练，五维上下文经零初始化线性支路加到两维raw均值；初始均值保持父策略。G、C和S分别使用独立价值输出，其中G、S为概率，C使用下面的归一化费用单位。冻结底层、参考滤波、限幅和已定重入资格不改。[E082,E086]

定义G为10秒内、首次触地或故障之前首入原目标1米圆；同tick触地不计入，先到后倒仍为G=1、S=0。S为完整10秒无触地；未知与未完成不能填作失败。Cpre,α为原用户α下、从起点到首次到达或物理终止之前的非负运行费用，首达tick计入，触地/故障tick排除，不含旧失败终止替代。完整观察继续到10秒，首达不截断平衡尾段。采用普通加权目标：

```text
B = reward_scale × H × sum(component_cost_caps) = 8980.2
U = 2 G + S - 0.5 Cpre,alpha / B
```

在该冻结费用合同下0≤Cpre,α≤B。上述权重只保证完整已知单条结局的排序：G增加一单位即使S与费用最坏变化仍使U增加；同G下S增加也同理。这不是期望到达概率的词典序优化、存活下限约束或偏好保持保证。较宽的费用上界可能削弱原α的学习信号；该局限预先保留，不以事后扫权重补救。[E082]

训练固定36回合并行、64批全新采样，每回合完整10秒；前两批仅更新价值网络，随后62批各进行4个PPO epoch。使用左右90度/R1.1米路线、请求速度分别1.8/1.5米每秒，α为0/0.5/1，世界固定方向的力为0或±32N、持续0.1秒，每个组合两次动作随机采样；起扰task tick在400–600整数区间采样。策略梯度先合成G/C/S优势再作PPO裁剪，所有已声明回合保留，不按成功筛选或把未知记录当负例。训练固定末端64，不选择事后best或自动延长。实际完成64批、2304回合与4,608,000个底层步；Actor执行248次、价值网络256次Adam更新。首两批Actor/目标支路/log标准差不变。只有一个新增训练分支；三个α是条件输入，不是三个独立模型，也不能把64个迭代检查点称为64个独立训练重复。[E082–E083,E087,E097]

终点评价预先固定为128条物理轨迹、192个相关用户α评分视图：比较固定末端、父task_only64、zero中层和zero加既有profile7速度支持。80条改变半径至1.25米、左右请求1.7/1.6米每秒及起扰tick360/640；48条保留原几何并用tick500。各角色使用确定性均值，zero/规则的α无关物理只执行一次再重评分；原目标与用户α不改。迁移面板重设下层历史，源物理初态相关，故是联合DEV迁移而非独立测试或训练重复。随后补充相同条件的冻结H75共48条，构成176条实际物理轨迹和240个相关评分视图；固定路径结果以及全方法共同重规划的另176条结果见第4.6节。逐tick冲量与实际窗口按原合同核对，不把提前终止后未观察的脉冲当施力错误。[E082,E084–E085,E088–E090]

## 3 评价与数据角色

### 3.1 原目的地与物理结局

到达：按各试验预声明的观察窗（旧面板10秒，重规划比较20秒并另报同轨迹10秒前缀），在首次触地或故障之前，有真实记录XY进入原世界目标点1米圆。它不要求末速度、航向或保持窗口，不以几何域退出否决已经发生的到达。1米是当前工作口径；0.5、0.75米和近期预声明1.25米仅作相应敏感性，原标签保留。

整窗不触地：完整观察该试验声明的10秒或20秒且未发生真实非轮触地；数值/控制故障或不完整记录单列，不强行作控制失败。近期contact-only诊断保留侧倾/任务域标记作遥测，不将工作侧倾阈值当真实摔倒。原生评测仍按各自冻结合同，将首个native physical/domain/fault停止作为到达观测终点，不能直接用contact-only口径替换；第4.1节H75/current原四上下文的16条实际均完整且没有原生物理/域失败，这不涵盖全部历史native面板。[E001,E011]

四类结局应分别报告：到达且全窗活、未到达但全窗活、到达后触地、未到达且触地；另保留未知。到达不是仅穿过路径终点截面，不触地也不是已经回到任务或具备环境避障安全。

### 3.2 原用户效用与实际容扰对象

原用户代价Jα由同一配置的原奖励分项逐实际tick重算；失败终止替代、全部轨迹均值和共同存活条件均值分开。不同α的原始成本不直接互相排名。同一条实测轨迹可以在不同用户效用下重评分，但这不是换α后真实闭环的反事实轨迹。重规划之后，沿新执行路径计算的V3路径误差只作该执行路径诊断，不能静默冒作原用户路径效用；当前尚未建立可跨所有原路/改路合同直接比较的统一Jα，故重规划结果主要分报原目标首达和物理结局。

闭环容扰对象必须指定完整状态ξ、策略π、参考方案、力方向/波形/持续时间、起扰与观察窗。对这些条件固定后，记录实测通过、触地失败与未知标签。未经单调性检查的离散成功档不能视为连续安全区间，也不能断言超过某个已测成功档必然摔倒。本文当前主要报告指定扰动事件的真实结局，不宣称已获得通用牛顿阈值。

为使研究对象可检验，定义（研究定义，不是新增已测结果）：

```text
xi = 完整物理/ESO/控制器/local300历史/FIFO/参考滤波与限幅/时钟
     + 路径与投影/follower/relay与gate/适用的随机状态
sigma = (方向d, 波形h, 持续时间Delta, 起扰时刻tau, 观察窗H)
C(pi, r; xi, sigma) = { F >= 0 : 完整闭环在[0,H]内无非轮触地 }
```

其中r是经原接口执行的参考方案，π包括冻结底层及所声明的中层决策。只有完整、无故障且整窗未触地者才记实测通过；在故障或截断前已明确触地者记触地失败，其余未能完整观察的分支记未知，不放入已测整窗不触地样本集合。比较不同用户α的完整回合，回答“偏好形成的进入过程与抗扰表现如何耦合”；克隆同一完整中途状态后再改参考，回答“此状态下参考干预是否有局部作用”。两种问题不能互相冒充；更换路径/投影后不再称完整闭环状态相同。

实际报告已测事件的通过、触地失败与UNKNOWN三态观测，而不是为所有力档给出完整的C成员判定。若汇总从零开始连续通过的已测网格前缀，其最大档仅为网格摘要，不证明档间连续安全或更大力一定失败。方向、时长和时刻改变后须重新标明条件；当前物理Critic或E_min的标量不能直接换算为该集合的牛顿半径。

### 3.3 配对与推广范围

同一实际轨迹在多个评价权重下重评分不增加物理样本数；同一祖先的力档/时刻也不是独立训练重复。不同任务栈分别报告，不合并分母或把几项局部正例拼成安全方法。原生停止、contact-only续观测、域外held和重入的语义按各冻结合同解释；域退出没有触地时，其后物理结局可能未知，不能算整窗存活或摔倒。完整中途快照需包括ESO、历史、FIFO、滤波、投影与时钟，位置和速度相同不足以称同状态。

## 5 旧解析式的物理含义与适用限制

早期固定速度局部模型采用不稳定模态坐标和折算脉冲：

```text
λ = sqrt(a4),     b = a1 + a2/λ
z = ω + λφ + (a2 δ + d_hat)/λ
Kτ = γ exp(−λτ) [1 − exp(−λΔ)] / λ
W = b² [1 − exp(−2λT)] / (2λ)
E_min(F) = (z + Kτ F)² / W
```

该式在其假设下衡量自由实际转向速率使终点z归零的最小L2控制努力。实际中层只能改有界参考，经过冻结闭环、历史、滤波与执行器后才改变实际速率；终点归零不保证中途不触地。变速和ESO变化也改变坐标导数。故本文不将能量预算拟合成经过验证的全过程防摔阈值，也不把代理的性能标签误判直接写成真实摔倒误判。原推导和适用性审计保留于[公式解释报告](../evidence/tolerance_progress_20261022/formula_explainer/README.md)，当前仅作解释对照。

一个额外的代数检查限制了“低速不可恢复”的解释。对原固定速度三状态模型，能控矩阵行列式D=a4·a1²−a2²；当前系数在约1.206865米/秒处D=0，但失去控制的是稳定极点−sqrt(a4)，不稳定方向b_plus仍约−3.65743/s。因此不能从该根断言物理不可稳定，也不能以既有gain hold分支直接解释此前实际触地。该检查没有ESO/local300/执行器积分，不修改任何底层；一般的稳定模态不可控现象已有自行车研究先例[15]。完整推导、适用边界与图见[数学核查](../../runs/ecbc_modal_authority_math_v1/REPORT.md)。[E080–E081]

## 6 讨论与尚缺证据

偏好网络内部能表达取舍，不等于比所有外部控制器更好；目标首达改善不等于整窗防摔改善；更低侧倾或更小局部能量指标也不等于更大可承受推力。当前证据包括条件性任务收益与准备时间改变真实触地结局的局部效应。控制器不读取真实起扰时刻的几何原型已在熟悉开发条件下验证，第4.11节补充了新准备初态和起扰时刻的有限确认，仍不提供普遍安全保证。

任务和系统研究可以形成论文贡献，不要求凭空发明全新算法，但必须明确相邻工作未回答的具体问题，并提供对应证据。准备时间试验给出了具体控制效应，但本稿仍需完成在线机制、适用范围及独立确认；大量相关DEV轨迹、不同栈正例或AI审查均不能替代独立确认。已有训练重复若配方不同，不能当同方法重复；当前实机部署未开始，不能补写硬件、作者、资助或审批事实。

用户已明确原终点首达的重要性，并要求受扰后共同接回。原整窗V3含首达后跟踪费用，首达前费用和执行新路径费用各有不同用途，不能事后互换以改变排序。普通目标学习与共同接回已完成，前者有本DEV到达收益，后者也带来部分回退；均未提供本组防摔增量。原生S弯进一步显示固定中间偏好是强对照，当前名义往返规则未超过它。[E087–E094]

以TCST为目标，现阶段应保留“偏好执行时序是否改变闭环容扰能力”的研究问题，而不能把“小型容扰MLP必不可少”当既定答案。第4.9–4.10节已提供准备时间和因果在线原型的局部证据；第4.11节已完成冻结规则的新初态/时刻五臂确认；第4.12节同态试采已获得正负标签及候选α差异；第4.13节首版预测试点概率评分改善但候选排序不稳定；第4.14节排序辅助及checkpoint选择对照改善了开发排序，第4.15节封存候选的新来源确认复现了排序用途，第4.16节已完成120回合在线协调并发现返回偏好过于保守；不能把同源条件数冒充独立状态覆盖。必要的固定偏好和速度支持对照用于定位增量，不把穷尽简单方案或巨大百分比优势作为研究门槛。原状态、候选α、扰动方向/持续时间及准备时间条件下的预测不触地概率是待研究对象；已完成首版小网络及在线原型验证，但尚缺全时域容扰标签、任务期间及时返回及更广场景确认；第4.10节的几何规则与第4.16节学习评价器必须区分。若未来普通控制已覆盖收益，应缩减方法主张；若发现剩余机会，应先用有界机制试验区分参考时序、状态变化和任务接回效应，而不是恢复已关闭的参数搜索。[E092–E094]
