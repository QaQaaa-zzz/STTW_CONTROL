## 6. 外环：Pure Pursuit，而不是新网络

参数：lookahead_time=.7s，L_min=.8m，L_max=1.8m。
L=clip(.7*max(actual_forward_speed,1.5),.8,1.8)。

从路径读取P(s+L)，变换到车体平面坐标(X,Y)。使用真实弦长分母：
κ_pp=2Y/(X^2+Y^2)。
不要因为s+L是弧长前瞻，就直接用L^2替代真实弦长平方。

δ_target=atan(wheelbase*κ_pp/cos(caster))，限幅±.30rad。
v_target=v_user。

以200Hz将名义参考朝target限速发布，速度.5m/s²，转角.3rad/s；PP目标每50Hz更新。

基线应使用实际车辆后轴/车架参考点的既有约定，不混用不同原点。先用已有正转角→正参考曲率约定检查符号：车在直线左侧应给向右修正；镜像亦然。

X<=.05m、路径航向误差绝对值>=π/2或目标无效时，标注超出本轮前进跟踪适用域并停止该诊断，不做原地旋转，不偷偷跳到另一段路线。

纯追踪的原理依据Coulter (1992) CMU-RI-TR-92-01；速度相关前瞻是常见工程选择。本轮数值是待验证初值，不是底层稳定性证明。不直接移植Nav2默认的曲率限速或动态窗口搜索。

## 10. 阶段C奖励：路径优先不再等同于车把指令优先

核心误差：
ev=actual_forward_speed-v_user；ey=当前固定路径横向误差；eh=当前路径切线航向误差。

令δ_ff=atan(L_wheelbase*κ_path/cos(caster))，
χ=clip((abs(δ_ff/q(v_user))-.18)/.12,0,1)。
这里χ仅作为任务难度分类，使用固定路径局部曲率；不是NN输出自己的安全阈值，也不是动力学保证。

H(z)=z²(|z|<=1)，否则2|z|-1。
C_speed=(10-9χ(1-α))*H(ev/.10)。
C_path=(10-9χα)*[H(ey/.10)+.5H(eh/.10)]。
C_primary=20χ*[(1-α)H((abs(ey)-.10)+/.10)+αH((abs(ev)-.05)+/.10)]。

意义：普通和出口直线χ接近0，两项都重要；急弯χ较大，α0主要保护几何路径，α1主要保护速度。路径误差持续非零始终有成本，不能为了展示差异主动偏离。

共同成本：
C_roll=40H((peak_roll-.26)+/.04)；
C_work=120H((peak_roll-.30)+/.02)；
C_roll_rate=H((abs(phi_dot)-.8)+/.8)；
C_over=2H((ev-.05)+/.10)；
C_low=4H((1.5-v)+/.20)；
C_mag=.02[(Δv/1)^2+(Δδ/.20)^2]；
C_rate=.03[(dΔv/dt/1)^2+(dΔδ/dt/.40)^2]，dt=.02，只对已执行offset做策略端点差分，每策略步计一次。

- 不加“必须保留PP转角”的强主项；必要时偏离PP指令正是协调网络的工作。
- 不使用旧time-reference航向债或旧回正g；路径外环本身持续纠偏，不再添加第二套相互矛盾的航向任务。
- 不奖励前进得比时间车辆更快，不惩罚单纯沿路径落后。
- 不加规划器自动曲率减速替α做选择。
- 分项高位caps使用JSON，和为5080.2；无global clip。记录分项触顶。
- 正常每5ms reward=-.1*.005*sum(costs)。失败一次替换当前策略区间和剩余有限任务成本：-5-.1*.02*5080.2*(1-gamma^N)/(1-gamma)。N包含当前区间；fault/termination/truncation沿用已核验的有限任务契约。
- 软奖励不是严格安全保证。不能因为加入大惩罚就宣称所有请求可行。
